# 영상 색상 공통 규칙

영상은 송신 기기와 수신 화면이 모두 컬러일 때만 컬러로 표시합니다. 컬러 로비폰 → 흑백 비디오폰/경비실기는 흑백, 흑백 로비폰 → 컬러 화면도 흑백입니다. 기기의 사양이 확인되지 않으면 흑백을 기본값으로 사용합니다.

공통 판정과 색상 변환은 `video/VideoFormat.java`를 사용합니다. 현재 KVM 모델은 `KvmModel.videoFormat()`에서 흑백 CRT 사양을 명시하고, 모든 KVM 영상 화면이 이 수신 사양을 반드시 전달합니다. KLP-204/204RF의 컬러 송출 사양은 유지합니다. 앞으로 추가하는 로비폰·비디오폰·경비실기는 송출 사양과 표시 사양을 각각 명시하고 이 공통 판정을 사용해야 합니다. 실시간 영상·미리보기·저장 영상에도 같은 제한을 적용합니다.

기존에는 일부 KVM 화면이 송신 로비폰의 컬러 여부만으로 컬러를 표시할 수 있었습니다. 수신 사양을 생략하는 호출 경로를 제거했습니다. 네 가지 송수신 조합과 흑백 RGB 채널 일치, 현재 KVM 모델 사양을 자동 검사합니다. 동작 이미지나 스크린샷은 생성하지 않습니다.
