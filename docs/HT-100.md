# 삼성 HT-100 도어카메라

깨끗한 정면 사진을 색상과 인쇄의 기준으로 삼고, 앞서 제공된 다섯 장의 측면 사진은 본체와 외곽틀의 분리 및 깊이 기준으로 사용했습니다. 변색, 먼지, 도료, 렌즈에 붙은 물질은 모델에 그리지 않았습니다.

본체 높이는 외곽틀을 제외하고 **0.300블록**, 가로는 정면 비율에 맞춘 **0.228블록**입니다. 외곽틀을 장착하면 각각 0.312, 0.240블록입니다. 본체는 둥근 뒷케이스와 앞커버, 분리된 상단 카메라 패널, 파란 표시창, 원형 다층 렌즈, 하단 6개 스피커 슬롯, 두 줄 마이크, 호출 버튼, 버튼 표시창, 하단 구멍막음 부품으로 구성됩니다.

삼성 탭의 `HT-100` 아이템은 사진의 외곽틀이 장착된 상태로 설치됩니다. 빈손으로 웅크리고 클릭하면 틀을 떼어 아이템으로 돌려받습니다. `HT-100 탈착식 외곽틀` 아이템으로 클릭하면 다시 장착합니다. 다른 틀 디자인은 후속 부품으로 확장할 수 있도록 틀의 형상과 장착 상태를 본체와 구분했습니다.

홈링커로 세대 내부기기를 먼저 선택하고 HT-100에 사용하면 같은 단지의 세대번호가 연결됩니다. 호출 버튼을 클릭하면 해당 세대 내부기기에 착신하고 파란 표시창이 켜집니다. 통화는 본체 마이크·스피커를 사용하며, 통화 종료 시 표시창이 꺼집니다. 버튼을 다시 누르면 호출을 취소하거나 통화를 끊습니다. 실내기의 영상 통화·현관 확인 및 문열림 경로와 연결되며, 이동 도구로 위치를 옮길 수 있습니다.

설치 화면에서 스피커 슬롯과 마이크가 앞커버에 가려진 문제를 수정했습니다. 여섯 슬롯의 실제 메시 표면이 앞커버보다 앞에 노출되는지 검사하고, 렌즈의 밝은 회색 고리를 사진에 가까운 어두운 자주색으로 바꿨습니다. 로고도 사진 비율에 맞춰 키웠습니다.

서버 GameTest 40개와 실제 클라이언트의 HT-100 메시·월드 렌더링, 기존 통화·영상·이동 검사를 통과했습니다. 제품 사진이나 게임 스크린샷은 생성하지 않았습니다.
