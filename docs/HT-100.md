# 삼성 HT-100 도어카메라

깨끗한 정면 사진을 본체의 색상과 윤곽 기준으로, 이전 다섯 측면 사진을 탈착식 외곽틀과 깊이의 기준으로 삼아 기존 외형 메시와 그림 자산을 전부 새로 만들었습니다. 변색, 먼지, 도료, 렌즈에 붙은 물질은 재현하지 않았습니다. 기존 월드에 설치한 기기의 등록 ID와 세대 연결 정보는 유지됩니다.

외곽틀을 떼어낸 본체는 **높이 0.300 × 폭 0.226블록**입니다. 틀을 장착한 외곽은 **높이 0.310 × 폭 0.238블록**이고 본체가 틀 앞으로 함께 이동합니다. 뒤쪽 둥근 케이스, 전면 커버의 넓은 곡면, 상·하부 이음선과 독립된 틀의 경사면을 따로 구성했습니다. 정면 사진의 세로로 긴 암색 패널 안에 짙은 파란 표시창과 자주색 다층 렌즈를 놓았고, 오른쪽 위 마이크 두 줄, 하단의 실제로 파인 가로 스피커 홈 여섯 개, 둥근 호출 버튼과 표시창, 맨 아래 분리된 구멍막음 부품을 3D 표면으로 만들었습니다. 로고와 모델명은 새 인쇄 자산입니다.

삼성 탭의 `HT-100`은 외곽틀을 끼운 상태로 설치됩니다. 빈손으로 웅크려 클릭하면 틀을 떼어 아이템으로 돌려받고, `HT-100 탈착식 외곽틀` 아이템으로 클릭하면 다시 끼웁니다. 본체와 틀은 별도 형상이므로 후속 틀 디자인으로 바꿀 수 있습니다.

홈링커로 같은 단지의 세대 내부기기를 먼저 선택해 HT-100에 사용하면 세대번호가 연결됩니다. 호출 버튼을 누르면 내부기에 착신하고 파란 표시창이 켜집니다. 본체 마이크·스피커로 통화하며 통화 종료 시 표시창이 꺼집니다. 다시 누르면 호출 취소 또는 통화 종료입니다. 실내기의 현관 영상·문열림 경로 및 공통 이동 도구와 연결됩니다.

클라이언트 메시 검사는 외곽틀 분리, 세로형 카메라 패널, 여섯 개 홈의 전면 노출, 마이크, 호출 버튼, 메시 캐시를 확인합니다. 서버 GameTest는 호출·통화·틀 탈착·이동을 확인합니다. 제품 사진과 게임 스크린샷은 테스트 산출물로 만들지 않습니다.
