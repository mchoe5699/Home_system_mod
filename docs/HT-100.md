# 삼성 HT-100 도어카메라

본체 높이는 외곽틀 없이 **0.300블록**, 폭은 **0.226블록**입니다. 마지막의 깨끗한 정면 사진을 색상·인쇄·정면 배치의 기준으로 삼았습니다. 앞선 다섯 장의 사진은 측면 곡률과 외곽틀의 별도 구조를 확인하는 데만 사용했습니다. 앞선 사진에 보이는 황변, 도료, 오염, 렌즈의 부착물과 변색된 푸른 표시부는 재현하지 않았습니다.

본체는 둥근 뒤 케이스와 평평한 앞면, 가장자리에서 뒤로 말리는 좌우 측면, 본체와 이어지는 완만한 양쪽 세로 몰딩로 구성됩니다. 상단 덮개와 하단 조작 구역에는 분명한 가로 이음선이 있습니다. 카메라 패널은 **거의 정사각형**이며 안쪽의 어두운 감색 표시부와 자주색 테두리를 가진 원형 렌즈는 독립된 깊이로 만듭니다. 오른쪽 위 마이크 두 줄, 하단 왼쪽의 실제로 파인 가로 스피커 홈 6개, 하단 오른쪽의 약간 돌출된 호출 버튼과 작은 상태 표시부, 아래 중앙 반원형 마개도 별도 형상입니다. 본체와 외곽틀의 색은 깨끗한 사진의 차가운 은회색 계열입니다.

외곽틀은 본체 뒤에 끼우는 분리 가능한 부품입니다. 틀을 끼운 외곽 크기는 **높이 0.310 × 폭 0.238블록**이며 본체도 틀의 두께만큼 앞으로 이동합니다. 빈손으로 웅크리고 클릭하면 틀을 떼고, 틀 아이템으로 클릭하면 다시 끼웁니다.

홈링커로 같은 단지의 삼성 또는 타사 세대 내부기기를 먼저 선택한 뒤 HT-100을 클릭하면 연결됩니다. 선택한 내부기기에 동·호 번호가 없다면 먼저 설정하라는 안내가 표시됩니다. 같은 세대로 다시 클릭하면 연결이 해제됩니다. 호출 버튼을 누르면 실내기에 착신하고 표시부에 빛이 들어옵니다. 실내기의 현관 영상, 본체 스피커·마이크 통화와 문열림 경로를 지원하며, 공통 이동 도구로 이동할 수 있습니다.
