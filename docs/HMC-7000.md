# 현대 HMC-7000 경비실기

크리에이티브 HomeNet 탭의 **현대 HMC-7000 경비실기** 또는 `/give @s qwertys_homenet:hmc_7000`으로 설치합니다. 가장 긴 변인 앞뒤 **0.8블록**, 가로 약 **0.67블록**의 세로형 책상 위 제품입니다. 흰색 본체·수화기·받침, 회색 원형 숫자 버튼, 납작한 기능 버튼, 경보 아이콘, 2줄 LCD를 사진 기준으로 구성했습니다. 케이블·낙서·스티커·노후 오염은 제외했습니다.

제품을 바라보고 **Ctrl＋/－**를 누르면 **LCD만 1도씩 0~65도** 움직입니다. 조절 방법은 KAM-305와 같습니다. 로고 편집 도구로 기본 HYUNDAI TELECOM / 숨김 / 직접 문구 / 리소스팩 이미지를 선택합니다. 저장·이동 후에도 각도와 로고가 유지됩니다. 본체 뒤쪽을 맨손으로 웅크려 클릭하면 전원을 켜고 끕니다.

## 연결과 관리실 번호

현대 **HYUNDAI BUS** 호환 세대·로비폰과 연결합니다. 코콤 BUS와는 제조사 규격이 달라 직접 연결하지 않습니다. 현재 모드의 코콤 제품을 현대 제품으로 가장해 연결하지 않으며, 현대 세대기·로비폰은 이후 같은 프로토콜로 추가할 수 있습니다. HMC-7000끼리 관리실 통화는 가능합니다.

모든 통화·메시지·착신 전환은 **같은 단지 구획** 안에서만 동작합니다. 대시보드로 여러 구획을 같은 단지로 묶을 수 있습니다. 연결 후 구획이 분리되면 통화도 종료됩니다.

조작 화면 아래의 **관리실 번호 저장**으로 0~9999를 설정합니다. 같은 단지의 중복 번호는 거부합니다. 관리실1~4 버튼은 각각 번호 1~4, 중앙관리실 버튼은 번호 0을 선택합니다. 임의의 관리실 번호는 관리실 버튼을 누른 뒤 숫자로 입력합니다. 경비실 링크 아이템으로 호환 세대기를 일괄 연결합니다.

## PDF에 따른 버튼 조작

- 수화기를 클릭하거나 **H**로 들고 놓습니다. 세대 발신은 `동번호 → 동 → 호번호 → 호출`입니다. 받는 쪽이 응답하면 통화가 연결되고 수화기를 놓으면 종료합니다. 메시지 입력란으로 연결 상대와 통화 메시지를 주고받습니다.
- 응답하지 않는 세대 호출 중 **세대**를 누르면 경비실 메시지 대기 표식을 남깁니다. 세대가 경비실로 다시 호출하면 지웁니다. 현대 세대기는 저장된 `HmcGuardMessage` 표식으로 메시지 램프를 표시할 수 있습니다.
- 공동현관은 **로비폰**입니다. 공동현관 호출을 수신할 수 있으며 수화기를 들면 응답합니다. 동시에 여러 종류의 호출이 오면 **공동현관 → 세대 → 타 관리실 → 중앙관리실 → 관리실1~4** 순으로 우선 수신합니다. 수화기를 들기 전에 해당 종류의 버튼으로 수신 대상을 고를 수 있습니다.
- 관리실1~4 또는 중앙관리실을 선택하고 **호출**합니다. 다른 번호는 `관리실 → 번호 → 호출`입니다.
- 세대와 통화 중 **보류**를 누르면 세대 통화를 유지하며 대기시킵니다. 수화기를 내려도 보류가 유지됩니다. 다시 들거나 보류를 누르면 복귀합니다. 보류 중에는 다른 종류의 대기 호출을 직접 선택할 수 없습니다.
- 세대를 보류한 뒤 상대 세대 번호를 입력해 호출하고 응답 후 수화기를 내려놓으면 **두 세대가 직접 통화**합니다. 경비실이 빠진 뒤에도 메시지와 종료가 이어집니다.
- 세대에서 경비실로 걸어온 통화가 연결된 상태에서만 `* → 새 동번호 → 동 → 새 호번호 → 동 → 현관번호(두 자리) → #`로 주소를 등록합니다. 잘못된 번호·중복 주소·보류 중 등록은 거부합니다.
- 경보 **시험**은 화재→가스→방범→비상→화재 순으로 순환합니다. 실제 호출·경보·수화기 들기는 시험을 종료합니다. **경보음정지**는 소리를 정지·재개하고 표시등은 계속 점멸합니다. 새 경보가 오면 정지를 해제합니다. **복귀**는 경보·시험·모닝콜을 확인하고 시간 표시로 돌아갑니다.
- 실제 경보가 여러 개면 각 종류의 표시등이 함께 점멸하고 LCD에는 가장 최근 경보의 세대가 나옵니다. 화재·가스·방범·비상 버튼은 해당 종류의 저장 기록을 최신 순으로 조회합니다. 5초 동안 조작하지 않으면 종료합니다. 기록은 월드 저장 후에도 유지되며 최대 1024건을 보관합니다. 프린트 버튼은 저장 기록을 게임 채팅으로 출력합니다.
- 시간 표시 중 `1 → *`로 시간을 수정합니다. 월→일→시→분→오전/오후→요일 순으로 **동(→)** 또는 키보드 오른쪽 방향키로 이동합니다. 숫자로 수정하고 오전/오후·요일은 **0(↑)**으로 변경합니다. **#**로 저장합니다. 선택된 항목은 점멸합니다.
- 시간 표시 중 **3**으로 모닝콜 설정을 조회하고 **3 → ***로 시·분·오전/오후를 편집한 뒤 **#**로 저장합니다. 조회 상태에서 곧장 **#**를 누르면 설정을 삭제합니다. 지정 시각에는 대기 상태에서 호출음이 울리며 수화기를 들거나 복귀를 누르면 멈춥니다. **2**는 소프트웨어 버전을 표시합니다.

숫자는 키보드·숫자패드로도 입력합니다. `*`·`#`는 그대로 입력하며, Backspace는 `*`, Enter는 호출입니다. 메시지·관리실 번호 입력란에 포커스가 있으면 일반 텍스트 편집을 우선합니다.

## 첨부 PDF와 게임 표현의 차이

첨부 PDF는 스캔 16면이며 마지막 본문은 31쪽입니다. 목차에 있는 **착신 전환 32쪽은 파일에 포함되어 있지 않습니다**. 따라서 착신 전환은 게임 조작으로 `수화기를 내려놓고 착신전환 → 대상 관리실 번호 → 호출`로 설정하고, 착신전환을 다시 누르면 해제하도록 구현했습니다. 실제 PDF의 누락된 조작 순서를 재현했다고 주장하지 않습니다.

경보는 3초 경보음 뒤 안내 구간을 반복하며 한국어 안내 문구는 가까운 플레이어에게 텍스트로 알립니다. 녹음된 한국어 음성이나 실제 프린터 출력은 포함하지 않습니다. 장비의 음성 통화는 기존 모드와 같이 통화 메시지로 표현합니다.

검증: `python3 tools/check_hmc7000_assets.py`, 설계 검사, 전용 서버 GameTest(통화·교환·우선 수신·단지 경계·경보·시계·모닝콜·주소 등록). 작동 예시 이미지나 게임 화면 캡처는 생성하지 않습니다.

경보 조회 버튼 외형: 화재·가스·방범·비상 줄의 아래쪽 중복 글씨는 제거하고 버튼 면에만 표시합니다. 흰색 공통 테두리 안에 세 개의 좁은 밝은색 버튼과 더 넓은 빨간 비상 버튼을 배치하고, 외곽 끝부분의 곡면과 버튼 사이 분할선·음영을 적용했습니다.

추가 외형 보정: 숫자키의 지름·가로/세로 간격과 오른쪽 기능키의 줄 높이를 다시 맞췄습니다. 관리실 선택키·경보음정지·착신전환·프린트 버튼은 더 얇은 회색 버튼으로 다듬고, 가장자리의 음영과 왼쪽 미끄럼 방지 무늬를 적용했습니다. 숫자키·기능키의 표시 위치와 클릭 위치는 같은 배치 파일에서 읽습니다. 경보 버튼 줄의 글씨는 버튼 면에만 유지합니다.

로고는 조작 화면 오른쪽 아래 **로고 변경** 버튼으로도 편집할 수 있습니다. 전원을 꺼도 편집이 가능하며 기존 로고 편집 도구와 같은 공통 편집기를 사용합니다.

선명한 정면 사진 기준 재작업: 넓은 수화기 상단과 좁아지는 손잡이, 둥근 하단을 별도 단면으로 구성하고 받침과의 간격을 줄였습니다. 본체 조작판의 얕은 단차와 LCD 프레임의 입체 테두리, 더 얇은 경보 표시창, 버튼 줄의 여백·숫자키 지름·회색 기능키 폭을 조정했습니다. 최장변 0.8블록, 흰색 본체, 기존 기능과 LCD 각도 조절은 유지합니다.
