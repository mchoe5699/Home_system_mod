# KVM-931 / 932 / 936, KVM-931T / 932T

기존 KVM-931과 같은 가로 0.45675블록·세로 0.45블록 및 얇게 조정한 본체 테두리를 사용합니다. 신제품 ID는 `qwertys_homenet:kvm_932`, `qwertys_homenet:kvm_936`, `qwertys_homenet:kvm_931t`입니다.

- **KVM-932**: 사진처럼 검은 비상 버튼, 외출·경비·현관/LP·문열림 순서입니다. 첨부 KVM-932 국문 설명서에 맞춰 BUS 경비·로비 통화, 30초 무응답 해제, 3분 경비·로비 통화 종료, 통화 선택, 비상·외출, 로비 통화 중 문열림을 지원합니다. 현관 통화는 상세 설명에 따라 3분 후 화면이 꺼지며 현관/LP 버튼으로 다시 켤 수 있습니다. 외출은 버튼으로 해제하며, 외출 중 현관 호출에 응답해도 해제됩니다. 대기 중 수화기를 들었다 내려놓는 것만으로 외출이 해제되지는 않습니다. 외출 중 경비 호출은 울리지 않고 로비 호출은 연결된 경비실로 우회합니다.
- **KVM-936**: 경비·로비·현관·문열림 네 버튼을 개별 배치합니다. 큰 검은 원과 가로등은 모두 전원 램프이며 같은 전원 상태를 사용합니다. 검은 원은 누르는 버튼이 아닙니다. 비상·외출·국선 버튼은 없습니다. BUS 경비실에 연결하며 세대 주소는 **호 번호 1~9999만** 저장합니다. 동-호 주소는 서버에서 거부합니다. AM-10KP와 KAM-305에서 호 번호로 등록·호출할 수 있고, KAM-305의 936 개별 등록 화면에서는 동 입력란을 건너뜁니다. 같은 경비번호/경비실에 연결된 로비폰에서는 해당 호 번호로 호출됩니다. 로비·현관 버튼으로 각각의 통화를 선택하고 로비 통화에서만 문열림을 허용합니다. 936 동작 중 사진에 없는 기능은 932 BUS 동작을 기준으로 했습니다.
- **KVM-931T**: 932T의 외형과 전화·보류·재다이얼·비상·외출·통화 기능을 유지하되 문열림 버튼·문구·클릭 영역을 제거하여 평평하게 메웠습니다. 서버에서도 문열림을 차단합니다. 전화 계열의 가로 버튼은 국선·보류·재다이얼 순서입니다.

931 기본형·화면 버튼형·932·936이 한 형제모델군이고, 931T·932T가 별도 형제모델군입니다. 통화 중 모델 변경은 차단하며, 936으로 전환하면 동이 없는 고유 호 번호를 배정하고 931/932로 전환하면 경비실의 동·호 주소를 다시 배정합니다. 호환되는 경비실 연결과 로고 등 설정은 유지합니다.

형제모델 선택창은 기존·신규 모두 `FamilyModelScreen`을 사용합니다. 모델명/ID/기능 설명 검색, 검색 결과 스크롤, 현재 모델 강조, 선택 영역과 닫기 버튼이 공통입니다. 경비실 링크 아이콘은 경비실 패널과 연결 플러그, 형제모델 변경 아이콘은 두 패널과 양방향 화살표로 변경했습니다. 실제 인벤토리 텍스처만 생성하며 동작 이미지나 게임 스크린샷은 생성하지 않습니다.
