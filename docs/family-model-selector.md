# 공통 형제모델 선택창

KVM, IP-203AP, KLP 계열은 모두 `client/family/FamilyModelScreen.java`를 사용합니다. 창 크기·배경색·제목·현재 모델 표시·선택 강조·모델 이름과 기능 설명·스크롤바·하단 안내·클릭 영역이 공통입니다. 제품군별로 모델 목록과 설명만 다릅니다. 선택 후 전환 요청과 서버의 통화/수화기/호환성 검사는 유지합니다.

앞으로 추가하는 형제모델 선택창도 반드시 이 공통 클래스를 상속합니다. `Choice(id, label, description)` 목록과 현재 모델 ID, 제품군 이름을 생성자에 전달하고 `update`에서 서버 응답만 처리합니다. 레이아웃과 렌더링, 스크롤, 클릭 처리는 공통 클래스의 final 메서드를 사용합니다. 개별 선택창에 별도의 디자인을 추가하지 않습니다.

이미지 생성이나 게임 스크린샷 촬영은 하지 않으며 코드·빌드·자산·자동 검사로 검증합니다.
