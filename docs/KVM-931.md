# KOCOM KVM-931

첨부 KVM-931 사용설명서와 사진을 기준으로 만든 4선 KOCOM BUS 비디오폰입니다. 크리에이티브 HomeNet 탭의 `qwertys_homenet:kvm_931`로 설치하거나 기존 공통 형제모델 선택창에서 선택합니다. 기존 KVM 모델들의 크기와 기능은 유지합니다.

세 번째 사진의 거의 정사각형 비율(1.015:1)을 적용하여 본체 가로 0.5075블록, 세로 0.5블록입니다. 수화기까지 포함한 깊이는 약 0.111블록이며 네 벽 방향으로 설치할 수 있습니다. 실제로 파인 수화기 받침과 CRT, 걸쇠·타공 스피커·아래 조절부, 곡면 수화기, 둥근 돌출 버튼과 램프를 별도 구조로 만들었습니다. 몰딩 경사와 가장자리·파임의 명암을 표현합니다. 사진의 세 원형 빈 자리와 가로 전원 램프를 유지하고, 세 번째 사진처럼 비상·외출·현관·경비의 네 버튼을 사용합니다.

- 현관 카메라 호출: 딩동 호출음, 화면 자동 켜짐, 현관 램프 점멸. 수화기를 들면 통화하며 램프가 점등합니다. 수화기를 내려놓으면 종료합니다.
- 수화기를 놓고 현관 버튼을 누르면 방문자 화면을 확인하고 다시 누르면 꺼집니다. 무응답 호출은 약 30초 후 해제됩니다. 통화 중 약 3분 후에는 화면만 꺼지고 음성은 유지하며 현관 버튼으로 다시 켭니다.
- 대기 상태에서 수화기를 들면 연결된 BUS 경비실을 자동 호출합니다. 경비 통화 중 들어온 현관 호출은 현관 버튼으로 선택하고, 경비 버튼으로 기존 경비 통화에 복귀합니다.
- 비상 버튼은 경비실에 비상을 통보하고 비상 램프가 점멸합니다. 수화기를 들었다 내려놓으면 비상이 해제됩니다. 외출 버튼은 외출 상태와 램프를 설정/해제합니다.
- 전원·비상·외출·현관·경비 램프는 실제 상태와 연동합니다. 음량·밝기·명암과 로고 설정, 제품 이동 도구를 지원합니다. 931에는 국선 다이얼이나 전용 문열림 버튼을 추가하지 않았습니다.

세대번호는 기존 BUS 모델처럼 경비실기에서 동·호수 각각 1~9999로 등록합니다. 기존 공통 선택창에서 형제모델을 전환할 수 있으며 통신 방식이 호환되는 설정과 로고를 유지합니다.

검증은 코드·자산·서버 자동 검사로 진행합니다. 동작 이미지나 게임 스크린샷은 생성·촬영하지 않습니다.
