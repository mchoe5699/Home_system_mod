# IP-200PC · IP-200PCHB · DP-202H

세 제품 모두 IP-203APB의 본체·수화기·받침·뒤판과 세로 0.4블록, 가로 0.176블록 크기를 공유합니다. 앞쪽 플라스틱은 흰색, 뒤판은 회색이고 설치판·코일선·전선은 제외합니다. 버튼부와 로고·모델명 배치는 제공 사진을 참고했습니다. 설치 모델·아이템·조작 화면의 버튼 구성을 함께 맞췄습니다.

| 제품 | 버튼 | 경비실 | 세대 현관 호출 |
| --- | --- | --- | --- |
| IP-200PC | 없음 | STAR 아날로그 | 호출 전용 초인종 |
| IP-200PCHB | 비상 버튼 1개와 위쪽 램프 | KOCOM BUS 디지털 | 호출 전용 초인종 |
| DP-202H | 열쇠 버튼 1개와 위쪽 램프 | 연결 기능 없음 | 도어폰·도어카메라 |

## PC·PCHB 경비 통화와 비상

PC·PCHB는 대기 중 수화기를 들면 연결된 경비실을 바로 호출합니다. 경비실에서 세대를 호출하면 수화기를 들어 응답하며 내려놓으면 통화가 종료됩니다. STAR와 BUS는 서로 연결할 수 없습니다.

PC는 STAR 링크 도구로 아날로그 경비실에 연결하고 세대에서 동·호수를 설정합니다. PCHB는 KOCOM BUS 경비실기 AM-10KP·KAM-305에 연결하며 IP-203APB처럼 번호를 경비실에서 등록합니다.

PCHB의 사진에 있는 유일한 버튼은 비상 버튼으로 구현했습니다. 수화기가 놓인 상태에서도 누르면 경비실에 비상 알림을 보내고 다시 누르면 해제합니다. PC에는 비상 기능과 버튼이 없습니다. 두 제품에는 현관·경비 선택 버튼과 부재 버튼 동작을 제공하지 않습니다.

## 호출 전용 초인종

새 아이템/블록 ID는 `qwertys_homenet:doorbell`이며 모드의 크리에이티브 탭에 있습니다. 벽에 설치한 뒤 홈 링크 도구로 PC 또는 PCHB를 선택하고 초인종을 클릭해 연결합니다. 다시 클릭하면 해당 연결을 해제합니다. 초인종 하나에 64블록 이내의 최대 32대 PC·PCHB를 연결할 수 있습니다.

초인종을 누르면 연결된 내부 인터폰에서 딩동 2타가 울립니다. 초인종은 음성 통화 기기가 아니며, 내부 인터폰에 통화 회선을 만들지 않습니다. 초인종과의 통화·메시지 송수신은 불가능합니다. 경비실 통화 중에도 초인종은 호출음만 별도로 울립니다.

PC·PCHB는 도어폰·도어카메라 연결을 거부하고 해당 기기의 호출도 받지 않습니다. 초인종이 울린 뒤 수화기를 들면 초인종에 응답하는 대신 경비실을 호출합니다. 초인종의 연결 대상은 저장되고 회수 후에도 유지됩니다.

## DP-202H 열쇠 버튼

DP는 STAR·BUS를 포함한 모든 경비실 연결을 거부합니다. 수화기를 들기만 해서는 경비실을 호출하지 않으며 비상 알림도 없습니다.

문 링크 도구로 DP와 실제 문을 연결합니다. 열쇠 버튼은 수화기를 들지 않은 대기 상태에서도 연결된 문을 엽니다. 기존 문 제어 방식에 따라 약 3초 뒤 자동으로 닫힙니다. 연결된 도어폰·도어카메라와 현관 통화 중 눌러도 문을 열 수 있습니다.

H 수화기, PCHB의 E 비상, DP의 O 열쇠를 사용할 수 있습니다. PC에는 클릭 가능한 호출/선택 버튼이 없고 PCHB·DP에는 큰 버튼 하나만 있습니다. 조작 화면도 해당 모델의 버튼만 동작합니다. DP에는 동·호수와 경비실 번호 등록란을 제공하지 않습니다.

사진이나 게임 스크린샷은 생성하지 않았습니다.
