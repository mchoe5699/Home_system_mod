# 삼성 SHT-5500S 경비실기 · 외형 모델

크리에이티브 HomeNet 탭의 **삼성 SHT-5500S 경비실기** 또는 `/give @s qwertys_homenet:sht_5500s`로 설치합니다.

사진을 기준으로 가로 **0.8블록**, 앞뒤 약 **0.52블록**, 높이 약 **0.30블록**의 탁상형 비율을 적용했습니다. 새 제품 상태의 밝은 회백색 본체, 왼쪽 수화기와 받침, 측면 통풍구, 경사진 검은 표시판, 녹색 LCD, 경보·상태 표시창, 8개 기능키, 18개 단축키, 12개 숫자키와 제어키를 입체 부품으로 구성했습니다. 선·스티커·낙서·오염은 포함하지 않습니다.

현재는 **외형만 구현**했습니다. LCD 내용, 통화·경보·문열림·키 동작은 추가 설명에 맞춰 후속 구현합니다. 기존 KOCOM 기기의 통신 규격을 임의로 적용하지 않으며, 검색·호출 대상에도 등록되지 않습니다. 현재 표시창과 램프는 외형 표현이며 동작 상태를 나타내지 않습니다. 우클릭은 외형 모델 안내만 표시합니다.

기존 제품 로고 편집 도구로 클릭하면 **기본 SAMSUNG / 숨김 / 직접 문구 / 리소스팩 이미지**를 선택할 수 있습니다. 로고 설정은 월드 저장·불러오기와 이동 후에도 유지됩니다. 인벤토리 아이콘은 기본 제품 외형을 표시합니다.

**제품 이동 도구**로 이동량과 방향을 지정합니다. 원래 블록의 경계를 넘어 이동할 수 있고, 수화기·본체·로고·선택 영역이 함께 이동합니다. 이동 중 다른 블록을 덮어쓰거나 벽과 겹치지는 않습니다. [이동 도구 안내](device-mover.md).

검증: `python3 tools/check_sht5500s_assets.py`, `gradle -I tools/kvm_checks.gradle kvmChecks build`, 별도 SHT/이동 서버 GameTest. 게임 화면 이미지나 작동 예시 이미지는 생성하지 않습니다.

비율 보정: 검은 표시판의 가로·세로를 약 3.1:1로 조정하고 본체 뒤쪽에 배치했습니다. 기능키 아래의 불필요한 간격을 줄이고 숫자키를 작은 3×4 배열로 재배치했으며, 단축키 이름표와 입체 버튼이 같은 좌표를 사용하도록 맞췄습니다. 수화기 길이와 받침, 로고 위치, 선택 영역도 변경된 본체에 맞췄습니다.

오른쪽의 문열림 버튼 아래 버튼은 **문닫힘**입니다. 버튼 표기를 이에 맞춰 수정했으며, 동작 구현은 후속 사양에 따릅니다.
