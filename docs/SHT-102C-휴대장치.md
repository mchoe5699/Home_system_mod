# 삼성 홈오토메이션 공통 휴대장치와 충전기

SHT-102C 설명서 6~10쪽의 별도 휴대장치와 충전기를 추가했습니다. 긴 안테나, 둥근 상단 스피커, 통화·내선 키, 숫자 키패드, 재발신/포즈·메모리·재다이얼, 현관·경비실·온후크 키를 별도의 형상과 조작화면으로 만듭니다. SHT-102C 본체의 유선 수화기와 SHT-101C 무선수화기는 그대로 유지합니다.

## 크기와 배치

충전기에 휴대장치를 거치한 전체 설치 면적은 **가로 0.4 × 깊이 0.4블록**입니다. 안테나를 포함한 높이는 설명서의 비율에 맞춘 약 0.90블록이며, 휴대장치는 충전기에 뒤로 약 10도 기울여 거치합니다. 충전기는 평평한 바닥 위에 놓고 네 방향으로 설치할 수 있습니다. 둥근 충전기 외곽, 낮은 앞쪽과 높은 뒤쪽, 수화기·예비 배터리 홈, 충전 표시등을 표현합니다. 전원선은 만들지 않습니다. 예비 배터리 홈은 외형 표현입니다.

## 등록과 사용

1. 삼성 크리에이티브 탭 또는 본체의 **휴대장치 받기**로 장치를 구합니다. 받기 버튼은 미연결 장치를 지급하며 자동 등록하지 않습니다.
2. 충전기를 설치하고 장치를 든 채 클릭해 거치합니다. **홈링커로 무선 지원 삼성 세대내 기기를 선택한 뒤 휴대장치가 놓인 충전기를 클릭**하면 연결됩니다. 충전기를 먼저 선택하고 내부기기를 클릭해도 됩니다. 같은 연결을 다시 클릭하면 해제되며, 연결할 휴대장치를 교체할 때에는 홈링커를 들고 웅크려 클릭합니다.
3. 연결 대상은 모델명이 아니라 삼성 제조사·세대내 기기 종류(비디오폰/월패드/인터폰)·무선 지원 여부로 판정합니다. 현재 구현된 무선 지원 본체 SHT-101C와 SHT-102C에서 공통으로 동작합니다. 외형 전용 SHT-5500S나 무선 미지원 기기는 연결 대상이 아닙니다. 기존 SHT-101C의 본체 수화기와 공통 휴대장치는 서로 다른 등록을 사용합니다.
4. 빈손으로 충전기를 클릭하면 휴대장치를 들고, 장치를 손에 들고 빈 공간을 우클릭하면 전용 조작화면이 열립니다. 웅크리고 우클릭하면 전원을 켜거나 끕니다. 착신 또는 본체 내선 호출 중 충전기에서 들면 자동 응답하며 거치 중에도 벨과 통화 램프가 반응합니다.

본체 한 대에 공통 휴대장치 하나를 연결합니다. 홈링커의 기존 세대내 기기↔세대현관 도어카메라/도어폰 연결 기능은 유지합니다. 휴대장치 자체로 본체를 클릭하는 종전의 직접 등록은 홈링커 연결 안내로 바꿨습니다.

## 통화

- **통화:** 현관·공동현관·경비실·전화 착신에 응답하거나 통화를 종료합니다.
- **현관:** 연결된 현관 장치와 통화합니다. 현관·공동현관 통화 중에는 문을 엽니다. 휴대장치에는 비디오 화면을 만들지 않습니다.
- **경비실:** 본체의 BUS/STAR 방식에 맞는 경비실을 호출합니다.
- **온후크:** 전화 발신 상태로 전환합니다. 번호를 입력하고 `#`을 누르거나 잠시 기다리면 게임 내 전화번호로 발신합니다. 실제 전화망에는 연결하지 않습니다.
- **메모리:** 대기 중 메모리 → 단축키 → 번호 → 메모리로 휴대장치 전용 번호를 저장합니다. 발신 상태에서 메모리 → 단축키로 호출합니다. 재다이얼은 마지막 발신 번호입니다.
- **재발신/포즈:** 번호 입력 중 발신 대기를 늘리고, 연결된 국선 통화에서는 보류/재통화를 전환합니다. 실제 통신사의 재발신·통화대기 서비스는 연결하지 않습니다.
- **내선:** 본체와 휴대장치를 서로 호출합니다. SHT-102C 본체는 유선 수화기를 들어 응답하고, SHT-101C는 본체 스피커 또는 원래 수화기의 통화 버튼으로 응답하며 휴대장치는 통화 키 또는 충전기에서 들기로 응답합니다. 양쪽에서 채팅 통화를 할 수 있습니다.
- **통화 전환:** 외부 통화 중 현재 통화하는 쪽에서 내선을 누릅니다. 휴대장치 쪽으로 넘길 때에는 휴대장치에서 통화를 누르거나 충전기에서 듭니다. 본체 쪽으로 넘길 때에는 해당 본체의 수화기/통화 버튼으로 응답합니다. 전환 대기 중에도 외부 연결을 보존하며, 받지 않으면 30초 뒤 원래 통화로 돌아갑니다. 전환 요청이 없으면 다른 수화기가 진행 중인 통화를 가져갈 수 없습니다.

휴대장치를 충전기에 돌려놓으면 해당 장치의 통화가 끝납니다. 본체로 통화 전환을 요청한 상태에서는 거치해도 상대 연결을 유지합니다. 반대로 유선 수화기를 걸어도 휴대장치로 넘긴 통화는 유지됩니다.

## SHT-102C BUS 공동현관 문열림

SHT-102C는 STAR/BUS 두 방식을 지원하며 동·호는 두 방식 모두 직접 설정합니다. 호환되는 BUS 공동현관기에서 호출이 오면 유선 수화기를 들어 통화한 뒤 본체 다이얼의 `*`을 누르면 해당 공동현관기에 연결된 문이 열립니다. 공통 휴대장치에서 응답한 경우에도 `*`으로 열 수 있습니다. 착신 응답 전이나 공동현관 통화가 아닌 상태에서는 이 단축 문열림을 실행하지 않습니다. STAR는 기존 현관 버튼 문열림을 유지합니다.

## 배터리와 통신 범위

충전 시간은 게임용으로 축약하여 완전 방전부터 약 5분, 전원 ON 사용 시간은 약 30분입니다. 꺼져 있어도 충전됩니다. 조작화면에 전원과 배터리 잔량을 표시합니다. 통화 중 전원·배터리·통신 조건이 끊기면 휴대장치 통화도 종료됩니다.

통신은 같은 차원의 **같은 단지, 본체에서 32블록 이내**로 제한합니다. 유효한 등록 장치를 실제 인벤토리나 보조 손에 가지고 있어야 조작할 수 있습니다. 본체의 원래 수화기와 공통 휴대장치는 각각의 등록으로 조작하며 다른 본체의 장치로 대신 조작할 수 없습니다. 충전기에는 장치의 등록과 배터리 상태가 저장되며 들기·거치로 복제되지 않습니다.

배포 파일은 버전 없는 `qwertys_homenet.jar` 하나입니다. 기존 JAR를 제거하고 서버·클라이언트 모두 교체한 뒤 재시작하세요.

## 검증

서버 기능 검사 31개를 통과했습니다. 홈링커 양방향 선택·연결/해제, 삼성 공통 휴대장치 제어, SHT-102C BUS 공동현관의 실제 문열림도 확인했습니다. 휴대장치 등록·식별·영속 저장, 전원·배터리·보조 손·거리·단지 제한, 본체/휴대장치 내선 양방향, 국선 통화 전환 양방향, 현관·경비실 통화, 충전기 배터리 증가와 들기/거치 시 복제 방지, 거치 중 착신 표시와 들기 자동 응답을 검사했습니다. 기존 유선 본체 및 SHT-101C 검사도 함께 통과했습니다.

실제 클라이언트에서 홈링커로 SHT-101C/SHT-102C에 휴대장치를 연결한 뒤 별도 조작화면의 20개 키와 한글 통화, 충전기 거치/들기 상태 패킷을 검사했습니다. 렌더링된 거치 모델의 설치 면적 0.4 × 0.4블록과 설명서 비율의 높이를 실제 정점에서 확인했습니다. 기존 18종 본체의 착신 영상 검사도 통과했습니다. 게임 화면 이미지나 스크린샷은 만들지 않았습니다.
