# IP-203APB BUS 인터폰

첨부 IP-203APB 사용·설치 설명서와 정면/HEIC 측면 사진을 기준으로 제작했습니다. 설치판은 포함하지 않습니다. 본체와 송수화기는 흰색이며, 가장 긴 높이를 0.4블록으로 맞췄습니다. 설명서 규격 108×218×80mm의 비율에 따라 가로 약 0.19816블록, 높이 0.4블록, 두께 약 0.14679블록입니다. 두께에는 걸어둔 송수화기가 포함됩니다.

## 연결과 세대번호 등록

- 코콤 BUS 전용 제품입니다. BUS 링커로 AM-10KP 또는 KAM-305에 연결합니다.
- 세대번호를 인터폰에서 직접 변경할 수 없습니다. 링커 연결 시 초기 번호가 배정되고, 이후 경비실기에서 동·호수를 등록합니다.
- AM-10KP: 세대에서 수화기를 들어 경비실을 호출 → 경비실에서 응답 → `**00*` → 동 번호 → `부재/동` → 호 번호 → `*`.
- KAM-305: 세대 발신 통화에 응답한 상태에서 관리자 → 세대번호 등록 메뉴로 들어가 동·호수와 관할 경비실 번호를 입력합니다. 초기 관리자 비밀번호가 미설정이면 바로 관리자 메뉴에 들어갑니다.
- 전원은 연결된 경비실기의 전원 공급 상태를 따릅니다. 경비실기 전원을 끄면 인터폰의 통화도 종료됩니다.

## 설명서의 조작

- 송수화기를 들면 경비실이 자동으로 호출됩니다. 경비실에서 세대를 호출한 경우에는 수화기를 들어 응답합니다.
- 현관 호출음은 딩동 2타, 경비실 호출음은 멜로디입니다.
- 경비실 통화 중 방문자가 현관을 호출해도 경비실 통화를 유지합니다. **현관 버튼**을 눌러 방문자와 통화하고, **경비 버튼**을 누르면 경비실과 통화를 계속할 수 있습니다.
- 수화기를 내려놓으면 현재 통화와 보류 중인 통화를 모두 종료합니다.
- 현관 버튼과 경비 버튼을 동시에 누르면 부재 설정을 전환합니다. 화면에서 **F와 G를 함께 누른 상태**로 같은 조작을 할 수 있습니다. 독립적인 부재 버튼은 만들지 않았습니다.
- 비상 버튼은 연결된 경비실기에 비상을 통보합니다. 다시 눌러 해제하면 경비실기에도 해제가 전달됩니다.
- 음량 조절: 본체 왼쪽 윗측면 또는 V. 수화기: H, 비상: E, 현관: F, 경비: G. 통화 중 하단 메시지 입력은 기존 모드의 대화 기능입니다.
- 이 제품에는 화면, 번호 다이얼, 문열림 버튼을 추가하지 않았습니다.

## 현재 제품의 로고 변경

제품 디자인/로고 도구로 AM-10KP, KAM-305, IP-203APB 및 기존 수신기·현관 호출기의 로고를 설정합니다. KVM 시리즈는 일반 클릭하면 기존 디자인 편집기가 열리고, **웅크린 채 도구로 클릭하면 공통 로고 편집기**가 열립니다.

로고 방식은 `default`(기본), `none`(숨김), `text`(문구), `custom`(리소스팩 PNG)입니다. 예: `mypack:textures/logos/my_logo.png`. 리소스팩은 사용하는 클라이언트에 설치해야 합니다. 로고는 저장되며, 제품을 아이템으로 회수할 때도 유지됩니다. 로고를 바꿔도 제품 모델, 제조사 호환성, BUS 방식은 바뀌지 않습니다. 향후 수신기와 호출기는 같은 공통 로고 설정을 재사용합니다.

## 외형과 동작 확인

수화기를 걸었을 때는 사진처럼 송수화기가 본체 왼쪽 가장자리에 가깝게 놓이고, 오른쪽에 사선 스피커 슬롯 9개, 전원등, 비상버튼, 현관·경비 버튼과 세 개의 표시등이 이어집니다. 본체의 상단 모서리와 둥근 하단, 송수화기의 좁아지는 손잡이·두꺼운 양 끝·옆면 접합선은 정면과 사선 사진을 함께 기준으로 만들었습니다. 수화기를 들면 상단 걸쇠 자리와 얇은 후크, 긴 안쪽 받침과 하단 받침턱이 게임 모델과 조작 화면에 드러납니다. 설치판은 제품 외형에서 제외했습니다.

설명서의 경비실 통화 중 현관 호출 동작을 확인했습니다. 경비실 통화를 유지하면서 현관 딩동 2타가 들리고, 현관 버튼으로 방문자와 통화한 뒤 경비 버튼으로 경비실 통화를 계속합니다. 조작 화면 아래에는 실제 통화·부재·비상 상태와 음량이 표시되며, 기기 자체에는 별도 화면이나 독립 부재 버튼이 없습니다.
