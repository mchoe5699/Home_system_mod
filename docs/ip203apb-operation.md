# KOCOM IP-203APB BUS 인터폰

IP-203AP의 본체·수화기·받침·하단 곡선과 세로 0.4블록, 가로 0.176블록 크기를 공유합니다. 앞쪽 플라스틱은 흰색, 벽 쪽 뒤판은 회색입니다. 사진의 설치판·코일선·전선은 제외합니다. 비상 버튼은 큰 원형, 현관·경비 버튼은 같은 크기의 작은 원형이며 전원·현관·부재·경비 표시를 제공합니다.

## 설명서에서 확인한 기능

첨부 IP-203APB.pdf의 사용방법과 제품사양을 근거로 BUS 디지털 경비실 통화, 현관 딩동 2타·경비 멜로디, 수화기 들기 자동 경비 호출, 방문자 호출 중 현관 버튼 전환과 경비 버튼 복귀를 적용했습니다. 수화기를 내려놓으면 통화가 종료됩니다. 현관·경비 버튼을 동시에 누르면 부재 상태가 설정되고 경비실기에서 확인할 수 있습니다.

PDF에는 비상 통보 기능이 명시되어 있으나 해제 절차는 설명하지 않습니다. 게임에서는 기존 KVM 제품과 동일하게 비상 버튼을 누르면 경비실에 통보하고 다시 누르면 해제합니다. 부재 동시 누름도 다시 수행하면 해제됩니다. 부재 설정은 경비실 표시 기능이며 설명서에 없는 자동 현관 통화 전환 기능은 추가하지 않았습니다.

## 연결과 동·호수

제품 ID는 `qwertys_homenet:ip_203apb`입니다. KOCOM BUS 경비실기 AM-10KP·KAM-305와 호환됩니다. 링크 도구로 세대를 선택하고 웅크린 상태에서 호환 경비실기를 클릭합니다. STAR 아날로그 경비실기는 연결할 수 없습니다.

동·호수 등록은 KVM-933과 동일합니다. 연결 시 초기 번호를 부여하고 이후 번호 변경은 연결된 디지털 경비실에서 수행합니다. 세대 조작 화면은 번호를 표시하며 직접 변경할 수 없습니다. AM-10KP에서는 세대와 통화 중 `**00*`, 동 번호, 동 버튼, 호 번호, `*` 순서로 등록합니다. KAM-305에서는 해당 경비실기의 기존 번호 등록 화면을 사용합니다.

## 조작 화면

두 모델 모두 왼쪽 기기 그림과 오른쪽 설정 패널을 사용합니다. 수화기와 실제 버튼을 클릭할 수 있고 호출 음량 및 통화 메시지 입력을 제공합니다. IP-203AP만 세대 번호 저장이 가능합니다.

- H: 수화기 들기/내려놓기
- F: 현관 통화, G: 경비 통화
- E: APB 비상 통보/해제
- F와 G를 함께 누르기: APB 부재 설정/해제
- APB의 현관 또는 경비 버튼을 Shift와 함께 클릭하거나 설정 영역의 ‘현관 + 경비 동시 누름’을 눌러도 두 버튼의 동시 누름을 전달합니다.

비상·부재·음량·번호·로고는 저장됩니다. 수화기 들림과 진행 중인 통화는 재접속 시 초기화합니다. 표시등과 수화기 상태는 설치 모델과 조작 화면에 동기화됩니다. 사진·스크린샷은 생성하지 않았습니다.

버튼부 외형을 실물 사진에 맞춰 압축했습니다. 비상 버튼 중심, 작은 두 버튼·표시등·부재 괄호·로고 간격을 조정하고 패널 하단을 올려 길게 비던 공간을 줄였습니다. 설치 모델·아이템·조작 화면에 같은 배치를 적용했습니다. [형제 모델 KIP-234R2](kip234r2-operation.md)는 열쇠·버튼 배치와 통화·부재 동작이 다릅니다.
