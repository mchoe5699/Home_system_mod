# 삼성 HT-512 디지털 로비폰 (BUS)

첫 번째 참고 사진을 색상·배치의 기준으로 삼은 외형 모델입니다. 다른 방향의 사진은 얇은 테두리와 전면판·표시창·버튼·카드 슬롯의 깊이를 판단하는 데 사용합니다. 호출·통화·문열림·카드 인증 동작은 추후 사양에 따라 추가하며 현재 구현에는 포함하지 않습니다.

삼성 홈오토메이션 크리에이티브 탭에서 **삼성 HT-512 디지털 로비폰 (BUS)**를 꺼내 벽에 설치합니다. 네 방향 설치, 기기 이동 도구의 미세 이동·블록 간 이동, 아이템 표시와 파괴 시 드롭을 지원합니다. 본체를 우클릭하면 외형 확인 화면이 열립니다. **사용법**에서 현재 구현 범위를 확인하고 Esc로 닫습니다.

## 사진 기준 치수와 형태

- 사진을 정면 보정한 외곽 비율: 가로 464 : 세로 610.
- 높이: 기존 KLP-203 모델 원본 외곽 높이와 같은 약 **0.583333블록**. 폭은 사진 비율에 따라 약 **0.443716블록**입니다.
- 따뜻한 샴페인 금색의 미세한 입자 표면, 네 모서리의 사선 접합이 있는 얇은 경사 테두리, 안쪽 판과의 가는 경계선을 재현합니다.
- 긴 검은 표시창의 보라색 카메라 창·원형 렌즈, 통화중/문열림 표시, 붉은 4자리 숫자 외관을 배치합니다. 표시 내용은 사진 외관이며 실제 통화·문 상태를 나타내지 않습니다.
- 왼쪽의 9열 × 11행 원형 스피커 구멍은 깊이가 있는 실제 메시 구멍입니다.
- 청회색 숫자키 12개와 경비실·호출 키 2개는 같은 돌출 높이를 사용합니다. 검은 키 소켓·밝은 가장자리·약간 볼록한 전면·흰 글자를 구분합니다.
- 아래 카드 구역은 전면판과 분리된 테두리, 움푹한 가로 투입구, CARD 화살표를 갖습니다. 사용법 인쇄와 SAMSUNG 로고도 첫 사진의 위치를 따릅니다.

공유 메시 캐시를 사용하고 서버 주기 갱신은 하지 않습니다. 불투명 벽에 완전히 가려지면 렌더링을 생략합니다. 기존 제품의 클래스나 통신 기능을 교체하지 않습니다.

생성 스크립트: `python tools/sht/ht512.py`. 원본 KLP-203 리소스의 실제 높이를 읽어 치수를 기록합니다. 제품 텍스처만 생성하며 게임 화면·스크린샷은 생성하지 않습니다.

## 검증

실제 Forge 클라이언트에서 KLP-203 원본 높이와 비율, 99개 구멍의 개방 깊이, 카드 슬롯 깊이, 14개 키의 같은 돌출 높이, 메시 캐시 재사용을 검사했습니다. 네 방향의 모델·클릭 영역, 실제 블록 우클릭, 사용법 창, 크리에이티브 아이템 렌더 경로도 통과했습니다. 게임 화면 캡처는 하지 않았습니다.

서버 검사 39개와 등록 기기 45종의 미세 이동·블록 경계 이동이 통과했습니다. HT-512가 통화 기기로 잘못 등록되거나 주기 작업을 수행하지 않는 것도 검사합니다. 기존 제품 클래스 239개는 배포 시 원본 바이트를 보존합니다.

## 버튼 재디자인 — 1.0.31

실물 첫 사진을 외곽 모서리로 정면 보정한 좌표와 설치 화면을 비교했습니다. 이전 숫자 버튼의 검은 외곽은 약 29.5×29.5, 새 외곽은 26×28입니다(제품 전체 기준 좌표 464×610). 버튼 묶음을 왼쪽·위로 이동하고, 가로 틈은 1.5에서 5, 세로 틈은 1.5에서 3.5로 조정했습니다. 경비실·호출 키는 같은 높이에서 아래 열에 재정렬하고 사이를 6.5만큼 띄웠습니다.

두꺼운 밝은 테두리를 폭 0.7의 가는 은회색 선으로 바꾸고 모서리를 덜 둥글게 했습니다. 버튼 면은 더 푸른 청색으로, 숫자는 굵은 흰색 산세리프로, *는 중앙의 여섯 갈래 표시로 수정했습니다. 버튼 테두리·좌표 정의를 텍스처 생성과 실제 3D 메시가 공유합니다.

외부 틀·전체 치수·표시창·스피커·카드 부분과 본체 인쇄는 유지합니다. 버튼 및 취소 글자 주변을 제외한 텍스처 픽셀이 이전 배포본과 같은 것도 확인했습니다. 기능은 계속 외형 전용입니다.

이번 수정은 실제 클라이언트에서 버튼 사이의 전면판이 드러나는지, 아래 키 간격과 테두리 폭, 같은 돌출 높이, 네 방향 설치·아이템·사용법 표시를 검사했습니다. 기존 영상·통화·휴대장치·공통 이동 클라이언트 검사도 통과했습니다.

## 검은 패널 중심 정렬 — 1.0.32

이전 검은 패널은 x=78부터 402까지여서 중심이 240이었고, 제품 외곽의 중심 232보다 오른쪽으로 8만큼 치우쳤습니다. 좌우 경계를 70과 394로 옮겨 두 여백을 같게 맞췄습니다. 렌즈·보라색 창·램프·숫자 세그먼트·표시 글자와 실제 메시의 개구부를 함께 이동합니다. 패널 내부 이미지가 그대로 8만큼 이동하고 다른 텍스처 픽셀이 유지되는지 확인했습니다.
