# 새 HA-4100H 외형 모델

기존 HA-4100H의 모델·동작 코드·조작 화면을 제거하고, 이번에 제공한 다섯 사진으로 외형을 새로 제작했습니다. 기능은 추후 자료를 받은 뒤 구현합니다. 기존 PDF의 동작을 이번 모델에 적용하지 않았습니다.

- 크기: 세 번째 정면 사진 기준 **가로 0.5 × 세로 약 0.3916블록**. 케이싱 좌표는 모델 파일의 소수점 네 자리 정밀도로 저장합니다.
- 색상: 흰색. 사진의 변색·스티커·때와 외부 선은 포함하지 않습니다.
- 본체: 좌우 세로 테두리, 수화기 받침, 중앙 제어판, 오른쪽 모니터 케이스의 분할과 이음매를 별도로 구성했습니다.
- 수화기: 넓은 위·아래 단면, 완만한 허리, 말린 가장자리와 볼록한 전면을 실제 곡면 단면으로 만들었습니다. 받침 홈과 걸림 부분도 별도 요소입니다.
- 버튼: 검은 타원형 12개 숫자키, 위쪽 3개와 아래쪽 6개 회색 기능키, 큰 원형 비상키를 분리했습니다. 글씨·아이콘은 두 번째 확대 사진을 기준으로 작성했고, 버튼 높이와 상단 반사·하단 그늘을 구분했습니다.
- 모니터: 둥근 검은 외곽, 깊은 내부 경사, 곡면 CRT의 꺼진 화면을 구성했습니다. 명암·밝기 슬라이더와 점 표기도 재현했습니다.

아이템 식별자는 `qwertys_homenet:ha_4100h`로 유지해 기존 설치 위치의 제품도 새 외형으로 교체합니다. 이전 기기의 통화·경보·등록 데이터는 새 외형 기기에서 사용하지 않으며, 로드될 때 기존 통신 기기 목록에서 제거합니다. 새 모델은 수신기나 경비실 연결 대상으로 등록되지 않습니다.

검증: `python3 tools/check_ha4100h_assets.py`로 크기·UV·리소스·곡면 키·실제 CRT/수화기 파임과 기존 조작 화면 제거를 확인합니다. 작동 예시 이미지나 게임 캡처는 생성하지 않습니다.
