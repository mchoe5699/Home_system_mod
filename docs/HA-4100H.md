# 현대 HA-4100H

흰색 현대 디지털 BUS 홈오토메이션입니다. 두 번째 정면 사진의 비율에 맞춘 본체는 **가로 0.5 × 세로 0.390625블록**입니다. 수화기·중앙 조작부·오른쪽 모니터 케이스를 분리하고, 수화기의 볼록한 단면과 받침, 조작판 단차, CRT의 파임, 타원형 숫자키와 작은 회색 버튼을 실제 모델 요소로 구성했습니다. 선·노후화·스티커는 포함하지 않습니다.

크리에이티브 탭의 `현대 HA-4100H 디지털 홈오토메이션` 또는 `/give @s qwertys_homenet:ha_4100h`로 설치합니다. 기존 이동 도구와 로고 편집을 지원합니다. 이 제품은 독립 모델이므로 다른 제품의 형제 선택기에 넣지 않습니다.

## 연동과 세대 번호

경비실 링크 도구로 **같은 단지의 현대 HMC-7000**에 연결합니다. KOCOM BUS나 삼성 장비와는 통신하지 않습니다. 단지 구획 밖·서로 다른 단지 간 연결은 차단하며, 하나로 묶인 구획은 기존 단지 규칙대로 연동합니다. 통화 중 구획을 분리하면 통신도 끊깁니다.

동·호 번호의 기기 자체 설정은 없습니다. 관리실/현관을 누르고 수화기를 들어 HMC-7000을 호출한 뒤, 경비실에서 응답합니다. HMC-7000의 `* → 동 → 동 버튼 → 호 → 동 버튼 → 로비 번호 두 자리 → #` 순서로 번호를 변경합니다. 초기 연결 시 임시 번호를 할당하는 기존 경비실 링크 동작은 유지합니다.

## 통화·모니터·문열림

- 수화기 클릭 또는 H: 들기/놓기. 관리실/현관을 먼저 선택하면 관리실을 호출합니다. 수신 중 들면 응답합니다.
- 도어폰: 연결된 세대 현관 카메라를 최대 90초 확인합니다. 다시 누르면 모니터를 끕니다.
- 관리실/현관과 도어폰 호출은 약 30초 울리며, 두 카메라가 동시에 부르면 공동현관 영상이 우선입니다. 도어폰을 선택하고 수화기를 들면 세대 현관 쪽에 응답합니다.
- 문열림: 연결된 세대 문을 열고, 공동현관 통화 중이면 해당 로비폰의 문열림도 전달합니다. 문열림 표시는 1초 켜집니다.
- 모니터는 **흑백**입니다. 컬러 로비폰이 송출하더라도 `VideoFormat.MONOCHROME`으로 표시합니다. 명암·밝기 슬라이더를 클릭해 각각 5단계로 조절합니다.
- 외출/메세지: 외출·방범 감시를 켜거나 끕니다. 관리실의 연락 메시지가 있으면 램프가 깜박이고, 버튼을 누르면 표시를 해제합니다.

## 전화·번호 기억

전화 통화는 BUS 통화와 별도 세션입니다. 게임 내 같은 단지 HA-4100H끼리 등록한 우리집 전화번호로 연결합니다. 실제 외부 전화망을 사용하지 않습니다.

수화기를 놓은 상태에서 `1·2·3·6 중 선택 → * → 전화번호 → #`로 통보1·통보2·통보3·우리집 번호를 기억합니다. 번호는 4~15자리이며 빈 번호는 삭제합니다. 같은 단지의 우리집 번호 중복은 거부합니다. `종류 → 0`으로 기억 번호를 확인하며, 입력은 10초 뒤 취소되고 호출·경보·수화기 들기에도 취소됩니다. 확인 내용은 게임 조작 화면의 상태줄에 표시합니다.

수화기를 들거나 전화/보류를 눌러 숫자를 입력합니다. `#` 또는 마지막 숫자 뒤 잠시 기다리면 전화를 겁니다. 온후크 다이얼로 발신한 뒤 상대가 받으면 수화기를 들어 통화합니다. 전화/보류는 통화 보류·해제를 수행하며, 보류 중 수화기를 놓아도 연결은 유지하고 다시 들면 복귀합니다. 재다이얼은 마지막 발신 번호를 사용합니다. 통화 메시지는 조작 화면 아래에서 전송합니다.

## 경보

실물 PDF의 시험 순서는 `시험(화재) → 정지/복귀(음소거) → 시험(가스) → 정지/복귀 → 정지/복귀(종료)`입니다. 시험은 실제 경비실 경보로 전달하지 않습니다. 실경보는 시험과 번호 입력을 중단합니다.

비상 버튼은 조작 화면에서 1초 이상 누른 뒤 놓으면 켜거나 끕니다. 방범/외출로 감시를 설정합니다. 방범은 초기 1분 동안 표시만 하고 이후 소리를 내며, 비상·방범·카메라 도난 경보음은 15분으로 제한합니다. 화재·가스는 감지 입력이 사라진 뒤 정지/복귀로 복귀할 수 있습니다. 연결했던 카메라가 사라지면 도난 경보가 발생합니다.

게임 내 감지기 접점은 본체 아래쪽 레드스톤=화재, 기기 방향의 시계 방향 이웃=가스, 반시계 방향 이웃=방범입니다. 감지 신호가 켜지면 해당 경보가 유지됩니다. 별도의 외부 기기 통신 없이 본체의 인접 입력을 읽습니다. 서버 연동용 `setSensor(type, active)`도 제공합니다.

실경보는 같은 단지에 연결된 HMC-7000에 종류별로 전달합니다. 통보 번호를 기억했다면 첫 30초 뒤 순서대로 전화를 시도하고, 최대 9회 시도·3회 성공 시 종료합니다. 응답한 통보처에는 경보 내용과 경보음을 전달합니다. 본체 수화기를 들거나 경보가 해제되면 자동 통보를 멈춥니다. 실제 녹음 음성 및 숫자 읽기는 게임의 상태 문구와 기본 경보음으로 표현합니다.

각 기능의 점등·점멸은 조작 화면과 설치 모델에 동기화합니다. 본체 오른쪽 아래 전원 표시 부근을 누르면 전원을 전환하고 통화·모니터를 종료합니다.
