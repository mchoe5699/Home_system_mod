# 현대 HA-4100H — 설명서 기반 동작

첨부된 HA-4100H 사용설명서의 조작 순서·표시·시간 제한을 적용했습니다. 기존 사진 기반 흰색 외형, 가로 0.5 × 세로 0.392블록, 수화기·버튼 곡면, 평평하게 들어간 비상 버튼과 로고 편집은 유지합니다. 작동 예시 이미지나 게임 캡처는 생성하지 않습니다.

설치된 제품을 우클릭하면 제품과 같은 배치의 조작 화면을 엽니다. 각 버튼·수화기를 직접 클릭합니다. H는 수화기를 들거나 놓고, 숫자·`*`·`#`는 키보드로도 입력합니다. 비상 버튼은 마우스로 **1초 이상 누릅니다**. 화면 아래 입력란은 연결된 상대에게 보낼 통화 메시지입니다. 화면 아래 전원·음량·등록·로고 버튼은 게임의 보조 설정입니다.

## 연동·세대 번호·로고

**전용 경비실 링크 도구**로 연결합니다(서서 HA-4100H 선택 → 웅크리고 HMC-7000 클릭). 홈 링커는 경비실 연결에 사용하지 않습니다. 같은 단지의 **현대 디지털 BUS HMC-7000**에 연결합니다. 제조사가 다른 BUS 경비실기는 연결할 수 없습니다. 서로 다른 단지·구획 밖의 기기와 통신·등록·영상 전달·문열림·경보 전달을 하지 않습니다. 여러 구획을 하나의 단지로 묶었을 때는 기존 단지 규칙을 따릅니다. 통화 중 구획을 분리하면 연결도 종료됩니다. 연결이 실패하면 단지 대시보드에서 두 기기가 구획 안에 있는지 확인하세요. 구획 밖 기기는 연결되지 않으며, 홈 링커는 이를 연결 실패로 표시합니다.

동·호 번호는 HA-4100H 자체에서 입력하지 않습니다. 최초 링크 시 기존 도구가 임시 세대번호를 배정합니다. 이후 `관리실/현관 → 수화기 들기`로 경비실을 호출하거나 보조 설정의 세대 등록을 선택합니다. HMC-7000에서 응답한 뒤 `* → 동 번호 → 동 버튼 → 호 번호 → 동 버튼 → 로비 번호 두 자리 → #`로 번호를 저장합니다.

로고 편집은 공통 편집기에서 기본 HYUNDAI·숨김·사용자 글자·리소스팩 텍스처를 선택합니다. 본체의 세 로고에 반영하며 로고를 바꿔도 제조사 통신 규격은 HYUNDAI입니다. 공통 이동 도구도 지원합니다.

## 관리실·공동현관·도어폰

- **관리실/현관:** 버튼을 선택하고 수화기를 들어 경비실을 호출합니다. 수신 시 이 버튼의 램프가 깜박이고 응답하면 켜집니다. 관리실 통화는 최대 3분입니다.
- **공동현관:** 로비폰에서 호출하면 관리실/현관 램프가 깜박이고 영상이 켜집니다. 수화기로 응답합니다. 세대에서 공동현관으로 먼저 발신하지 않습니다. 공동현관 통화는 최대 **1분**입니다.
- **도어폰:** **홈 링커로 HA-4100H → 세대 현관 도어카메라 또는 음성 도어폰 순서로 우클릭**합니다. 같은 현관 기기를 다시 클릭하면 해제됩니다. 도어 링커는 전기정 문 연결용입니다. 수신 시 도어폰 램프가 깜박입니다. 도어폰 버튼으로 해당 회선을 선택하고 수화기를 들면 응답합니다. 카메라가 있으면 영상이 표시됩니다. 통화·영상은 최대 3분입니다.
- **평상시 모니터:** 도어폰 버튼은 연결된 카메라를 최대 **30초** 켜고, 다시 누르면 끕니다.
- **동시 호출:** 수화기를 들 때 전화가 가장 우선이고, BUS 쪽은 공동현관이 우선입니다. 다른 회선은 대기 램프로 남으며 해당 기능 버튼으로 선택합니다. 통화 중 새 BUS 호출은 처음 약 3초 안내음과 대기 램프로 표시합니다.
- **문열림:** 공동현관 통화 중에는 해당 로비폰의 자동문을 엽니다. 그 외에는 세대 문 링크 도구로 연결한 현관 전기정을 엽니다. 문열림 램프는 1초 점멸합니다. 세대 문 릴레이는 기존 도어 제어의 자동 복귀를 사용합니다.
- **외출/메세지:** 외출과 방범 감시를 설정·해제합니다. 경비실이 연락 메시지를 남기면 점멸하며, 누르면 기기와 경비실의 메시지 표시를 함께 확인 처리합니다.

모니터는 **흑백**입니다. 컬러 영상이 들어와도 `VideoFormat.MONOCHROME`으로 표시합니다. 방문자 영상은 조작 화면과 설치 모델의 CRT에 같은 카메라 장면을 표시합니다. 명암·밝기는 슬라이더 클릭으로 각각 5단계 조절합니다. 음성 전용 도어폰은 영상을 만들지 않습니다.

## 전화·보류·재다이얼

국선 전화는 현대 BUS와 독립된 회선입니다. 게임 내 같은 단지의 HA-4100H에 등록한 **우리집 전화번호**로 통화합니다. 실제 외부 전화망에 전화를 걸지 않습니다.

수화기를 들면 전화를 선택합니다. 숫자를 누르고 `#` 또는 마지막 입력 뒤 잠시 기다리면 발신합니다. 수화기를 놓은 채 **전화/보류**를 선택하면 온후크 다이얼이 가능하며, 상대가 받으면 수화기를 들어 통화합니다. **재다이얼**은 마지막 발신 번호를 사용합니다.

전화 통화 중 전화/보류를 누르면 보류 램프가 점멸하고 상대에게 보류 멜로디를 보냅니다. 보류 중 수화기를 놓아도 끊기지 않습니다. 다시 들거나 전화/보류를 선택하면 복귀합니다. BUS 회선을 선택해도 전화는 보류로 유지합니다. 통화 메시지는 선택한 회선으로만 전송합니다. 전원을 끈 상태에서도 국선 전화 조작은 가능하며 BUS·경보·모니터는 동작하지 않습니다.

### 번호 기억·확인·삭제

수화기를 놓고 전화를 선택하지 않은 상태에서 조작합니다. `1=통보1, 2=통보2, 3=통보3, 6=우리집`입니다.

- 저장: `종류 → * → 4~15자리 전화번호 → #`
- 삭제: `종류 → * → #`
- 확인: `종류 → 0` 또는 입력 완료 시 표시

3자리 이하 번호는 저장하지 않습니다. 우리집 전화번호는 같은 단지의 로드된 HA-4100H와 중복 저장하지 않습니다. 입력 중 10초 대기, 수화기 들기, 수신 호출 또는 실제 경보 발생 시 입력을 취소합니다. 전화번호 기억은 세대 동·호 설정과 별개입니다.

## 경보 시험·실제 경보

화재·가스·비상·방범·카메라 도난 경보를 구분합니다. 우선순위는 이 순서이며 동시에 발생한 램프는 각각 점멸합니다.

**시험:** `시험(화재) → 정지/복귀(음소거) → 시험(가스) → 정지/복귀 → 정지/복귀(종료)`입니다. 음소거하지 않고 시험을 다시 눌러도 종류를 바꾸지 않습니다. 시험 경보는 경비실·통보처에 전달하지 않으며, 실제 경보가 발생하면 시험을 중단합니다.

**화재·가스:** 감지 시 경보를 유지하고, 정지/복귀로 음소거합니다. 감지 입력이 사라진 뒤 정지/복귀를 다시 누르면 정상으로 복귀합니다.

**비상:** 버튼을 1초 이상 눌러 시작·해제합니다. 정지/복귀는 경보음을 멈추거나 재개합니다. 경보음은 약 15분으로 제한합니다.

**방범:** 방범 또는 외출로 감시를 설정합니다. 초기 감시 1분은 램프만 표시하고, 감지가 지속되면 소리가 납니다. 경비실에는 감지 10초 뒤 신호를 보냅니다. 방범을 다시 누르면 감시·경보를 해제합니다. 소리는 약 15분 뒤 멈추고 표시를 유지합니다.

**카메라 도난:** 연결해 사용하던 카메라의 연결이 끊기거나 제거되면 도어폰 램프가 점멸하고 경보가 발생하며 모니터가 최대 3분 켜집니다. 정지/복귀로 음소거하고, 카메라 상태를 확인한 뒤 도어폰 버튼으로 확인 처리합니다. 단순히 카메라 청크가 로드되지 않았다는 이유로 도난 경보를 만들지 않습니다.

게임의 감지 접점은 본체 아래=화재, 본체 방향의 시계 방향 이웃=가스, 반시계 방향 이웃=방범, 위쪽=증설 비상입니다. 같은 단지에 있는 해당 이웃의 레드스톤 신호를 읽습니다. 서버 연동은 `setSensor(type, active)`도 제공합니다. 경비실 신호는 기존 현대 경보 전달 경로를 사용합니다.

### 자동 통보

실제 화재·가스·비상·방범 경보 시 도어폰에 먼저 30초 경보음을 보내고, 통보1→2→3 순서로 게임 내 전화 연결을 시도합니다. 통보처가 받으면 3초 사이렌·우리집 전화번호·경보 안내를 반복합니다. 다음 통보 전에 다시 30초 도어폰 경보를 보냅니다. 최대 9회 시도하고 **완료된 통보 3회**에 종료하며, 도중에 끊긴 통화는 성공으로 세지 않습니다. 원인이 제거되거나 본체 수화기를 들면 자동 통보를 중지합니다. 통보 번호가 없으면 도어폰 경보만 보냅니다. 카메라 도난은 전화 자동 통보 대상에서 제외합니다.

## 게임 표현·저장·검증

설명서의 녹음된 한국어 안내 음성·숫자 읽기는 **안내 문구와 게임 기본 소리**로 표현합니다. 실제 전화 회선의 증설 전화기는 별도 구현하지 않았으며, 통보 수신기는 같은 단지의 로드된 HA-4100H입니다.

동·호·로고·기억 번호·음량·밝기·명암·외출·방범·경보 상태는 저장합니다. 진행 중 통화와 시험은 재접속 후 재개하지 않습니다. 버튼·슬라이더 위치는 외형 자료를 그대로 사용하며, 램프와 화면 상태는 서버가 결정해 조작 화면과 설치 모델에 동기화합니다.

검증은 `tools/check_ha4100h_assets.py`, 설계 검사, HA-4100H 동작·설정 및 HMC-7000 전용 서버 검사로 수행합니다. 외형 크기·리소스·버튼 모양 외에 전화 보류·회선 전환·통화 우선순위·시간 제한·메시지·경보 시험·실경보·자동 통보·문열림·단지 분리를 검사합니다.

호출 상태는 조작 화면 상단과 하단에 표시합니다. 관리실/현관을 누른 뒤 수화기를 들면 호출 연결음이 나며, HMC-7000에서 수화기를 들어 응답합니다. HMC-7000의 수화기가 이미 들려 있다면 세대 버튼으로 대기 호출을 선택해 응답합니다. 양쪽 조작 화면 오른쪽에서 통화 메시지를 읽고, 입력란에서 Enter 또는 전송으로 보냅니다. 통화하지 않는 전화 회선의 선택 상태 때문에 연결된 BUS 통화 메시지가 사라지지 않습니다.
기능 버튼의 점등·점멸은 작은 별도 점이 아닌 버튼 면 전체에 표시합니다.
이동한 제품의 조작 거리·화면 갱신·주변 채팅 수신 범위는 화면에 보이는 실제 기기 위치를 기준으로 계산합니다. 조작 범위를 벗어난 요청은 안내를 표시합니다.
