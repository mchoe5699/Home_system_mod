# 현대 HA-4100H

이번에 제공한 여러 방향의 사진으로 본체·수화기·버튼·모니터 외형을 제작했습니다. 흰색 본체이며 세 번째 정면 사진의 제품 비율을 사용합니다. **가장 긴 변 0.5블록, 본체 가로 0.5 × 세로 0.392블록**이며 전체 모델은 가로·세로 1블록 안에 들어갑니다.

수화기 받침의 파임과 끝 받침, 수화기 전면의 볼록함, 각 케이스 이음매와 세로 테두리, 둥근 검은 경보판, 12개 타원형 숫자키, 9개 낮은 기능키, 큰 원형 비상키, 깊은 CRT 테두리와 명암·밝기 슬라이더를 분리된 모델 요소로 구성했습니다. 사진의 변색·낙서·스티커는 흰색 외형에 옮기지 않았습니다. 제품 동작을 보여주는 이미지나 게임 캡처는 생성하지 않습니다.

## 설치·로고

크리에이티브 탭에서 `현대 HA-4100H 디지털 홈오토메이션`을 선택하거나 `/give @s qwertys_homenet:ha_4100h`로 설치합니다. 설치된 제품을 우클릭하면 설정 창을 엽니다.

로고 편집은 기존 공통 로고 편집기를 사용하며 기본 HYUNDAI·숨김·사용자 글자·리소스팩 텍스처를 선택할 수 있습니다. 본체의 세 로고 위치에 같은 설정을 반영합니다. 로고를 숨겨도 제조사 BUS 규격은 HYUNDAI로 유지합니다. 공통 이동 도구도 지원합니다.

## HMC-7000 연동과 동·호 번호

경비실 링크 도구로 같은 단지의 현대 디지털 HMC-7000에 연결합니다. KOCOM BUS처럼 제조사가 다른 경비실기와는 연결하지 않습니다. 단지 밖이나 서로 다른 단지의 경비실과는 연결·등록·번호 변경을 할 수 없습니다. 하나의 단지로 묶인 구획에는 기존 단지 연동 규칙을 적용합니다.

동·호 번호는 이 제품에서 직접 입력하지 않습니다. 초기 링크는 기존 경비실 링크 도구의 임시 세대번호 할당을 사용합니다. 이후 번호 변경은 다음 순서로 합니다.

1. HA-4100H 설정 창에서 **경비실에 세대 등록 요청**을 누릅니다.
2. 연결된 HMC-7000에서 수화기로 응답합니다.
3. HMC-7000에서 `* → 동 번호 → 동 버튼 → 호 번호 → 동 버튼 → 로비 번호 두 자리 → #`를 누릅니다.
4. 새 번호가 HA-4100H와 경비실에 저장됩니다. 등록 후 설정 창의 등록 요청 종료 또는 경비실 수화기 놓기로 끝냅니다.

이번 구현은 사진 외형, 로고 편집, 현대 BUS 연결과 경비실 전용 주소 등록에 한정합니다. 실물의 전화·경보·문열림·화면·버튼별 동작은 추후 제공될 설명을 받은 뒤 구현합니다. 물리 버튼에는 임의의 동작을 부여하지 않았으며, 설정 창도 제품의 조작 화면을 대신하는 것이 아닙니다.

## 검증

`python3 tools/check_ha4100h_assets.py`로 최장변·비율·곡면 키·실제 CRT/수화기 파임·텍스처·UV·로고 분리를 확인합니다. 전용 서버 검사에서는 HMC-7000의 실제 키패드로 주소 변경, 로컬 번호 변경 거부, 잘못된 제조사·경비실·단지 차단, 로고 저장을 확인합니다.

외형 보정: 본체 중앙 조작부와 모니터 케이스의 정면 깊이를 좌우 껍데기의 정면 깊이에 맞췄습니다. 수화기는 더 얕은 연속 곡면으로 바꿔 설치 모델의 층·줄무늬를 없애고, 숫자키 돌출은 모델 단위 0.06, 작은 기능키는 0.035로 낮췄습니다. 설치 모델의 수화기·버튼은 내부 면이 없는 외부 곡면과 연속 법선을 사용하며, CRT 안쪽 경사의 흰 옆면도 검게 보정했습니다.

버튼 보정: 비상 버튼의 평평한 누름면은 외곽 테두리보다 0.012 모델 단위 안쪽에 위치합니다. 다이얼 버튼은 원본 비율의 타원형을 유지하고 크기를 59 × 39 기준으로 맞췄습니다. 다이얼 이외 기능 버튼은 끝이 반원인 길쭉한 형태, 낮고 평평한 윗면, 좁은 경사 테두리와 회색 음영으로 다시 구성했습니다.

비상 버튼 형상 정정: 중심이 휘어진 접시형이 아니라, 평평한 원형 누름면 전체가 테두리 안쪽으로 들어간 형태입니다. 누름면 깊이는 일정하고 외곽의 좁은 경사면만 높이가 달라집니다.
