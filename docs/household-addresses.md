# 공통 세대번호 및 경비실 연결

동 번호와 호 번호는 각각 **1~9999**입니다. 예: `1-1`, `9999-9999`. 로비폰·경비실기에서 세대를 호출하거나 등록할 때도 같은 범위를 사용합니다. 앞자리 0과 `101동 1203호` 표기는 정규화됩니다. 기존 동 생략 호 번호 입력은 1~9999 범위에서 유지됩니다. 범위 밖 입력은 기존 번호를 바꾸지 않습니다.

신규 모델은 `UnitAddress` 공통 검사와 `ReceiverBlockEntity.setUnit` / `assignUnitFromSwitchboard` 경로를 사용해야 합니다. 경비실기 자체 ID, 관리실 0번 및 로비 그룹 0번은 세대 동·호수가 아닌 별도 식별자입니다.

경비실기 링크 도구의 선택·일괄 연결 수, AM-10KP·KAM-305의 등록·저장 세대수에는 별도의 프로그램 상한이 없습니다. 장치가 로드되어 있고 통신 규격이 호환되어야 연결됩니다. 동시에 통화할 수 있는 회선 수는 기종별 사양을 따릅니다.

동·호수 비교는 각 숫자를 구분하므로 `1-111`과 `11-11`은 별개 세대입니다. 자동 배정도 각 1~9999 안에서 중복을 피합니다.
