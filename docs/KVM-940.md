# KVM-940 / KVM-940R3

두 모델 모두 KVM-906 기반의 0.4블록 크기이며, 수화기·화면 옆 전원/국선 표시·3개 기능 버튼·12키 다이얼을 제공합니다. 사진에 붙은 캐릭터 스티커와 전선은 추가하지 않습니다. 로고·색상 편집은 기존 디자인 도구를 사용합니다.

| 모델 | 경비실 방식 | 동·호수 | 기능 버튼 | 개폐 조건 |
|---|---|---|---|---|
| KVM-940 | STAR, 제조사 제한 없음 | 내부 설정 가능 | 현관·경비·개폐 | 도어카메라 호출에 응답한 통화 중 |
| KVM-940R3 | BUS, 코콤 제품끼리 연결 | 경비실기 전용, 링크 시 무작위 배정 | 현관/로비·경비·개폐 | 로비폰 호출에 응답한 통화 중 |

형제모델 변경 아이템의 목록을 스크롤해 클릭하거나 `/give @s qwertys_homenet:kvm_940` 및 `/give @s qwertys_homenet:kvm_940r3`로 가져옵니다.

국선은 **게임 내 전화 시뮬레이션**이며 실제 외부 전화망에 접속하지 않습니다. 같은 차원의 로드된 940 계열 기기끼리 각각 국선 번호(예: 1001·1002)를 등록하면 전화할 수 있습니다. 국선 번호와 동·호수는 별개입니다. 수화기를 들고 숫자를 누르며 `#`/발신 버튼으로 발신하고, `*`로 입력을 지웁니다. 마지막 숫자 입력 뒤 약 1초 후에도 발신합니다. 연결 중 키는 키패드음을 내며 두 번째 통화를 시작하지 않습니다.

국선 착신은 수화기로 응답하고 현관·경비와 동시 호출 시 해당 기능 버튼/후크로 통화를 전환합니다. 보류된 통화로 복귀할 수 있으며 수화기를 놓으면 모두 종료됩니다. 국선 착신 대기는 약 30초, 통화는 약 3분입니다. 전자식/기계식 다이얼 모드, 벨 음량·밝기·명암은 디자인 설정에서 변경합니다. 940R3에는 비상 기능이 없으며 외출 기능만 조작 화면에서 제공합니다. 세대 번호는 AM-10KP 등 연결된 경비실기에서 등록합니다.

## 실제 동작 사진

개발용 Minecraft 월드에서 직접 캡처한 화면입니다. 940R3 로비 통화 사진은 **배포 AM-10KP와 테스트 전용 로비폰 연결 기기**로 통화와 영상·개폐 조건을 검증한 장면입니다. 테스트 로비폰은 배포 JAR에 포함하지 않으며 AM-10KP 경비실기는 배포 JAR에 포함합니다. KAM-305도 추가되었습니다. 새 로비폰 본체는 후속 제작 예정입니다.
