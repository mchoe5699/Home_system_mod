# KVM 비디오폰 사용 안내

906·904·930·960·933의 버튼과 호환 경비실기 차이는 [README](../README.md)를 참고하세요. 사진과 설명서를 참고해 곡면을 작은 모델 요소로 근사했습니다. 원제품 로고를 편집할 수 있으며 외부 전선은 없습니다.

## 가져오기와 모델 변경

홈네트워크 크리에이티브 탭 또는 다음 명령으로 가져옵니다.

```mcfunction
/give @s qwertys_homenet:kvm_906
/give @s qwertys_homenet:model_changer
/give @s qwertys_homenet:analog_linker
/give @s qwertys_homenet:kvm_designer
/give @s qwertys_homenet:home_linker
/give @s qwertys_homenet:door_linker
```

`model_changer`를 든 채 비디오폰을 우클릭합니다. 휠로 목록을 스크롤하고 906/904/930/960/933 중 선택합니다. 변경 시 세부 커버·버튼·표시기·호환 규격이 함께 바뀝니다. 문과 현관 기기 링크 및 사용자 로고·색상은 유지됩니다. 새 모델이 기존 경비실기와 호환되지 않으면 경비실기 연결이 해제됩니다. 배포 버전에서는 실제 경비실기 본체가 없으므로 연결 대상 제작을 기다려야 합니다. 모델 변경은 통화 종료 후 가능합니다.

각 모델 아이템은 크리에이티브 탭에도 있습니다(`kvm_904`, `kvm_930`, `kvm_960`, `kvm_933`). 생존 플레이의 기존 기기 변경은 모델 변경 아이템으로 진행합니다.

## 현관과 문

1. 홈 링커로 내부 비디오폰(또는 일반 월패드·인터폰)을 선택합니다.
2. 연결할 도어카메라·도어폰을 선택합니다. 같은 세대번호의 다른 기기로 호출이 퍼지지 않고 직접 선택한 수신기만 울립니다. 숫자를 설정하지 않은 내부 기기도 현관 호출을 받을 수 있습니다.
3. 도어 링커로 **내부 기기**를 선택한 뒤 문을 선택합니다. 현관 카메라에 문을 연결하지 않습니다.
4. 걸려온 호출은 수화기를 눌러 들면 응답하고, 다시 놓으면 종료됩니다. 메시지는 기존 모드의 채팅 통화 방식이며 실제 마이크 음성 전송은 제공하지 않습니다.
5. 현관 버튼은 직접 연결한 카메라의 흑백 미리보기를 켜거나 끕니다. 클라이언트에 로드된 주변 블록·엔티티를 저해상도 광선 샘플링으로 보여주므로 원래 텍스처·스킨을 그대로 촬영한 영상은 아닙니다. 카메라 청크가 로드되지 않으면 신호 없음으로 표시됩니다.

받지 않은 현관 호출은 약 30초 후 종료됩니다. 수화기로 응답한 현관 통화의 CRT는 3분 후 꺼지며, 수화기를 놓을 때까지 통화는 유지됩니다. 현관 버튼으로 화면을 다시 켤 수 있습니다. 음량은 호출음, 밝기·명암은 미리보기에 적용됩니다.

문열림은 모델과 실제 호출 기기에 따라 제한합니다. **906·930·960은 문열림 기능이 없습니다. 904는 직접 연결한 도어카메라 호출에 응답해 통화 중일 때만, 933은 호환 로비폰 호출에 응답해 통화 중일 때만** 문을 엽니다. 933의 도어카메라 통화와 모든 모델의 대기·호출 대기·경비실 통화에서는 문열림이 차단됩니다. 도어 링커로 내부 기기 → 문을 연결한 뒤 조건에 맞는 통화 중에 물리 문열림 버튼이나 화면의 연결된 문 열기 버튼을 누르면 약 3초간 열립니다. 전원이 켜져 있어야 합니다. 철문·나무문은 위칸을 연결해도 두 칸 모두 개폐합니다.

## 세대번호와 STAR / BUS 경비실

- 906: 비디오폰에서 세대번호를 설정하되, 경비실 통화를 위해서는 비디오폰을 제조사와 무관한 STAR 아날로그 경비실기에 직접 연결해야 합니다. 현관 기기 링크에는 이 번호를 사용하지 않습니다.
- 904: 경비실 기능이 없습니다.
- 930/960/933: 동·호수는 연결된 호환 경비실기에서만 설정됩니다. 비디오폰 화면의 값은 읽기 전용입니다. 930·933·960은 KOCOM BUS 제품입니다. 코콤 BUS 경비실기인 AAM-10KP·KAM-305 및 이후 제작할 코콤 BUS 제품에만 연결합니다. 타사 BUS 경비실기와 STAR 경비실기에는 연결하지 않습니다. 모델명·배선수 대신 방식과 제조사로 검사합니다.

**경비실기 링크**로 서서 여러 비디오폰을 클릭해 선택합니다. 같은 기기를 다시 클릭하면 선택 해제됩니다. **웅크리고 경비실기를 클릭**하면 선택한 기기를 일괄 연결합니다. 웅크린 상태에서는 경비실기만 선택하며 내부 기기를 눌러도 선택·기존 연결을 바꾸지 않습니다. 서서 경비실기를 누르거나 웅크리고 허공을 눌러도 선택 목록은 유지됩니다. STAR/BUS·제조사 규칙에 맞지 않는 대상이나 로드되지 않은 기기가 있으면 일괄 연결을 적용하지 않으며 선택을 유지합니다. 904는 선택할 수 없습니다. 경비실기 본체는 후속 제작을 기다립니다.

930·933·960처럼 내부에서 동·호수를 변경할 수 없는 제품은 연결 시 무작위 동·호수를 배정하고 저장합니다. 다른 기기 및 예약 번호와 중복되지 않으며 저장/재시작·재연결 후 번호를 유지합니다. 비디오폰의 입력창·설정 패킷으로는 변경할 수 없습니다. 906처럼 내부 번호 설정이 가능한 제품도 연결할 수 있으며 현재 번호는 유지됩니다. 경비실 전용 번호 모델의 이후 번호 변경은 연결된 경비실기에서만 처리합니다.

930·933은 비상·외출 상태를 본체에 저장합니다. 930은 **비상 키**, 933은 **비상/전원 겸용 표시등**을 누릅니다. 비상음과 화면 옆 비상 표시기 점멸이 시작되며, 호환 경비실기가 연결돼 있으면 해당 경비실기에 비상 신호를 전달합니다. 다시 누르면 비상음·점멸이 멈추고 해제 신호를 전달합니다. 경비실기가 없으면 자체 경보만 작동하고 연결 대기 안내를 표시합니다. 외출은 다시 눌러 해제할 수 있고 화면 옆 외출 표시기를 점등합니다. 호출은 해당 표시기를 점멸하고 통화 연결 후 점등합니다.

## 로고·외관과 저장

로고는 기본 KOCOM / 없음 / 글자 / 커스텀 PNG 중 선택합니다. 906·904·960 커버 무늬는 사선 / 집·해·물결 / 사각형 / 삼각형·V / 민무늬 / 커스텀 PNG 중 선택할 수 있습니다. 930·933은 상태 표시기 디자인을 유지합니다. 본체와 커버 색상은 6자리 HEX로 지정하고 각 입력 옆 저장을 누릅니다.

디자인·모델·동호수·전원/비상/외출 상태·내부 문 링크·경비실기 위치는 월드 저장 및 정상 파손/재설치 시 보존됩니다. 통화와 화면 켜짐 상태는 재설치 후 재개하지 않습니다. 현관 기기의 직접 수신기 목록은 해당 현관 기기에 저장됩니다.

커스텀 PNG는 일반 Minecraft 리소스팩으로 적용합니다.

```text
pack.mcmeta
assets/my_pack/textures/kvm/logo.png
assets/my_pack/textures/kvm/cover.png
```

```json
{"pack":{"pack_format":15,"description":"Custom KVM designs"}}
```

디자인 설정의 로고/커버 경로에 다음처럼 입력합니다.

```text
my_pack:textures/kvm/logo.png
my_pack:textures/kvm/cover.png
```

투명 PNG를 권장하며 각 경로는 최대 64자입니다. 존재하지 않는 경로는 기본 커스텀 예제로 대체합니다. 다른 플레이어도 같은 리소스팩을 적용해야 같은 디자인이 표시됩니다. 웹 주소나 컴퓨터의 절대 경로를 입력하지 않습니다.

## 개발·검증

JDK 17과 Gradle 8.8을 사용합니다. 빌드와 테스트 명령은 README에 있습니다. KVM 에셋 재생성은 Pillow를 준비한 뒤 `PYTHONDONTWRITEBYTECODE=1 python3 tools/gen_kvm906.py`로 실행합니다. KVM 전용 에셋만 만들며 별도 LCD 글꼴은 필요하지 않습니다.

KVM-906·904·930·933·960은 모두 가로·세로 0.4블록, 두께 약 0.088블록으로 같은 외곽 크기를 사용합니다. 경비실기 명칭은 아날로그 STAR·디지털 BUS 모두 **경비실기**로 표시하며, 아날로그 경비실기를 교환대라고도 부릅니다.
