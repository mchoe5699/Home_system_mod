# 모든 회사 제품의 공통 이동

기존 기기 이동 도구와 위치 조정 화면을 그대로 사용합니다. 기존 코콤·현대 등 제품과 새 삼성 제품 모두 같은 이동 엔진을 사용하며, 제조사별로 허용 여부를 나누지 않습니다. SHT-101C·SHT-102C와 삼성 휴대장치 충전기도 포함합니다.

- 이동 도구로 설치된 기기를 클릭하고 방향과 이동량을 선택합니다. 상하·동서남북, 칸 또는 mm 입력을 지원합니다.
- 미세 이동이 블록 경계를 넘으면 실제 기기 블록을 옮기고 나머지 미세 위치를 보존합니다.
- 동·호, 전화번호, 기기 식별값, 외부기기 연결을 보존합니다. 삼성 휴대장치의 등록도 이동한 본체에 이어집니다. 이전에 로드되지 않은 충전기도 이동 기록을 반영합니다.
- 본체·충전기의 화면상 위치, 클릭 영역, 렌더링 경계와 벽 가림 위치가 같은 이동량을 사용합니다.
- 통화·호출·경보 등 동작 중에는 먼저 동작을 끝내야 합니다. 기존 이동 권한, 거리, 단지 경계, 이동 위치 충돌 검사는 유지합니다.

기존 이동 대상 판정이 기존 제품 등록 경로만 허용하여 새 삼성 모듈을 거부하던 부분을 확장했습니다. 별도 삼성 이동 도구나 별도 조작 화면을 만들지 않았습니다. 기존 제품 클래스 파일은 보존하고 실행 시 공통 대상 판정과 삼성 동작 중 검사를 확장합니다.

등록된 기기 블록 44종을 각각 100mm 조정하고 블록 경계 너머로 이동하는 서버 검사를 통과했습니다. 삼성 두 본체와 충전기의 설정·문 연결·휴대장치·이동 기록도 검사합니다. 배포 파일은 버전 없는 `qwertys_homenet.jar`입니다.

서버 기능 검사 38개를 통과했습니다. 실제 클라이언트에서는 기존 이동 도구와 위치 조정 화면을 통해 SHT-101C·SHT-102C·충전기를 조정하고, 요청/응답 및 위치 갱신 패킷, 충전기 형상 위치, 클릭 영역이 따라오는 것을 확인했습니다. 기존 통화·휴대장치·벽 가림·18종 영상 검사도 함께 통과했습니다.
