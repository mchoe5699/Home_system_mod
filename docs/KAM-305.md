# KOCOM KAM-305 디지털 경비실기

Minecraft Java 1.20.1 / Forge 47.x. 기존 AM-10KP와 함께 KAM-305를 제공합니다. 크리에이티브 HomeNet 탭이나 제작법에서 꺼내 책상·바닥에 설치합니다.

본체는 설명서의 **340:210 가로·세로 비율**을 유지합니다. 수화기의 곡선과 접합선, 둥근 숫자 다이얼, 4개 상단 스위치, 8개 하단 기능 버튼, 스피커 구멍, 흰색 LCD 테두리와 녹색 화면을 별도 부품으로 구성했습니다. 본체와 회전하는 LCD의 전체 범위가 **1×1블록 안**에 들어갑니다. 외부 전선은 생략했습니다.

## LCD 각도

설치한 KAM-305를 바라보며 **Ctrl + `+` / Ctrl + `−`**를 누릅니다. 숫자 키패드의 `+` / `−`도 지원합니다. 한 번에 1°, 기본 0°, 범위는 0~65°입니다. **0°는 본체의 홈에 수납된 상태**이며 +를 누를수록 화면이 올라옵니다. 본체 조작면은 약 8° 기울어져 있습니다. **LCD만 회전**하고 본체·수화기·버튼은 책상 위에 유지됩니다. 손에 아이템이 있어도 조절할 수 있으며, 열린 조작 화면에서도 Ctrl +/− 및 각도 버튼을 사용할 수 있습니다. 각도는 월드에 저장됩니다.

## 연결과 호출

KAM-305는 **코콤 BUS 디지털 경비실기**입니다. KVM-930·960·933·940R3을 연결할 수 있습니다. STAR KVM-906·940, 경비 기능이 없는 KVM-904, 다른 제조사의 BUS 기기는 연결하지 않습니다.

경비실기 링크 아이템으로 비디오폰을 서서 선택한 뒤 웅크리고 KAM-305를 클릭합니다. 다시 클릭한 비디오폰은 선택 해제됩니다. 세대와 등록된 로비를 합쳐 최대 60개 기기, 세대 통화는 3회선입니다. AM-10KP의 기존 4회선 기능은 유지합니다.

- 세대에서 경비 호출: 수화기 → 경비 버튼. KAM-305에서 수화기를 들고 해당 회선이나 확인을 눌러 받습니다.
- 경비실에서 호출: 수화기를 들고 번호를 입력한 뒤 **확인을 0.7초 이상** 누릅니다. 주소는 `01011203` 또는 오른쪽 입력란에 `101-1203`을 입력하고 입력 적용을 누릅니다.
- **F1**로 SD(세대), GB(경비), SH(상호), LB(로비) 그룹을 선택합니다. 같은 코콤 BUS 경비실기 간에도 호출·응답할 수 있습니다.
- **교환** → 다른 세대로 호출 → 해당 세대가 응답 → 경비 수화기를 내려놓으면 세대 간 통화로 전환합니다. `*` 또는 교환 버튼으로 취소할 수 있습니다.
- 호출 대기는 30초입니다. 수화기를 내려놓거나 전원을 끄면 상대 회선도 정리됩니다.

## 관리자 메뉴

초기 상태에서는 관리자 버튼을 누르면 **관리자 메뉴로 바로 진입**합니다. 경비실 관리에서 비밀번호를 등록한 뒤에는 관리자 버튼 → 비밀번호 입력 → 입력 적용 순으로 인증합니다. 초기화로 비밀번호가 초기값이 된 경우에도 바로 진입합니다. 관리자 인증은 조작한 플레이어에게만 적용되며 일정 시간 후 만료됩니다. 숫자 또는 UP/DOWN으로 메뉴를 선택하고 확인을 누릅니다.

| 메뉴 | 입력 및 동작 |
|---|---|
| 1 부재 설정 | 우회 경비실 번호를 등록합니다. 부재 버튼에서 비밀번호 인증 후 부재를 실행/해제합니다. 관리실 모드(경비번호 0)는 부재를 사용하지 않습니다. |
| 2 세대번호 관리 | **세대와 통화 중** `101-1203\|99`처럼 동-호와 경비번호를 함께 입력합니다. 경비번호는 필수입니다. 다른 호환 경비실로 변경하면 링크도 함께 이동합니다. |
| 3 세대암호 관리 | **세대와 통화 중** 새 숫자 암호 4~8자리를 저장합니다. 세대 기기의 암호에도 반영됩니다. |
| 4 로비 관리 | `101-1\|5678\|x,y,z` 형식으로 같은 KAM-305에 연결된 코콤 BUS 로비의 ID·암호를 등록합니다. 좌표는 실제 설치 위치입니다. |
| 5 경비실 관리 | 아래 하위 메뉴를 사용합니다. |
| 6 시각 관리 | `2026-10-13 12:00`처럼 입력합니다. 이후 게임 시간에 따라 진행하고 저장됩니다. |
| 7 감시모드 | `1` 설정 / `0` 해제. 경비실에서 로비 문을 열면 OPN 기록을 남깁니다. |
| 8 비상 데이터 | 누적 비상 기록을 5개씩 조회합니다. 최대 500건을 저장합니다. |
| 9 언어 설정 | `ko`, `en`, `zh`로 대기 화면 언어를 선택합니다. 관리 입력 형식은 동일합니다. |
| 10 음량 조절 | `2\|2`처럼 벨·통화 음량을 각각 0~2로 저장합니다. 모드의 대화는 통화 메시지 방식입니다. |

경비실 관리의 하위 메뉴:

| 메뉴 | 입력 및 동작 |
|---|---|
| 1 현재번호 수정 | `99\|0`처럼 경비번호와 SETUP 모드 0/1을 설정합니다. SETUP 모드에서는 같은 주장치 ID의 KAM-305에 연결된 세대 호출을 우회 수신하고 세대번호·경비번호를 등록할 수 있습니다. 초기 등록 후 0으로 해제합니다. 다른 경비실과 중복된 번호는 저장하지 않습니다. |
| 2 비밀번호 수정 | 새 비밀번호 4~16자리. |
| 3 동[로비] ID 관리 | 삭제할 `동-로비` 주소를 입력합니다. |
| 4 상호 ID 관리 | 설치된 호환 경비실기를 조회합니다. |
| 5 장치기 버전 | 본체 버전 및 연결 정보를 표시합니다. |
| 6 마스터 초기화 | `현재비밀번호\|RESET` 입력. 번호 99, 비밀번호 ffff, 우회 0, 음량 2, 주장치 0, 통화 기록 초기화. |
| 7 중계기 ID 변경 | 주장치 ID 0~99를 저장합니다. |
| 8 세대통신 검사 | 등록된 기기의 정상·부재·통화중·통신 불량 상태를 조회합니다. 아래 관리 입력도 지원합니다. |
| 9 공동현관문 제어 | 문열림 시간 1~10초. 로비와 통화 중 개폐 버튼을 누르면 문을 열고 통화를 종료합니다. |
| 10 로비영상 제어 | 예: `101,1,1-101,20,3\|1`. 시작 동·층·라인부터 끝 범위까지 영상번호 1을 배정합니다. 다른 영상번호와 겹치는 범위는 저장하지 않습니다. |

세대통신 검사 화면의 관리 입력:

- `REGISTER|x,y,z|101-1203|99`: 실제 로드된 호환 비디오폰을 해당 경비실에 등록합니다.
- `DELETE|101-1203|CONFIRM`: 해당 세대 등록과 링크를 삭제합니다.
- `CLEAR|CONFIRM`: 관리하는 세대 등록과 링크를 모두 삭제합니다.
- `RANGE|101|1|20|1|3`: 연결된 세대들을 위치 목록 순서대로 동 101, 층 1~20, 라인 1~3 범위에 배정합니다. 통화 중이거나 로드되지 않은 기기가 있으면 적용하지 않습니다.

## 비상과 기록

세대 비상을 받으면 주소·상태를 LCD에 표시하고 경보음을 냅니다. UP/DOWN으로 비상 주소를 선택하고 확인으로 호출합니다. 비상/정지 버튼은 소리만 멈추며 원래 세대의 비상 상태는 유지합니다. 세대에서 해제하면 경비실에서도 해제됩니다.

수신된 비상이 없는 대기 상태에서 붉은 비상 버튼을 누르면 **경비실 자체 비상**을 다른 코콤 BUS 경비실기에 전파합니다. AM-10KP도 수신합니다. 발생한 KAM-305에서 다시 누르면 해제됩니다. 상대 경비실의 정지 버튼은 소리만 멈춥니다.

F3는 최근 통화 기록, F2는 현재 시각입니다. 통화·비상 기록은 최대 500건씩 저장하고 5개씩 조회합니다. STD/ROU/EXC/OPN과 SD/GB/SH/LB 구분을 사용합니다. 프린터가 없는 상태에서 기록 화면의 F2는 연결 없음 안내를 표시합니다.

## 외부 장치 범위

이번 JAR에는 **AM-10KP와 KAM-305 본체**를 포함합니다. 새 로비폰·물리 주장치·프린터·RF 리더기·외부 영상 모니터 본체는 추가하지 않습니다. 세대 관리와 통신 검사는 게임에 설치된 기기 링크를 대상으로 작동합니다. 로비 호출·개폐·암호·영상 범위 기능은 같은 경비실에 연결된 호환 로비가 있을 때 사용합니다.

후속 로비는 `AnalogLobbyEndpoint`의 `manufacturer()`를 KOCOM으로 선언하고 경비실 위치를 제공해야 합니다. 영상 범위를 설정한 경우 `videoNumber()`와 실제 `cameraPosition()`도 제공해야 합니다. KAM-305의 `checkLobbyPassword`로 등록 암호를 검증할 수 있습니다. 설명서의 PC 펌웨어 설치·USB/RS232 업데이트 절차는 게임 외부에 실행하지 않습니다.
