# KOCOM KAM-305

Minecraft Java 1.20.1 / Forge 47.x. 코콤 BUS 비디오폰과 연결하는 디지털 경비실기입니다. 사진의 340:210 비율과 1×1블록 안의 크기를 유지합니다. LCD는 Ctrl +/−로 조절합니다. 0°는 본체에 수납된 상태입니다.

## 설명서의 LCD와 버튼 조작

조작 화면에는 제품의 실제 전면과 LCD가 표시됩니다. 설정용 외부 패널이나 특수 형식의 입력란을 사용하지 않습니다. 숫자 버튼, UP/DOWN, 확인, 취소(*)로 조작합니다. 키보드 숫자·방향키·Enter·F1/F2/F3도 같은 버튼으로 동작합니다.

- 대기: 설명서의 KOCOM 로고, 회사 문구, 날짜·요일·시각을 표시합니다.
- 발신: 번호를 입력하고 확인을 약 0.7초 누릅니다. 수화기를 놓은 상태에서도 호출하며, 수화기를 들면 통화로 이어집니다. F1으로 SD/GB/SH/LB 그룹을 선택합니다. 세대 주소는 동 4자리와 호 4자리입니다.
- 착신: 수화기를 들어 응답합니다. 진행 중인 회선은 UP/DOWN으로 선택합니다.
- 설정보기: 현재 경비실 번호, 우회 번호, 벨·통화 음량, 주장치 ID, 마스터 모드, 버전을 표시합니다. 같은 버튼으로 복귀합니다.
- 통화기록: F3. 한 페이지에 5개 내역과 페이지 번호, 방향·그룹·주소·시각·STD/ROU/EXC/OPN을 표시합니다.
- 교환: 세대와 통화 중 교환 → 상대 세대 번호 입력 → 확인 → 상대 응답. 3자 통화 후 경비실 수화기를 내려놓으면 세대끼리 직접 통화합니다. 상대를 호출하기 전에 *로 취소하면 원래 통화로 돌아갑니다.
- 문열림: 연결된 로비폰과 통화 중에만 개폐합니다. 설정한 시간이 지나면 문을 닫고 통화를 종료합니다.
- 부재: 부재 버튼 → 등록된 비밀번호 입력 → 확인 → UP/DOWN으로 설정/해제. 우회 대상은 관리자 메뉴에서 정합니다. 관리실 번호 0은 부재 기능을 사용하지 않습니다.
- 전원: 빈손으로 제품 뒤쪽을 바라보며 웅크리고 우클릭하면 뒤쪽 전원 스위치를 조작합니다. 부재 설정은 전원을 다시 켜도 유지됩니다.

## 관리자 메뉴

비밀번호가 초기 상태로 등록되지 않았으면 관리자 버튼에서 바로 진입합니다. 비밀번호를 등록한 뒤에는 인증합니다. 인증은 메뉴를 나가거나 수화기를 조작하면 종료됩니다.

설명서 사진처럼 메뉴를 6행씩 표시하고 선택 항목을 반전합니다. 숫자나 UP/DOWN으로 항목을 선택한 뒤 확인합니다.

| 항목 | 조작 |
|---|---|
| 1 부재 설정 | 우회 경비실 번호 입력 → 확인 |
| 2 세대번호 관리 | 세대와 통화 중 현재 주소 확인 → 새 동 → 확인 → 새 호 → 확인 → 관할 경비번호 → 확인 → 옵션번호 → 확인 |
| 3 세대암호 관리 | 세대와 통화 중 현재 암호 확인 → 새 암호 입력 → 확인 |
| 4 로비 관리 | 동 → 로비 번호 → 암호 순서로 입력·확인. 호 번호 0000은 해당 동의 일괄 암호입니다. |
| 5 경비실 관리 | 경비실 관리 목록으로 진입 |
| 6 시각 관리 | 년·월·일·시·분·초를 순서대로 선택·수정. 요일은 자동 계산하며 같은 주장치 ID의 경비실기에 시각을 적용합니다. 기존 기록의 시각은 바뀌지 않습니다. |
| 7 감시모드 설정 | UP/DOWN으로 설정/해제. 감시 중 문열림을 통화기록에 기록합니다. |
| 8 비상데이터 관리 | 5개씩 저장된 발생·해제 내역과 페이지 번호 조회 |
| 9 언어 설정 | UP/DOWN으로 한국어·영어·중국어 선택 → 확인 |
| 0 음량조절 관리 | 벨소리 조절 → 확인 → 통화음 조절 → 확인 |

## 경비실 관리

매뉴얼의 메뉴 사진에 있는 **중계기 라인 체크**도 포함했습니다. 목록의 항목 이름을 확인해 선택합니다.

- 현재번호 수정: 번호 입력·확인으로 먼저 저장하고, 이어서 SETUP ID 설정/해제를 선택합니다. 설치가 끝나면 SETUP을 해제합니다.
- 비밀번호 수정: 새 비밀번호 입력·확인.
- 동[로비] ID 관리: UP/DOWN으로 등록된 ID를 선택하고 확인으로 삭제합니다. 동의 0000 ID를 삭제하면 일괄 암호를 해제합니다.
- 주장치 상호 ID 관리: 주장치 ID로 실제 연결된 경비실기·상호 ID를 검색하고 선택한 번호를 수정합니다.
- 장치기 버전 정보: 장치기 종류와 주소를 선택해 실제 등록된 기기를 조회합니다. 없는 대상은 통신 실패로 표시합니다.
- 중계기 라인 체크: 등록 장치 수와 실제 응답 여부 확인.
- 마스터 초기화: 비밀번호 확인 → 초기화 여부 선택 → 확인. 번호 99, 우회 0, 음량 2, 주장치 0, 초기 비밀번호로 복귀합니다.
- 중계기 ID 변경: 주장치 ID 입력·확인.
- 세대통신 검사: 검색/삭제, 등록, 상태 검색, 범위 등록, 전체 삭제 메뉴를 제공합니다. 주장치·카드·채널로 실제 등록 대상을 구분합니다. 등록은 그룹·경비번호·주장치·카드·채널·동·호·옵션을 순서대로 입력합니다. 전체 삭제는 별도 확인이 필요합니다.
- 공동현관문 제어: UP/DOWN으로 1~10초 설정.
- 로비 영상 제어: 시작/끝 동·층·라인과 영상번호 입력·확인. 등록 범위에 맞는 세대에만 로비 영상을 제공합니다.

## 비상와 추가 기능

비상/정지는 경보음을 정지하며 발생 상태를 임의로 지우지 않습니다. 실제 세대 또는 발생 경비실에서 해제한 상태를 반영합니다. 경비실 자체 비상은 다른 코콤 경비실기에 전달합니다. 지원되는 안전 이벤트는 비상 내역에 종류와 ON/OFF 시각으로 기록합니다.

F3 → # → 0 → 7 → 4로 설명서의 비밀번호 확인 화면을 엽니다. 초기화 확인 화면에서 같은 코드를 입력하면 공장 초기화를 선택할 수 있습니다. 확인 후 등록정보와 설정·기록을 초기화하고 약 35초 뒤 대기 화면으로 복귀합니다. 초기화 중 저장·재시작해도 진행 상태를 유지합니다.

프린터나 출동경비 서버 하드웨어가 설치되지 않은 연결은 성공으로 표시하지 않습니다. 프린터 미연결 시 LCD에 미연결 알림을 표시하며, 장치기 관리와 버전 조회는 실제 설치·링크된 기기를 대상으로 동작합니다. 설명서의 PC·Linux 펌웨어 업그레이드 절차는 Minecraft 기기의 조작 기능과 별도입니다.

## KLP-203RF 연동

KLP-203RF 로비폰의 경비번호를 이 경비실 번호와 맞추고 경비실기 링크로 연결합니다. 로비 관리 창을 열면 등록된 패널의 동·라인과 호출 호수 범위가 표시됩니다. 해당 로비의 출입 비밀번호를 저장하면 로비 키패드에서 `경비번호#출입암호#`로 문을 엽니다. 로비 통화 중 개폐 버튼으로도 해당 로비 문을 열 수 있습니다. [KLP-203RF 안내](KLP-203RF.md).

외형 크기: 가장 긴 변을 **0.8블록**으로 통일합니다. 본체·수화기·버튼·표시부·로고와 선택 영역을 같은 비율로 조정하며, 이동 도구의 mm 이동량은 실제 블록 좌표 기준을 유지합니다.
