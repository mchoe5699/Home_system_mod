# 단지 구획과 기기 연동

로비폰·비디오폰·경비실기·인터폰·월패드는 같은 단지에 있는 기기끼리만 연동됩니다. 구획 밖에서는 직접 링크, 번호 검색, BUS/STAR 통화 및 전화 연결이 차단됩니다. 출입문 링크도 같은 단지 안에서만 동작합니다.

대시보드로 구획을 만든 뒤 **구획 묶기 / 분리**를 누르세요. 여러 구획을 선택하고 단지 이름을 입력한 뒤 **선택 구획 묶기**를 누르면 하나의 단지가 됩니다. 같은 단지 이름을 사용하면 기존 단지에 구획을 추가할 수 있습니다. **선택 구획 분리**는 선택한 구획을 각각 독립 구획으로 되돌립니다.

묶인 구획의 실제 영역만 같은 단지입니다. 떨어진 구획 사이의 빈 땅은 포함되지 않습니다. 겹친 구획에서는 기존처럼 가장 작은 구획이 우선합니다. 서로 다른 차원의 기기는 연결되지 않습니다.

기존 월드의 구획은 각각 독립 단지로 불러옵니다. 기존 링크는 저장되지만, 단지 경계를 벗어나면 호출·영상·메시지·문열림이 차단되고 통화가 종료됩니다. 다시 같은 단지로 묶으면 저장된 링크를 사용할 수 있습니다. 구획을 하나도 만들지 않은 월드는 먼저 구획을 지정해야 합니다.

네트워크 형식이 변경되어 서버와 클라이언트 모두 이번 버전으로 교체해야 합니다.

같은 단지로 묶은 구획이 면으로 맞닿으면 대시보드는 맞닿은 내부 경계선을 숨기고 실제 영역의 외곽선만 표시합니다. 일부만 붙은 면은 붙은 구간만 지우며, ㄱ자 형태나 빈 공간의 경계는 보존합니다. 떨어진 구획은 같은 단지여도 각각 외곽선을 표시하고 사이의 땅을 채우지 않습니다. 같은 단지는 가장 먼저 생성된 구획의 지도 색상으로 통일해 색상 이음선도 없앱니다. 구획을 다시 분리하면 각 구획의 경계와 원래 색상이 복원됩니다.
