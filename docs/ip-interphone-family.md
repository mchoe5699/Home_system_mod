# IP-203AP 형제모델과 흰색 외장

IP-203AP·IP-203APB·KIP-234R2·IP-200PC·IP-200PCHB·DP-202H를 하나의 형제모델 그룹으로 묶었습니다. 기존 **형제모델 변경 아이템**을 들고 해당 기기를 클릭한 뒤 여섯 모델 중 하나를 선택합니다. 기존 KVM 형제모델 변경 기능도 유지합니다.

수화기가 놓여 있고 통화·보류 호출이 없는 상태에서 변경합니다. 설치 방향, 로고와 음량을 유지합니다. 같은 STAR 또는 BUS 경비실과 호환되는 모델끼리는 연결과 세대 번호를 유지합니다. 다른 통신 방식으로 바꾸거나 DP로 바꾸면 호환되지 않는 경비실 연결을 해제합니다. PC·PCHB로 바꾸면 기존 도어폰·도어카메라 연결을 제거합니다. 초인종은 같은 설치 위치의 PC·PCHB에만 호출음을 전달합니다.

사진에 표시한 앞쪽 본체·수화기·받침·옆면 플라스틱은 흰색 텍스처를 조명 때문에 회색으로 어둡게 만들지 않는 재질로 표시합니다. 깊이 검사는 유지하여 뒤쪽 면이 앞으로 비치는 현상을 방지합니다. 아이템도 회색 명암을 줄인 흰색 외장으로 표시합니다. 벽 쪽 회색 뒤판, 검은 글자·그릴·테두리는 유지합니다. 주변에 빛을 내는 발광 블록을 추가한 것은 아닙니다.

## 도어폰과 초인종의 구분

- 도어폰은 렌즈·영상 송출 없이 호출과 음성 통화를 제공합니다. 내부 기기에서 수화기를 들어 통화하고 내려놓아 종료합니다. 도어폰은 카메라 주소로 선택하지 않으며 영상 렌더러에서도 제외합니다.
- 도어카메라는 호출·통화와 영상 기능을 제공합니다.
- 호출 전용 초인종은 PC·PCHB에서 딩동만 울리며 음성 회선을 만들지 않습니다. 두 모델의 도어폰·카메라 연결 거부는 유지합니다.

신규 제품 사진이나 게임 스크린샷은 생성하지 않았습니다.

버튼이 있는 형제모델의 버튼 돌출량을 소폭 늘렸습니다. 도어폰을 우클릭하면 호출과 함께 채팅 화면을 열고, 통화 중 다시 우클릭해도 통화를 유지합니다. 연결 후 메시지를 주고받으며 화면의 통화 종료로 끊습니다. 영상은 제공하지 않습니다.
