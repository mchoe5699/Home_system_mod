# KOCOM KVM-932T

첨부 KVM-932T 국문 설명서(표기 KVM932T 03.11)와 정면·측면 사진을 기준으로 구현했습니다. `qwertys_homenet:kvm_932t`로 설치하며 930·931과는 별도이며 KVM-931T와 같은 전화 겸용 모델군입니다. 모델 선택창의 디자인은 공통 FamilyModelScreen을 유지합니다.

사용자 지정에 따라 본체 크기와 외곽 테두리는 KVM-931과 동일합니다. 본체 가로 0.45675블록, 세로 0.45블록이며 기존에 줄인 본체 두께를 유지합니다. 각진 긴 수화기와 받침, 확대된 검은 CRT 패널, 빨간 비상 버튼, 외출·현관/로비·경비 버튼과 녹색 표시등, 별도 문열림 버튼과 원형 전원등, 국선·보류·재다이얼 가로 버튼, 3×4 숫자 키패드, 상단 타공과 하단 모델명을 구분했습니다. 파인 CRT·받침과 곡면 버튼·수화기는 실제 깊이를 갖는 게임 모델입니다.

## 사용

- 경비실은 기존 BUS 연결 도구로 연결하고 동·호수는 경비실에서 지정합니다(각각 1~9999). AM-10KP 및 KAM-305와 연동합니다. 현관 카메라는 직접 연결하고, 로비폰은 같은 경비실에 연결합니다. 설명서의 현관카메라 연결은 전원·접지·음성·영상의 4선이며, 게임의 로비 통신은 기존 공동현관 BUS와 호환됩니다.
- 대기 상태에서 수화기를 들면 국선을 선택합니다. 게임 안의 국선 번호를 등록한 다른 국선 지원 KVM으로 숫자를 눌러 호출할 수 있습니다. 실제 외부 전화망 연결은 없습니다. 국선 버튼으로 국선을 선택하며 보류 버튼은 상대방 연결을 유지한 채 현관/로비·경비 통화로 전환하고 다시 누르면 국선으로 복귀합니다. 재다이얼은 마지막 발신 번호를 다시 호출합니다.
- 경비 버튼을 먼저 누른 후 수화기를 들거나, 수화기를 든 상태에서 경비 버튼을 누르면 경비실을 호출합니다. 무응답은 약 30초, 세대에서 발신한 경비 통화는 3분, 경비실에서 수신한 통화와 로비 통화는 5분 후 종료합니다.
- 현관 호출은 딩동음과 영상·램프를 동작시키며, 수화기를 들면 통화합니다. 현관 버튼으로 수화기를 들지 않고 화면을 켜고 끕니다. 현관 통화는 상세 사용 설명에 따라 3분 후 화면만 꺼지며 음성은 유지하고 현관/로비 버튼으로 화면을 다시 켭니다. 흑백 CRT 화면을 사용합니다.
- 여러 호출을 받으면 해당 통화를 선택할 수 있습니다. 국선·경비·현관/로비 버튼으로 통화를 선택하고, 대기 중인 로비와 현관이 함께 있으면 현관/로비 버튼으로 전환합니다. 수화기를 내려놓으면 보류된 연결도 종료합니다.
- 문열림은 연결된 로비 통화 중에만 동작합니다. 같은 제품의 현관 카메라 통화에서는 로비 문열림을 허용하지 않습니다. 기존 문 연결 도구로 지정한 문을 엽니다.
- 비상 버튼은 본체·경비실에 비상을 알리고 비상 표시가 켜집니다. 다시 누르거나 수화기를 내려놓으면 해제하며 경비 응답 통화에서도 해제합니다. 외출은 버튼으로 설정/해제하고 수화기 사용 후 내려놓거나 현관 호출에 응답하면 해제합니다. 외출 시 경비실 호출은 울리지 않고, 로비 호출은 경비실로 우회하며 현관 카메라는 계속 호출할 수 있습니다.
- 국선 전화벨 음량은 별도 설정이며 호출 음량·밝기·농도·로고·제품 이동도 지원합니다.

설명서의 앞부분 도해에 KVM-931T라는 글자가 섞여 있지만, 제품 사양과 표지의 KVM-932T 및 사용자 제공 사진을 기준으로 모델명과 구성을 적용했습니다. 검증은 자산·코드·서버 자동 검사로 진행하며 동작 이미지나 스크린샷을 생성하지 않습니다.
