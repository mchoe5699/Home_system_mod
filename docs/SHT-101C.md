# 삼성 SHT-101C 홈오토메이션

여러 방향의 참고 사진과 업로드한 SHT-101C 설명서(12 PDF 면, 실물 쪽수 4–21)의 조작을 기준으로 구현했습니다. 설명서의 안내는 제품 기능 명세로만 사용했으며 외부 전화·연락을 실행하지 않습니다.

## 외형과 크기

다섯 번째 사진의 파란 내부 영역 가로는 정확히 **0.5블록**입니다. 분홍색 바깥 틀을 포함하면 약 **0.537634 × 0.397849블록**입니다. 본체는 1×1블록 안에 들어가며 본체·무선수화기 안테나는 이 범위 계산에서 제외합니다.

밝은 아이보리 플라스틱, 별도 거치판, 오목한 충전 거치대, 충전 접점, 스피커 슬롯, 둥근 연속 곡면 수화기, 12개 숫자키와 기능키, 중앙의 주황색 비상 버튼, 흑백 CRT의 실제 들어간 테두리, 명암·밝기 슬라이더를 구성했습니다. 무선수화기는 거치 시 뒷면이 보이고, 분리한 아이템에서는 통화·다이얼·기능 버튼이 있는 앞면이 보입니다. 수화기 안테나는 수직으로 서 있고 본체 안테나는 기본적으로 상단에 접혀 있습니다. 본체 안테나는 별도로 접거나 세울 수 있습니다. 같은 줄의 버튼은 앞면 높이와 돌출량이 같습니다. 사진의 변색·스티커·광고 문구·전선은 재현하지 않습니다.

## 설치와 방식

크리에이티브의 **SAMSUNG HomeNet** 탭에서 본체를 선택합니다. 본체를 우클릭해 조작합니다.

- **BUS**: 삼성 디지털 BUS 경비실 및 삼성 BUS 로비폰 프로토콜만 허용합니다. 전용 경비실 연결 도구로 연결하며 동·호 번호는 경비실에서 지정합니다. 코콤 BUS와 현대 BUS 경비실은 거부합니다.
- **STAR**: 같은 단지의 기존 STAR 경비실 경로를 사용합니다. 본체 화면에서 STAR로 바꾸고 동·호 번호를 설정합니다.
- 방식 변경은 수화기를 장착하고 통화를 종료한 상태에서 합니다. 변경 시 이전 경비실 연결을 해제합니다.
- 홈 링커는 **본체 → 도어카메라/도어폰** 순서로 연결합니다. 경비실은 홈 링커로 연결하지 않습니다.
- 모든 기기 간 연결·호출·메시지·영상·문열림은 같은 단지 규칙을 지킵니다. 무선수화기도 본체와 같은 단지 및 통신 범위 안에서만 동작합니다.

**현재 호환성 제한:** 기존 삼성 SHT-5500S는 앞선 요청대로 모델 전용 상태입니다. 그 기기에 임의의 경비 기능을 추가하지 않았습니다. SHT-101C의 BUS 경비실 통화를 사용하려면 실제 기능이 구현된 삼성 BUS 경비실기가 필요합니다. STAR 경비실·연결한 도어카메라·본체/수화기 내선·게임 내 전화는 현재 사용할 수 있습니다.

## 무선수화기와 통화

본체의 수화기 부분 또는 **수화기 들기**를 누르면 등록된 수화기를 인벤토리에 받습니다. 수화기를 손에 들고 우클릭하면 무선수화기 조작 화면이 열립니다. 웅크려 우클릭하면 수화기 전원을 켜고 끕니다. 수화기가 없는 본체 화면의 수화기 공간 또는 설치된 본체의 빈 거치대 부분을 클릭하면 인벤토리의 등록된 수화기를 찾아 다시 거치합니다. 본체를 수화기로 우클릭해도 거치합니다. 수화기는 본체의 고유 등록과 토큰을 확인하므로 다른 본체에 임의로 연결되지 않습니다. 이동 도구로 본체를 이동해도 저장된 등록을 찾습니다.

게임에서 무선 범위는 32블록이며 충전량은 약 30분 분량으로 단순화했습니다. 장착 후 다시 꺼내면 충전된 상태로 받습니다. 실물의 최초 12시간 충전을 기다리는 방식은 적용하지 않습니다. 전원 꺼짐·방전·범위 밖·다른 단지에서는 원격 조작을 거부합니다.

- **경비실**: 본체의 경비실 버튼으로 발신하고 무선수화기 통화 버튼으로 통화합니다. 무선수화기에서 경비실 버튼을 누르면 해당 경비실 경로로 발신합니다. 착신은 무선수화기의 통화 버튼으로 응답합니다.
- **현관**: 도어카메라에서 호출하면 영상이 표시됩니다. 무선수화기의 통화 버튼으로 응답합니다. 받지 않은 현관 호출은 설명서대로 15초 후 종료합니다. 문/열림 버튼으로 연결한 현관을 감시·호출할 수도 있습니다.
- **공동현관**: 방식에 맞는 로비폰에서 호출을 받고 통화 중 문/열림 버튼으로 문을 엽니다. 외출 상태의 공동현관 호출은 같은 단지의 호환 경비실 경로로 우회합니다. 지원하는 경비실/로비폰이 없으면 임의로 다른 방식에 연결하지 않습니다.
- **내선**: 본체 호출 → 수화기 통화, 또는 수화기 호출 → 본체 스피커 순서로 연결합니다.
- 통화 화면에서 **T 또는 입력란 클릭 → 메시지 입력 → Enter**로 전송합니다. 통화 중 다시 통화 버튼을 누르면 종료합니다. 게임 내 양방향 통신은 채팅 메시지로 표현합니다.
- 화면은 흑백 CRT이며 컬러 카메라를 연결해도 `VideoFormat.MONOCHROME`으로 표시합니다.

## 전화·기억·암호

실제 외부 전화망에 연결하지 않습니다. 같은 단지의 SHT-101C에 저장한 자택 전화번호를 찾아 호출하는 게임 내 전화 회선입니다.

| 기능 | 조작 |
|---|---|
| 자택 번호 저장 | 본체 메모리 → 스피커 → 번호 → 메모리 |
| 본체 암호 저장 | 본체 메모리 → 경비실 → 두 자리 → 메모리 |
| 수화기 암호 | 수화기 메모리 → * → # → 두 자리 |
| 고정장치 암호 | 본체 메모리 → 보류 → 두 자리 |
| 암호 일치 확인 | 수화기 메모리 → 본체 호출. 등록된 세 암호가 같으면 삐 안내 |
| 본체 단축번호 | 메모리 → 3–9 또는 *·# → 번호 → 메모리 |
| 수화기 단축번호 | 메모리 → 0–9 → 번호 → 메모리 |
| 단축번호 호출 | 본체 스피커 또는 수화기 통화 → 메모리 → 단축번호 |
| 원터치 번호 | 본체 메모리 → 소방·경찰·병원 버튼 → 번호 → 메모리 |
| 국선 발신 | 본체 스피커 → 번호, 또는 수화기 통화 → 번호. 입력 대기 후 발신하며 #으로 즉시 발신 |
| 재다이얼 | 재다이얼/재발신 → 무선수화기 통화 |
| 보류와 재통화 | 본체 보류 → 수화기 통화 |
| 국선 선택 | 메모리 → 재다이얼 → 0(기계식)/1(전자식) → 메모리 |
| 통화 중 전자식 전환 | * |
| 기억 확인 | 시험 → 스피커·경비실 또는 단축번호 |

## 경보와 조절

본체 비상 버튼 또는 같은 단지의 인접 레드스톤 접점으로 경보를 발생시킵니다. 접점 방향은 본체 기준 아래=화재, 앞을 바라본 오른쪽=가스, 왼쪽=방범, 위=비상입니다. 방범 접점은 방범 설정 중에만 감지합니다.

- 방범·외출 설정은 연결된 문이 닫힌 경우에만 됩니다. 외출 후 1분 뒤 방범을 설정합니다.
- 시험 → 1(화재) 또는 2(가스)로 내부 경보를 시험하고 복귀로 종료합니다. 시험은 실제 경비실·전화에 통보하지 않습니다.
- 실제 경보는 내부 30초 경보 후 호환 경비실에 알리고, 저장한 *·# 번호로 세 차례씩 자동통보를 시도합니다. 통화가 연결되면 경보 10초 → 자택 번호 2초 → 경보 10초를 메시지로 표현합니다. 112·113·119는 설명서대로 자동통보 번호로 등록하지 않습니다.
- 경보정지는 경보 표시를 남기며 통보를 정지합니다. 복귀로 해제하고, 정지 후 5분 내 복귀하지 않으면 자동 복귀합니다.
- ▲·▼는 착신 대기 중 벨 음량, 통화 중 수화 음량을 조절합니다. 밝기·명암 슬라이더는 CRT 영상에 반영합니다. 무선 채널 변경은 저장되며 실제 RF 간섭을 시뮬레이션하지는 않습니다.
- 본체 화면에서 로고 문구를 변경할 수 있습니다.

## 빌드와 보존

새 환경에서 이전 추가 제품 소스가 복원되지 않아 검증된 1.0.8 JAR를 SHA-256으로 고정하고 삼성 확장을 별도 소스 세트로 작성했습니다. `tools/samsung/package_release.py`가 최종 단일 JAR를 만들며 **기존 239개 클래스 전부를 바이트 단위로 보존**하는지 확인합니다. 기존 코콤·현대 구현을 다시 컴파일하거나 덮어쓰지 않습니다.

JDK 17과 Gradle 8.8을 활성화한 뒤 저장소 루트에서 실행합니다.

```bash
bash tools/samsung/prepare_baseline.sh
python3 tools/samsung/generate_assets.py
python3 tools/samsung/check_assets.py
gradle -b samsung.gradle build
python3 tools/samsung/package_release.py
```

산출물은 `build/samsung/release/qwertys_homenet-1.0.10.jar`입니다. 기존 HomeNet JAR를 제거하고 이 단일 JAR로 교체합니다. 멀티플레이는 서버와 클라이언트 모두 교체합니다. 삼성 확장 단독 JAR를 기존 JAR와 혼용하지 않습니다.

검사: 전용 게임 테스트 13개(삼성 BUS 접수/응답/채팅, 실제 기존 STAR 경비실 호출, 카메라, 무선 등록/범위/단지, 전화 보류/통보, 경보, 암호 순서/채널 저장)와 실제 클라이언트의 홈 링커·분리·원격 조작·한글 채팅·답신 경로를 확인했습니다. 게임 테스트는 `gradle -b samsung.gradle -Psamsung.runDir=/tmp/sht-fresh-test runGameTestServer`, 클라이언트 검사는 `-I tools/samsung/client_checks.gradle runClient`를 사용합니다. 새 테스트 월드를 사용하며 동작 사진과 스크린샷은 생성하지 않습니다.
