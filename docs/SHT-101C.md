# 새 삼성 SHT-101C (1.0.21)

이 모델은 이전 SHT-101C 코드와 리소스를 복구하지 않고 새로 작성했습니다. 새 모듈 ID는 `homenet_sht101c`이며 예전 삼성 확장의 ID·클래스·리소스를 포함하지 않습니다. 기존 코콤·현대 기능은 검증된 1.0.8 JAR의 239개 클래스를 그대로 보존합니다.

## 1.0.21 비상버튼 비발광·외부 틀 중앙 정렬·미세한 버튼 곡면

비상버튼의 발광 표시를 제거했습니다. 비상 경보 기능은 유지하지만 본체와 조작화면에서 버튼에 불은 켜지지 않습니다. 다른 표시등과 경보 렌즈는 유지합니다.

본체 경계 [110,89,934,672]의 중심에 외부 틀 중심을 맞췄습니다. 외부 틀 경계는 [74.5,54.5,969.5,706.5]이며 기존보다 아래로 6.5 좌표 단위(약 3.94mm), 왼쪽으로 1.5(약 0.91mm) 이동합니다. 위아래 여백은 각각 34.5, 좌우는 각각 35.5 좌표 단위로 같습니다. 외부판 크기·0.5mm 두께와 본체 자체 위치·깊이는 유지합니다. 조작화면 캔버스와 클릭 좌표, 설치 블록의 아래쪽 클릭 범위도 새 외곽에 맞췄습니다.

비상버튼을 제외한 중앙의 방범·외출·메모리·보류·재다이얼·경비실·문/열림·스피커 버튼은 동일한 깊이의 아주 얕은 볼록면을 사용합니다. 중앙 돌출은 종전보다 약 0.26mm 증가하며, 가장자리와 버튼 위치·간격은 유지합니다. 수화기 형상과 조작화면은 변경하지 않습니다.

## 1.0.20 경계선 굵기 원상복귀

경계마다 굵기·깊이·음영을 다르게 한 1.0.19 변경을 되돌렸습니다. 모든 접합선은 1.0.18과 같은 폭 2.2 좌표 단위, 깊이 1.2, 색상 #929584를 사용합니다. 사진을 기준으로 맞춘 시작점·끝점과 삼성 로고 영역 아래의 가로 경계는 유지합니다. 외부 틀 0.5mm, 본체 곡면, 램프와 통화 동작은 유지합니다.

## 1.0.19 정면 사진 기준 경계선 재구분

새 정면 사진의 이음 위치와 강도를 따로 적용했습니다. 모든 부품에 같은 굵기와 깊이의 테두리를 두르지 않습니다.

- 중앙 버튼 열과 모니터 모듈 사이의 세로 이음(x=518)은 본체 위(y=89)부터 맨 아래(y=672)까지 이어지는 가장 강한 경계입니다.
- 거치대·숫자 조작부·중앙 버튼 열·모니터 조절부 사이의 선은 중앙 이음보다 가늘고 얕게 했습니다.
- 좌우 측면 덮개 경계는 가장 연한 접합선으로 나누고, 상하 끝까지의 연결 범위를 따로 맞췄습니다.
- 삼성 로고/상태 표시 영역과 아래 숫자 조작부 사이의 가로 이음(x=298~456, y=230)을 추가했습니다.
- 상·하단 접합선도 얇은 패널 이음으로 표현합니다. 조작화면에는 동일한 선을 안티앨리어싱하여 표시합니다.

각 경계의 폭·깊이·색상·시작점·끝점을 모델 데이터에서 따로 지정하며, 표면을 실제로 얕게 파서 끊김 없이 연결합니다. 수화기·좌우 곡면·외부 틀 0.5mm·표시등·통화 기능은 유지합니다. 메시 검사에서 각 이음의 위치·깊이와 중앙 이음의 전체 높이 연결을 확인합니다.

## 1.0.18 표시등 동작 수정

본체와 조작화면이 같은 표시등 정의와 서버 상태를 사용합니다. 전원은 적색, 충전·방범설정·외출설정·현관·경비실·국선 사용 표시는 녹색 계열로 표시합니다. 화재는 적색, 가스는 황색, 방범 경보는 녹색 원형 렌즈에 표시하고 비상 상태도 표시합니다. 본체의 점등 부위는 발광 렌더링으로 주변 어두움에 묻히지 않게 했습니다. 형상·좌표와 0.5mm 장착판은 유지합니다.

- 충전 표시는 거치 시 켜지고 분리 시 꺼집니다.
- 설명서대로 외출 설정 시 외출·방범설정 표시를 켜며, 실제 방범 감시는 1분 뒤 활성화합니다.
- 현관 표시는 감시·현관/공동현관 착신·통화 중에 켜지고 종료 시 꺼집니다. 공동현관을 경비실 표시로 잘못 분류하지 않습니다.
- 국선 표시는 스피커 국선 선택·전화 착신/발신·통화·보류 상태를 나타내며 본체↔무선수화기 내선만 사용할 때에는 켜지지 않습니다.
- 경보정지는 소리만 멈추고 경보등은 유지하며, 복귀하면 해당 경보등이 꺼집니다. 조작화면에 경보 렌즈 표시가 빠졌던 문제를 수정했습니다.
- 통화·타이머로 상태가 바뀌면 표시등 변화를 본체에도 동기화합니다. 전화 자동 종료 후 국선 선택 상태가 남는 문제도 수정했습니다.

서버 기능 검사와 실제 클라이언트에서 상태 패킷, 조작화면과 본체의 일치, 발광 메시·앞면 방향, 경보정지/복귀를 검사합니다. 조작 화면 이미지나 스크린샷은 생성하지 않습니다.

## 1.0.17 외부 틀 0.5mm·본체 경계

외부 장착판을 **0.0005블록(0.5mm)**로 변경했습니다. 본체·버튼·화면·표시등·거치된 수화기도 기존보다 0.2mm 앞으로 함께 이동하며 본체 자체 깊이와 좌우 곡면은 유지합니다. 본체 평면의 벽으로부터 거리는 약 15.06mm입니다.

좌우 측면 덮개·수화기 거치부·숫자 조작부·중앙 기능키 열·모니터·화면 조절부를 구분하는 세로 접합선 6개와 상하 접합선 4개를 실제 표면의 얕은 홈으로 표현했습니다. 홈 폭은 약 1.3mm, 깊이는 약 0.62mm이며 어두운 중심선과 가장자리 음영으로 경계를 선명하게 했습니다. 부품 사이가 뚫리거나 막대가 따로 뜨는 형태는 만들지 않습니다. 조작화면의 경계도 같은 위치에 표시합니다.

수화기와 스피커 통화, 대기 중 현관 영상 감시, 영상 지원 제품의 본체 착신 표시는 유지합니다. 실제 메시에서 0.5mm 외부판과 10개 접합선의 연속된 표면을 확인합니다.

## 1.0.16 사진 기준 좌우 곡면·스피커 통화

정면 사진에서 좌측 곡면 띠는 x=110~154, 우측은 x=891~934에 해당합니다. 내부 본체 폭 824 좌표 단위 중 각각 44(약 5.34%)·43(약 5.22%)입니다. 0.5블록 폭 기준으로 약 26.7mm·26.1mm 구간이며 중앙의 평평한 전면과 접선이 이어지고, 바깥으로 갈수록 기울기가 커지는 타원형 단면으로 측면에 연결합니다. 가장자리의 전면 높이는 중앙보다 약 5.2mm 낮게 설정했습니다. 종전의 마지막 12 좌표 단위에만 있던 작은 굽힘을 넓혔으며 앞면보다 솟는 봉 형태는 만들지 않습니다. 이 수치는 원근이 있는 사진과 정면 사진을 맞춘 모델링 추정치이며 실측 반경은 아닙니다. 외부판 0.3mm, 본체 위치·깊이, 수화기 형상은 유지합니다.

본체 스피커 버튼으로 현관·경비실 착신에 응답하고, 현관 영상 감시에서 통화로 전환하며, 국선 발신·착신 통화도 할 수 있습니다. 다시 누르면 통화를 종료합니다. 수화기를 들 필요가 없고, 기존 본체↔무선수화기 내선·메모리 설정 동작은 유지합니다. 게임 내 대화는 기존 통화 메시지 방식입니다.

## 1.0.15에서 유지한 외형·조작·본체 착신 영상

외부 장착판은 **0.0003블록(0.3mm)**로 종전 0.2mm보다 조금 두껍게 했습니다. 본체·화면·표시등·거치된 수화기도 같은 0.1mm만큼 함께 이동합니다. 본체 덮개 깊이는 24 좌표 단위(약 14.56mm)를 유지하며 앞면은 벽에서 약 14.86mm입니다. 양 끝에 솟아오르던 둥근 봉 형태를 없애고 평평한 앞면에서 측면으로 내려가도록 했습니다. 수화기 형상과 조작화면은 유지합니다.

대기 중 **본체 문/열림**은 30초 현관 영상 감시만 시작합니다. 현관 기기에 호출을 보내거나 통화를 연결하지 않습니다. 연결된 현관·공동현관 통화 중에는 문열림 기능을 유지합니다. 무선수화기의 배터리·채널 상태 갱신은 아이템을 다시 꺼내는 애니메이션을 일으키지 않습니다. 슬롯이나 등록된 수화기 자체가 바뀌면 정상 장착 애니메이션을 유지합니다.

영상 지원 본체는 조작화면을 열지 않아도 착신 시 실제 본체 화면에 영상을 표시합니다. KVM 13종, 일반 비디오폰·월패드에 기존 렌더러를 유지하는 영상 덧그리기를 추가했고 HA-4100H·SHT-101C의 본체 영상 경로도 검사합니다. SHT의 사진 좌표와 영상 렌더러의 1/16 모델 좌표 단위 차이도 수정했습니다. 단지 경계와 KAM 공동현관 영상 허용 범위, 흑백·컬러 규격을 유지합니다. 음성 인터폰, LED·문자·숫자 표시창, 기능 미구현 SHT-5500S는 영상 대상으로 취급하지 않습니다. 기존 영상 방식과 같이 카메라 주변 청크가 클라이언트에 로드되어 있어야 실제 장면을 그릴 수 있습니다.

서버 기능 검사 14개와 캡처 없는 실제 클라이언트 검사로 배터리 애니메이션·감시 전용 동작·거치 동작·영상 패킷·화면 메시를 확인합니다. 게임 화면 이미지나 스크린샷은 생성하지 않습니다.

## 외형

사용자가 올린 바닥 위 측면·정면·수화기 앞면 사진과 선으로 표시한 비율 사진을 함께 기준으로 삼았습니다. 안테나를 제외한 파란 내부 영역 가로는 정확히 0.5블록입니다. 바깥 틀은 약 0.543083 × 0.395631블록입니다. 안테나는 블록 밖으로 나올 수 있습니다.

밝은 아이보리 본체, 별도 장착판, 전면에서 측면으로 완만하게 휘는 양 끝 덮개, 좌측 충전 거치대, 후크·충전 접점·스피커 슬롯, 중앙 기능 버튼 열, 숫자키, 하단 통풍구, 들어간 흑백 CRT 화면을 새로 구성했습니다. 수화기 뒷면과 앞면을 구분하고 앞면에 오목한 수화부·검은 타원 숫자키·검은 기능키·충전 접점을 배치했습니다. 같은 줄 버튼의 앞면 높이와 돌출 깊이는 같습니다. 곡면·모서리는 실제 메시와 법선으로 음영을 계산합니다.

수화기 안테나는 수직이고 본체 가운데 안테나는 처음 설치하면 접힌 상태입니다. 본체 안테나는 조작 화면에서 펼 수 있습니다. 외부 배선, 사진 배경, 변색·오염과 광고는 모델에 포함하지 않습니다. 동작 사진·스크린샷은 생성하지 않습니다.

## 방식과 연결

- 크리에이티브 `SAMSUNG SHT-101C` 탭에서 본체를 설치합니다.
- 본체 화면의 `BUS / STAR`로 방식을 선택합니다. 수화기를 거치하고 통화를 종료해야 변경할 수 있으며 변경 시 이전 경비실 연결을 해제합니다.
- BUS는 삼성 디지털 BUS 규격의 경비실기와만 연결합니다. 코콤·현대 BUS로 우회하지 않습니다. 동·호 번호는 경비실에서 지정합니다.
- STAR는 같은 단지의 STAR 경비실 통화 경로를 사용하며 본체에서 동·호 번호를 입력할 수 있습니다.
- 도어카메라·도어폰은 홈 링커로 본체 → 세대 외부기기 순서로 연결합니다. 홈 링커로 경비실을 연결하지 않습니다.
- 단지가 다른 기기는 연결·호출·영상·메시지·문열림을 허용하지 않습니다.

**현재 제공 기기 제한:** 기존 삼성 SHT-5500S는 모델 전용이므로 BUS 교환기 역할을 새로 부여하지 않았습니다. BUS 경비실 통화에는 기능이 구현된 삼성 BUS 경비실기가 필요합니다. 본체의 BUS 경로는 삼성 BUS 시험 교환기로 검증하고 STAR 경로는 기존 실제 STAR 경비실기로 검증합니다.

## 수화기와 통화

본체 화면의 수화기 부분을 누르면 무선수화기를 받습니다. 수화기를 손에 들고 우클릭하면 앞면 조작 화면이 열립니다. 웅크리고 우클릭하면 전원을 전환합니다. 수화기가 들려 있을 때 **본체 화면의 빈 수화기 자리 또는 벽에 설치된 본체의 빈 거치대를 클릭**하면 인벤토리의 해당 수화기를 찾아 다시 겁니다. 선택한 손에 수화기가 없어도 됩니다. 다른 본체의 수화기는 받아들이지 않으며 거치 시 통화를 종료합니다.

무선 범위는 같은 단지 안의 32블록입니다. 충전·배터리는 게임용으로 단순화하여 약 30분을 사용하고 재거치하면 충전된 수화기를 받습니다. 실물 최초 12시간 충전과 실제 RF 간섭은 재현하지 않습니다.

| 본체에서 경비실 발신 | 본체 경비실 → 무선수화기 통화 |
| 수화기에서 경비실 발신 | 수화기 경비실 |
| 경비실·현관·공동현관 착신 | 무선수화기 통화 |
| 현관 감시·통화 | 본체 문/열림으로 감시 → 스피커로 통화, 또는 무선수화기 문/열림 |
| 공동현관 문열림 | 공동현관 통화 중 문/열림 |
| 본체 → 수화기 내선 | 본체 호출 → 수화기 통화 |
| 수화기 → 본체 내선 | 수화기 호출 → 본체 스피커 |
| 통화 종료 | 수화기 통화 또는 다시 거치 |
| 메시지 | T 또는 입력란 클릭 → 입력 → Enter |

현관 착신을 15초 안에 받지 않으면 종료합니다. 영상은 흑백이며 카메라의 컬러 영상을 흑백으로 표시합니다. 밝기·명암을 조절할 수 있습니다. 게임 안의 양방향 통화는 채팅 메시지로 구현합니다.

## 전화·기억·암호

외부 전화망에 접속하지 않습니다. 같은 단지의 다른 새 SHT-101C에 등록된 자택 전화번호로 연결하는 게임 내 전화입니다.

- 자택 번호: 본체 메모리 → 스피커 → 번호 → 메모리.
- 본체 암호: 본체 메모리 → 경비실 → 두 자리 → 메모리.
- 수화기 암호: 수화기 메모리 → * → # → 같은 두 자리.
- 고정장치 암호: 본체 메모리 → 보류 → 같은 두 자리.
- 암호 확인: 수화기 메모리 → 본체 호출. 세 암호가 같으면 일치 안내.
- 단축번호 저장: 메모리 → 단축키 → 전화번호 → 메모리. 본체는 3–9·*·#, 수화기는 0–9를 사용합니다.
- 단축번호 발신: 본체 스피커 또는 수화기 통화 → 메모리 → 단축키.
- 원터치 저장: 본체 메모리 → 소방·경찰·병원 버튼 → 번호 → 메모리.
- 발신: 본체 스피커 또는 수화기 통화 → 번호. 입력이 끝나면 발신하며 #으로 즉시 발신할 수 있습니다.
- 재다이얼: 본체 재다이얼 → 수화기 통화. 수화기 재발신으로 국선 통화로 전환할 수 있습니다.
- 보류: 본체 보류, 재통화는 수화기 통화.
- 국선 선택: 본체 메모리 → 재다이얼 → 0/1 → 메모리. 통화 중 *은 전자식 선택입니다. 실제 전화국 펄스 신호는 재현하지 않습니다.
- 채널전환은 저장되며, ▲·▼는 통화 중 수화 음량 또는 대기 중 착신 음량을 바꿉니다.

## 경보

비상 버튼과 레드스톤 감지 입력을 제공합니다. 아래 접점은 화재, 위는 비상, 동쪽은 가스, 나머지는 방범입니다. 방범은 방범 설정 상태에서만 감지합니다. 열린 문이 있으면 방범·외출을 설정하지 않으며 외출 후 1분 뒤 방범이 설정됩니다.

시험 → 1/2로 화재/가스 내부 경보를 시험합니다. 시험은 경비실·전화에 통보하지 않습니다. 실제 경보는 30초 내부 경보 후 호환 경비실과 저장된 *·# 번호로 순서대로 통보하며 각각 세 번씩 시도합니다. 게임 내 자동통보는 경보·자택 번호 메시지로 표현합니다. 112·113·119는 자동통보 번호로 등록하지 않습니다.

경보정지는 표시를 남기고 통보를 멈춥니다. 복귀로 초기화하며, 정지 후 5분이 지나면 자동 복귀합니다.

## 검증

전용 게임 테스트 16개로 BUS/STAR 호출, 실제 STAR 경비실 연동, 현관 영상·통화·15초 종료, 빈 거치대의 네 방향 클릭, 수화기 소유권·범위·단지 제한, 전화 기억·보류, 암호·경보·자동통보·저장을 검사하며 대기 문/열림의 무호출 감시, 수화기 배터리 갱신 애니메이션, 영상 지원 여부와 착신/종료도 확인합니다. 실제 클라이언트 검사에서는 홈 링커 패킷, 수화기 분리·조작, 현관 응답, 한글 입력·양방향 메시지와 빈 거치대 클릭 후 상태 갱신, 17개 모델의 착신 시 영상 메시와 통화 종료 후 영상 제거를 확인합니다.

최종 산출물 `build/sht101c/release/qwertys_homenet-1.0.21.jar` 하나로 교체합니다. 서버와 클라이언트 모두 기존 JAR를 제거하고 교체 후 재시작합니다. 별도 확장 JAR와 중복 설치하지 않습니다.
