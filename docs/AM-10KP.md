# KOCOM AM-10KP 디지털 경비실기

Minecraft Java 1.20.1 / Forge 47.x. 크리에이티브 HomeNet 탭에서 AM-10KP를 꺼내 책상이나 바닥에 설치합니다. 수화기·조작면·모서리·숫자 버튼을 입체 모델로 구성했고, 조작면은 앞이 낮고 뒤가 높은 12° 기울기입니다. 사진의 가로형 비율(약 1.56:1)을 유지하며 모든 부품은 가로·세로 1블록 안에 들어갑니다. 외부 전선은 생략합니다.

## 연결과 세대번호 등록

AM-10KP는 **코콤 BUS 디지털 경비실기**입니다. KVM-930·960·933·940R3을 지원합니다. STAR 아날로그 KVM-906·940, 경비 기능이 없는 KVM-904, 다른 제조사 BUS 기기는 연결할 수 없습니다. KAM-305도 추가되었습니다. [KAM-305 사용법](KAM-305.md)을 참고하세요.

1. 경비실기 링크 아이템으로 비디오폰 여러 대를 서서 클릭합니다. 같은 기기를 다시 클릭하면 선택이 해제됩니다.
2. 웅크리고 AM-10KP를 클릭해 일괄 연결합니다. 선택·연결·저장 세대수에 별도의 상한이 없습니다.
3. 경비실에서만 등록하는 모델에는 링크 시 무작위 동·호수를 부여합니다. 비디오폰의 수화기를 들고 경비 버튼으로 호출합니다.
4. AM-10KP를 우클릭해 조작 화면을 엽니다. 수화기를 클릭해 들고, 호출이 표시된 통화1~4 버튼을 누릅니다.
5. **세대가 경비실에 건 통화 중** 숫자 다이얼에서 `**00*`를 누릅니다. 새 동 번호 → **동** 버튼 → 새 호 번호 → `*` 순서로 등록합니다. 번호가 비디오폰과 경비실기에 함께 저장됩니다.

940R3에는 비상 버튼·비상 기능이 없으며, 동·호수는 이 절차로 등록합니다. 940·940R3의 전원/국선 표시부와 현관·경비·개폐 버튼도 사진에 맞춰 어두운 사각 형태와 색상 아이콘으로 수정했습니다.

## 통화와 표시

- 4개 세대 회선을 각각 표시·응답합니다. 호출 중에는 해당 표시등이 점멸하고, 연결되면 계속 켜집니다. 통화 버튼으로 선택한 회선에 메시지를 보냅니다.
- 경비실에서 세대로 호출: 수화기 → 동 번호 → 동 버튼 → 호 번호 → `#`. 동 번호를 생략하면 경비실 자체 번호를 동 번호로 사용합니다.
- 호출 후 30초 동안 응답이 없으면 종료하며 통화는 3분 후 종료합니다. 전원을 끄거나 기기를 제거해도 상대 통화가 정리됩니다.
- 경비실 번호 등록: 통화가 없는 상태에서 **상호** → `**00*` → 새 번호 → `*`. 같은 번호의 다른 경비실기는 등록할 수 없습니다.
- 경비실 간 통화: 수화기 → 상호 → 상대 경비실 번호 → `#`. 상대가 수화기를 들고 상호 버튼을 눌러 응답합니다. 최대 100개 경비실기를 지원합니다.
- 세대 간 교환: A세대와 통화 중 **교환** → B세대 번호를 입력해 호출합니다. B가 응답한 뒤 경비실 수화기를 내려놓으면 A↔B 통화로 전환됩니다. 교환 버튼을 다시 누르거나 `*`를 누르면 교환 호출을 취소합니다.
- 비상 지원 세대의 경보를 최대 10세대까지 순환 표시합니다. 세대마다 표시가 두 번 점멸하고 경보음이 울립니다. **비상** 버튼은 경보음만 멈추며 표시·비상 상태는 유지합니다. 새로운 비상이 들어오면 경보음이 다시 울립니다. 세대의 비상 버튼을 다시 눌러 해제합니다. 비상 중 `#`는 현재 표시된 비상 세대만 호출합니다.
- 외출 상태의 세대를 호출하면 부재 표시가 켜집니다. 외출 기능이 있는 세대의 연결된 도어카메라 호출은 경비실로 우회해 현관과 통화할 수 있습니다.
- 경비실 부재 전환: 오른쪽 **부재 전환 대상** 버튼으로 설치된 다른 AM-10KP를 선택하고 오른쪽 **경비실 부재 전환** 버튼을 누릅니다. 본체의 **부재 / 동** 버튼은 입력한 동 번호를 확정하고 호수 입력으로 전환합니다. 세대 호출을 다른 경비실에서 받고 끊을 수 있습니다.
- 음량 슬라이더는 3단계, 멜로디 전환은 2가지입니다. 실제 음성 입력 대신 모드의 통화 메시지 기능을 사용합니다. 도어 개폐는 기존 모델별 허용 조건을 유지합니다.

동·호수·경비실 번호·링크·음량·멜로디·부재 전환 설정은 저장됩니다. 재접속 시 진행 중인 통화는 재개하지 않으며, 로드된 비디오폰의 비상·외출 상태는 경비실에 다시 반영합니다. 멀리 떨어진 기기가 청크 밖에 있으면 로드된 뒤 신호를 처리합니다.

## 검증

실제 AM-10KP 본체를 사용하는 게임 테스트로 연결 규격, 등록·저장, 4회선 한도, 비상/경보음 정지, 시간 제한, 세대 간 교환, 경비실 간 통화, 현관 우회, 부재 전환과 종료를 확인합니다. 테스트 전용 기기와 캡처 도우미는 배포 JAR에 포함하지 않습니다.

본체의 부재/동 버튼 아래에는 **동**이 인쇄되어 있으며 동 번호 입력 확정에 사용합니다. 교환 상대가 응답하면 3자 통화가 가능하고, 경비실 수화기를 내려놓으면 세대끼리 직접 통화합니다.

수정된 실제 게임 화면은 [경비실 통화 표시](screenshots/kvm930-guard-call.png), [940 버튼](screenshots/kvm940-controls.png), [940R3 버튼](screenshots/kvm940r3-controls.png), [AM-10KP 조작면](screenshots/am10kp-console.png)에서 확인할 수 있습니다.
