# 삼성 SHT-102C

사진의 유선 수화기형을 별도 블록 `homenet_sht101c:sht_102c`로 추가했습니다. 배포 파일명은 `qwertys_homenet.jar`이며 버전을 붙이지 않습니다. Minecraft 1.20.1 / Forge 47.3.0용입니다.

## 형상

본체 가로 0.5블록, 외부 장착판 0.5mm 및 중앙 정렬을 SHT-101C와 공유합니다. 직선형의 납작하고 폭이 좁은 밝은 아이보리 유선 수화기, 변경된 거치부, 넓어진 램프·시험·숫자 패널과 단일 원형 전원등을 적용했습니다. 수화기에 안테나와 전화선을 만들지 않습니다. 중앙 안테나는 검은색이며 처음에는 세워져 있습니다.

비상버튼 열의 가로 위치와 버튼 크기·돌출 정도, 모니터와 화면조절 스위치의 위치·크기는 SHT-101C와 같습니다. 메모리 버튼은 외출 바로 아래로 이동하고 그 아래에 공백을 둡니다. 현관과 국선은 기존 문/열림과 스피커 위치를 그대로 사용하며 국선 아래 공백을 유지합니다. 생성기는 이 조건들을 검사합니다. 오른쪽 영역과 SHT-101C 무선수화기 리소스는 변경하지 않습니다.

## 조작

- 유선 수화기 공간 또는 수화기 들기/걸기 버튼으로 들거나 걸 수 있습니다. 별도 인벤토리 아이템은 생성하지 않습니다. 들린 상태에서도 거치 공간을 누르면 걸립니다.
- BUS 공동현관 착신에는 수화기를 들어 통화한 뒤 `*`을 누르면 연결된 공동현관 문이 열립니다. STAR도 지원합니다. 현관/공동현관 통화 중 문열림은 `*`을 사용합니다.
- 대기 중 현관은 현관 영상 감시입니다. 수화기를 들면 통화하고, 현관/공동현관 통화 중 현관 버튼은 문을 열지 않고 영상과 통화를 유지합니다. 별도 문열림 버튼은 없습니다.
- 국선은 수화기를 놓은 상태에서도 발신·단축번호를 선택할 수 있습니다. 번호 입력 후 `#` 또는 잠시 기다리면 발신하며, 상대 응답 후 수화기를 들어 대화합니다. 실제 전화망 대신 같은 단지의 게임 내 전화번호를 사용합니다.
- 메모리 → 국선 → 국선 → 번호 → 메모리로 자택 전화번호를 저장합니다. 메모리 → 국선 → 단축키 → 번호 → 메모리로 단축번호를 저장합니다. 국선/수화기 들기 → 메모리 → 단축키로 발신합니다.
- 보류 후 수화기를 걸어도 연결은 보류되며 국선 또는 수화기 들기로 재개합니다. 보류는 3분 뒤 종료됩니다.
- 경비실, 재다이얼, 원터치 전화, 방범/외출, 시험/경보정지/복귀, 비상 기능은 해당 키로 조작합니다. 비상버튼은 발광하지 않습니다.
- PDF의 별도 무선 휴대장치와 충전기를 추가했습니다. 휴대장치가 놓인 충전기와 무선 지원 삼성 세대내 기기를 **홈링커로 연결**한 뒤 들고 거치할 수 있습니다. SHT-101C와도 공통 연동합니다. [휴대장치 설치·조작](SHT-102C-휴대장치.md)을 참고하세요. SHT-101C 무선수화기와는 별개입니다.

## 세대번호

SHT-101C와 SHT-102C의 본체 조작화면에 `101-1001` 형식으로 입력하고 동·호 설정을 누릅니다. BUS와 STAR 모두 직접 설정할 수 있습니다. BUS 세대아이디로 번호를 부여하는 실물 절차를 대체하는 사용자 요청의 임시 설정입니다. 기존 모델 전용 SHT-5500S도 빈손으로 클릭하면 동·호 저장 화면이 열립니다. SHT-5500S의 기존 통신 미지원 상태는 유지합니다.

같은 단지·거리 제한 및 BUS/STAR 연결 기기 구분은 유지합니다. 설명서는 제품 기능 자료로만 사용했습니다. 실제 게임 화면이나 조작 이미지, 스크린샷은 생성하지 않습니다.

## 검증

서버 기능 검사 33개를 통과했으며 홈링커 공통 연결 및 BUS 공동현관 `*` 문열림을 포함합니다. 휴대장치·충전기를 포함한 검증은 [휴대장치 문서](SHT-102C-휴대장치.md)를 참고하세요. BUS/STAR 동·호 저장과 재로드, 기존 삼성 모델의 입력 검증·거리 제한, 유선 현관 감시/착신/통화/거치, 국선 온훅 발신·수화기 응답·거치 중 보류·재통화와 기존 SHT-101C 기능을 확인합니다.

실제 클라이언트에서 새 블록/렌더러/조작화면, 유선 수화기 클릭과 동기화, 열린 CRT 메시, 기존 수화기 리소스 보존, 18종 본체의 착신 영상·통화 종료 후 영상 해제를 확인했습니다. 모델 생성기는 고정된 오른쪽 부품과 중앙 버튼 크기를 비교합니다. 게임 화면 이미지는 만들지 않았습니다. 배포 JAR는 기존 제품 클래스 239개를 바이트 단위로 보존합니다.

서버와 클라이언트 모두 기존 통합 JAR를 제거하고 `qwertys_homenet.jar` 하나로 교체한 뒤 재시작하세요.
