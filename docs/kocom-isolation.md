# 코콤 복구 기준과 전용 경로

복구 기준은 HMC-7000 최초 추가(65f838a) 직전 배포 커밋 `8ee17a7`의 `qwertys_homenet.jar`입니다.

이 배포본과 현재 배포 JAR를 직접 비교했습니다. AM-10KP, KAM-305, KVM, IP, KIP, KLP, 소형 인터폰, KGP/월패드 및 공통 수신기의 핵심 클래스 25개는 바이트 단위로 동일합니다. 관련 모델·텍스처·제품 정의 리소스 494개도 동일합니다. 이 구현은 교체하지 않았습니다. 코콤 전용 모델·치수·기능을 현대 구현으로 덮어쓰지 않습니다.

`kocom.KocomCallRoute`에서 코콤 기기의 조작을 기존 코콤 핸들러에 전달합니다. 코콤 수신기의 거리·근처 알림 기준은 HMC 생성 전과 같은 블록 중심으로 복원합니다. 현대 기기는 이 경로에 들어갈 수 없습니다.

HMC-7000은 이제 코콤 `Am10kpBlockEntity`를 상속하지 않습니다. 별도 `HyundaiBusConsoleBlockEntity`를 사용하며 현대 관리실 검색도 현대 구현으로 제한합니다. 코콤 AM-10KP와 KAM-305의 상속 및 호출 구현은 기존 그대로 유지합니다. 저장된 세대 등록과 NBT 키는 유지합니다.

이전 1.0.7 배포 JAR에서는 `IntercomCaller`의 위치 메서드 선언과 호출 이름의 재매핑이 일치하지 않았습니다. Minecraft 이름과 충돌하지 않는 `intercomPosition`으로 인터페이스를 바꾸고, `tools/check_release_call_linkage.py`로 실제 배포 JAR의 인터페이스 참조를 검사합니다. 이전 JAR에서는 실패하고 새 JAR에서는 통과하는 검사입니다.

단지 연결 제한, 흑백 영상 규칙, 홈 링커의 세대 내부/외부 기기 전용 제한은 유지합니다. 현대 기기나 단지 대시보드 자체를 과거 버전으로 되돌리지 않습니다.
