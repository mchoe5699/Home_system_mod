# KOCOM KLP-203RF

코콤 BUS 디지털 공동현관 로비폰입니다. 첫 사진의 폭:높이 비율 약 0.764를 기준으로 검은 카메라 창, 좌우 IR 창, 4자리 붉은 세그먼트, 엇갈린 가로 스피커 슬롯, 금속 원형 12키와 호출 버튼 2개, 돌출된 곡면 CARD 리더를 구현했습니다. 낡아서 지워진 글자와 카드 문양은 복원한 상태입니다. 아이템과 조작 화면도 같은 부품·배치를 사용합니다.

## 설치

경비실기 링크로 로비폰을 선택하고 웅크려 AM-10KP 또는 KAM-305를 선택합니다. 로비폰의 경비번호가 해당 경비실기의 번호와 같아야 통신합니다. 별도 링크가 없으면 같은 번호를 가진 가장 가까운 호환 경비실기를 찾습니다. 확실한 배선 지정에는 링크 도구를 사용하세요. 문 링커로 로비폰을 선택한 뒤 출입문을 선택하면 해당 로비폰의 문 릴레이에 연결됩니다.

KVM-933·KVM-940R3 등 호환 BUS 수신기와 KIP-234R2가 같은 경비실기에 연결되어 있어야 합니다. IP-203APB는 음성 수신기로 사용합니다. 경비실 전용 IP-200PC·IP-200PCHB와 경비 기능이 없는 DP-202H는 로비 통화 대상에 포함하지 않습니다.

## 조작

- 호수 → 세대호출: 설정한 동의 해당 호수를 호출합니다. 뒤 두 자리가 지정 범위 안에 있어야 합니다. 예를 들어 03~10이면 903호·1810호를 호출할 수 있습니다. 동과 호수는 각각 1~9999입니다.
- 경비실: 지정 번호의 연결된 디지털 경비실기를 호출합니다. KAM-305는 수화기를 들어 받고, AM-10KP는 수화기를 든 뒤 숫자 5로 로비 회선을 받습니다.
- 연결되면 로비 조작 창의 메시지로 음성 대화를 대신합니다. 영상 수신기가 연결된 경우 응답 후 로비 카메라 영상을 제공합니다. 수화기형 인터폰은 영상이 없습니다.
- `*`: 입력·호출 취소. 통화 종료 버튼으로도 끊습니다. 수신기의 지원되는 로비 문열림 버튼은 통화 중 해당 로비의 문을 엽니다.
- `호수 # 세대 비밀번호 #`: 해당 세대 암호로 문열림.
- `경비번호 # 해당 로비 출입 비밀번호 #`: KAM-305 로비 관리에서 해당 로비에 지정한 암호로 문열림. 예: `10#9999#`.
- 비밀번호 입력 숫자는 세그먼트와 조작 화면에 `-`로만 나타납니다.
- RF 카드를 들고 로비폰을 우클릭하면 등록 카드를 인식합니다. 관리자로 인증한 상태에서는 카드를 등록할 수 있으며 관리자 창에서 손에 든 카드의 등록·삭제도 가능합니다.

세대 비밀번호 변경은 **해당 세대와 통화 연결 중에만** 가능합니다. `##00#`를 순서대로 누르면 `====` 표시와 경보가 10초간 이어집니다. 표시가 `----`로 바뀐 뒤 새 비밀번호 네 자리와 `#`를 누르면 `YES`를 표시하고 통화 중인 세대에 저장합니다. `0000`은 비밀번호를 삭제합니다. 경보 10초 동안이나 새 비밀번호 입력 도중 통화가 끊기면 변경을 취소합니다. 대기 중이거나 경비실과 통화할 때는 변경할 수 없습니다. 호수는 따로 입력하지 않습니다.

## 관리자 설정 창

제품의 **세대호출(C) + 경비실(G)** 버튼을 동시에 3초 누릅니다. 마우스 왼쪽/오른쪽으로 각각 두 버튼을 유지하거나 키보드 C와 G를 함께 유지합니다. 관리 비밀번호 네 자리(초기 `9999`)와 `#`를 입력하면 설정 창이 열립니다. 키보드 Enter는 `#`, Backspace는 `*`입니다. 짧은 동시 누르기는 관리자 인증으로 처리하지 않습니다.

직접 입력하는 항목:

1. 동 번호·라인 번호: 각각 1~9999.
2. 경비번호: 실제 연결 경비실기와 일치해야 합니다.
3. 호출 호수 범위: `00~99` 형식의 시작~끝 두 자리. 예: `03~10`.
4. 관리 비밀번호: 네 자리. 빈칸으로 저장하면 기존 암호를 유지합니다.

관리 인증은 해당 플레이어에게만 적용되며 창 종료·거리 이탈·시간 경과·월드 재시작 시 해제합니다. 저장 전 검사를 통과한 설정만 반영합니다.

## KAM-305 로비 관리

로비의 동·라인은 KAM-305의 동/로비 번호에 대응하며, 호수 범위·경비번호도 해당 로비 설정 상세에 표시됩니다. KAM-305의 로비 관리에서 동/로비 번호를 수정하면 실물 패널에도 적용됩니다. 설정한 출입 암호는 그 로비에만 적용하며 동 번호의 0번 항목은 동 전체의 일괄 암호로 사용할 수 있습니다. 관리 비밀번호는 로비 본체 관리자 인증용으로, KAM-305의 로비 출입 암호와 별개입니다.

최신 외형은 직선형 금속 외곽 플랜지를 사용합니다. 버튼 지름은 원래 크기로 복원하고 돌출 두께만 절반으로 유지했으며 카드리더 두께를 더 줄였습니다. 그 상태에서 본체·버튼·리더·로고·세그먼트 전체를 비율 그대로 **2/3 크기**로 축소했습니다(세로 약 0.5833블록, 가로 약 0.4458블록). 디자인 도구로 로고를 기본/숨김/문구/리소스팩 텍스처 방식으로 바꾸며 월드와 조작 화면에 반영합니다.

추가 게임 화면과 전면 사진을 반영해 외함의 안쪽 단차·뒤쪽 축소 설치함을 제거했습니다. 같은 외곽의 평평한 단일 외함으로 구성하고, 전면의 가는 테두리·안내문·마이크 구멍·엇갈린 스피커 슬롯과 은색 표면을 다듬었습니다. 버튼과 카드리더의 치수·배치는 그대로 유지합니다.

상단 로고와 모델명은 왼쪽 기준선을 맞춘 두 줄로 재배치했습니다. KOCOM 로고를 위로 옮기고, 바로 아래에 작은 모델명을 배치해 글자가 겹치지 않도록 했습니다. 로고 변경 모드도 같은 영역을 사용하며 설치 모델·아이템·조작 화면에 함께 반영합니다.

## KLP 형제모델

| 아이템 ID | 제품 | 전면 / 카드 방식 |
| --- | --- | --- |
| `klp_203rf` | KLP-203RF | 기존 전면, RF 터치형 리더 |
| `klp_202` | KLP-202 | 초기 전면·사용방법 틀·검은 둥근 테두리, 카드 기능 없음 |
| `klp_202r2_early` | KLP-202R2 초기형 | 초기 전면에 스피커 아래 삽입구와 선명한 둥근 둘레 테 추가 |
| `klp_202r2_late` | KLP-202R2 후기형 | 203RF 전면에 RF 리더 대신 삽입구와 선명한 둘레 테 적용 |

새 세 모델은 밝은 회색 본체를 사용하며 카메라 렌즈·검은 표시창·마이크·스피커 그릴·14개 버튼의 위치와 크기는 203RF와 같습니다. 설치 크기·로고 편집·관리자 설정·BUS 경비실 연결·세대 호출·통화·문열림·비밀번호 변경도 공통입니다.

크리에이티브 HomeNet 탭에서 세 모델과 **삽입형 출입카드**(`qwertys_homenet:insert_card`)를 꺼낼 수 있습니다. 삽입형 모델의 관리자 설정에서 손에 든 삽입형 카드를 등록하거나 인증 중 카드로 제품을 사용하면 등록됩니다. 등록 후 삽입형 카드를 들고 제품에 우클릭하면 카드 삽입·인식을 수행하고 연결된 문을 엽니다. RF 카드와 삽입형 카드는 서로의 리더에서 인식하지 않습니다. KLP-202는 등록과 카드 출입을 모두 지원하지 않습니다.

**형제모델 변경 아이템**으로 네 모델을 전환합니다. 통화·관리자 설정을 끝낸 대기 상태에서 변경하며, 동/라인·경비번호·출입문 연결·비밀번호·등록 카드·로고·미세 이동 위치를 유지합니다. 카드 기능이 없는 모델로 전환해도 등록 정보는 보관하되 카드 기능은 동작하지 않습니다. **제품 이동 도구**의 블록/mm 이동도 모두 지원합니다.
