# 모델별 조작화면 사용법

제품 조작화면 오른쪽 위 **사용법**을 누르면 현재 제품의 안내가 열립니다. **돌아가기** 또는 **Esc**로 원래 화면에 복귀합니다. 휠·방향키·PageUp/Down으로 긴 안내를 읽고 Home/End로 처음/끝으로 이동합니다.

삼성 HT-512 외형 확인 화면, SHT-101C·SHT-102C·무선수화기·공통 휴대장치, SHT-5500S 주소 화면, 코콤 KVM 각 모델, IP/KIP 인터폰, KLP 공동현관기, AM-10KP·KAM-305·KGP-70K 경비실기, 현대 HMC-7000·HA-4100H, KHN 월패드 및 공통 비디오폰·인터폰·도어폰 화면에 적용합니다. 제어 블록 설정 화면에도 사용법을 제공합니다.

선택한 KVM 모델의 실제 키 이름과 경비·세대통화·공동현관·비상·외출 지원 여부에 맞춰 안내합니다. 삼성은 BUS/STAR 주소 지정, 본체와 휴대장치 연결, SHT-102C의 통화 중 `*` 문열림, SHT-101C의 대기 중 현관 확인·스피커 통화를 구분합니다. SHT-5500S는 외형·주소 설정만 지원한다고 표시합니다.

사용법은 기존 화면 위에 표시됩니다. 원래 화면과 통화 세션을 교체하거나 닫지 않으므로 호출·통화 상태 갱신을 계속 받습니다. 안내가 열려 있는 동안 본체 버튼·숫자키·메시지 입력으로 조작이 새지 않도록 차단합니다. 화면 크기를 바꿔도 안내를 유지하고 본문을 다시 줄바꿈합니다.

기존 제품 클래스는 변경하지 않고 Forge 화면 이벤트로 추가합니다. 실제 클라이언트 검증은 스크린샷 없이 버튼·이벤트·상태를 검사합니다.

검증: 실제 Forge 클라이언트에서 조작화면 18종의 버튼·렌더·스크롤·입력 차단·크기 변경·Esc 복귀를 통과했습니다. KVM 13개 모델의 실제 설치 상태와 키 지원별 안내 선택을 확인했으며, 사용법이 열린 무선수화기 화면에서 외부 착신 패킷이 전달되는 것도 검증했습니다. 기존 영상·통화·램프·휴대장치·공통 이동 클라이언트 검사도 함께 통과했습니다.

서버 회귀 검사 38개도 통과했습니다. 배포 시 기존 제품 클래스 239개의 원본 바이트를 보존하고 버전 없는 `qwertys_homenet.jar`로 제공합니다.
