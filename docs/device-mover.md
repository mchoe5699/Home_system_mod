# 제품 이동 도구

크리에이티브 HomeNet 탭의 **제품 이동 도구**(`qwertys_homenet:device_mover`)를 사용합니다.

1. 제품을 클릭하면 **제품 위치 조정** 창이 열립니다.
2. 이동량을 **0.1~1.0칸** 중 선택합니다.
3. 위·아래·동·서·남·북 방향을 누릅니다. 원하는 만큼 반복하고 완료를 누릅니다.

방향은 월드 좌표 기준입니다. 외형·버튼·로고·클릭 영역이 함께 움직입니다. 0.1칸을 열 번 이동하면 정확히 1칸이며, 블록 경계를 넘어도 연결과 설정을 유지합니다. 벽이나 다른 블록과 겹치는 이동은 허용하지 않습니다.

동일 차원에서 로딩된 위치 사이를 이동합니다. 다른 블록이 있는 칸은 덮어쓰지 않으며, 이동에 실패하면 제품을 기존 위치에 유지하거나 복원합니다. 설치·파괴 권한 및 Forge 보호 이벤트를 확인합니다. 통화·수화기 조작·문열림·경보가 동작 중인 제품은 동작을 끝내고 이동합니다.

번호·비밀번호·로고·디자인·등록 카드·기기 설정을 보존합니다. 세대/경비실/카메라/초인종/로비폰의 연결 위치와 경비실 등록 목록, 자동 세대번호 예약, 게임 내 국선 번호부도 새 위치로 갱신합니다. 로딩되지 않은 연결 기기는 이동 이력을 월드에 저장했다가 로딩이 끝난 뒤 연결을 복원합니다. 새로운 기기가 옛 위치에 설치된 경우와 기존 기기의 이동을 구분합니다.

HomeNet 네임스페이스의 블록을 기준으로 처리하므로 모델별 허용 목록 없이 현재 제품과 이후 제품을 지원합니다. 새 제품도 설정을 일반 BlockEntity NBT로 저장해야 합니다. 기존 위치 필드(`Pos`, `P`, `Receiver`, `Station`, `AnalogStation`, `Forward`)와 위치 배열(`Doors`, `ReceiverDoors`, `Receivers`)은 자동 갱신합니다. 새 형식의 위치 키를 사용하는 구현은 `DeviceMoves.registerPositionField` / `registerPositionArray`로 등록합니다.

새 제품은 공통 `WallMountedBlock` 또는 `ControlBlock`을 사용하며, 별도 선택 영역 구현은 `DeviceOffsets.shape`로 변환합니다. 별도 애니메이션 렌더러는 `MovingRenderer.register`로 등록합니다. 정적 블록 모델은 자동으로 미세 이동을 적용합니다.
