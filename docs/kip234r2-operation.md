# KOCOM KIP-234R2 BUS 인터폰

제품 ID는 `qwertys_homenet:kip_234r2`입니다. IP-203APB와 같은 본체·수화기·받침·뒤판을 사용합니다. 전체 크기는 세로 0.4블록, 가로 0.176블록이며 앞쪽은 흰색, 뒤판은 회색입니다. 설치판·코일선·전선은 포함하지 않습니다.

버튼부는 제공 사진에 따라 큰 열쇠 버튼, 위쪽 작은 경비 버튼, 아래쪽 작은 현관 버튼으로 구성했습니다. 모델명은 열쇠 버튼 아래에 인쇄하고 공동현관·경비/부재·현관 표시와 KOCOM 로고를 배치했습니다. IP-203APB는 비상·현관·경비 구성으로 유지하며 빈 공간을 줄인 버튼 패널을 설치 모델·아이템·조작 화면에 적용했습니다.

## 매뉴얼의 통화 동작

첨부된 스캔 PDF의 사용방법, 다중호출, 부재 설정 및 해제, 음량 조절 내용을 확인했습니다.

- 대기 중 수화기를 들면 발신 대기음이 들립니다. APB와 달리 수화기만 들어서는 경비실을 자동 호출하지 않습니다. 경비 버튼을 눌러 호출합니다.
- 경비실 또는 로비폰에서 호출하면 멜로디, 세대 현관에서 호출하면 딩동 2타가 울립니다. 수화기를 들어 응답합니다.
- 현관 버튼을 먼저 선택하고 수화기를 들거나, 수화기를 든 상태에서 현관 버튼을 누르면 연결된 세대 현관과 통화할 수 있습니다.
- 경비·로비·현관은 각각 호출과 통화를 유지합니다. 경비 버튼으로 경비 회선, 현관 버튼으로 로비/현관 회선을 선택합니다. 로비와 현관이 함께 대기 중이면 현관 버튼을 다시 눌러 다른 회선을 선택할 수 있습니다.
- 미응답 호출은 30초, 연결된 통화는 3분 후 종료됩니다. 보류한 회선도 같은 제한을 적용합니다. 수화기를 내려놓으면 모든 현재·보류 통화를 종료합니다.
- 현관 딩동과 다른 호출 멜로디가 함께 대기하면 두 호출음을 번갈아 알립니다. 수화기가 들린 상태에서는 호출음을 줄입니다.
- 경비나 로비가 먼저 연결을 종료하면 수화기가 들린 동안 최대 30초의 종료음을 제공합니다.

## 열쇠 버튼

사용자 요청에 따라 열쇠 버튼은 **호환되는 로비폰과 연결된 통화 중에만** 동작합니다. 대기·호출 중·경비 통화·세대 현관 통화에서는 문을 열지 않습니다. 로비폰은 세대와 같은 BUS 경비실기에 연결되어 있어야 하며, 버튼을 누르면 해당 로비폰에 연결된 문만 열고 로비 통화를 종료합니다. 세대 현관문이나 다른 로비의 문은 열지 않습니다.

현재 JAR에는 실제 로비폰 제품 블록이 등록되어 있지 않습니다. 로비 통화·문 열기·우회는 기존 `AnalogLobbyEndpoint` 연동 인터페이스로 구현했으며, 테스트용 로비 기기로 검증했습니다. 테스트용 기기는 배포 JAR에 포함하지 않습니다. 실제 로비폰 모델이 이 인터페이스를 구현해 등록되면 같은 통화·열쇠 동작을 사용할 수 있습니다.

## 부재와 음량

현관·경비 버튼을 **0.5초 이상 함께 누르면** 부재를 설정하며 다시 같은 동작으로 해제합니다. 수화기를 들었다 내려놓아도 해제됩니다. 0.5초보다 짧은 동시 누름은 설정하지 않습니다.

부재 상태에서 세대 현관 호출은 받을 수 있고 응답하면 부재가 해제됩니다. 경비실의 세대 호출은 응답하지 않고 경비실에 부재를 표시합니다. 로비 호출은 세대 대신 연결된 경비실기로 우회합니다. 비상 기능은 없습니다.

호출 음량은 매뉴얼의 3단 스위치에 맞춰 소·중·대로 조절합니다. 게임에서는 각각 30·65·100%로 표시합니다. 음량·부재·번호·로고는 저장되고 진행 중인 통화와 수화기 들림은 재접속 시 초기화됩니다.

## 경비실 연결과 세대 번호

KOCOM BUS 경비실기 AM-10KP·KAM-305와 연결합니다. 링크 도구로 기기를 선택한 뒤 웅크리고 호환 경비실기를 클릭합니다. STAR 방식은 연결할 수 없습니다.

동·호수 등록은 사용자 요청대로 KVM-933과 같습니다. 연결 시 초기 번호를 받고, 번호 변경은 연결된 경비실에서 수행합니다. 기기 화면에서는 번호를 직접 수정할 수 없습니다. AM-10KP에서는 경비실과 통화 중 `**00*`, 동 번호, 동 버튼, 호 번호, `*` 순서로 등록합니다. KAM-305에서는 해당 모델의 번호 등록 화면을 사용합니다.
