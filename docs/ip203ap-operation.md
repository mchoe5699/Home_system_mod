# KOCOM IP-203AP STAR 인터폰

이번에 제공된 IP-203AP 사진 여섯 장으로 본체, 송수화기, 버튼과 뒷면 구조를 구성했습니다. 마지막 사진은 크기 비율의 기준입니다. 외형은 새로 제작했으며, 앞쪽의 빈 패널과 작은 원형 마개, 같은 크기의 현관·경비 버튼 두 개, 사선으로 나뉜 스피커 슬롯, 둥근 본체 하단, 송수화기 안쪽의 손잡이 곡선과 두꺼운 양 끝, 받침 홈·후크·접합선·뒤판 단차·코일선을 포함합니다.

본체 가로·세로 비율은 약 0.44입니다. 코일선과 수화기를 포함한 전체 범위는 가로 약 0.267블록, 세로 약 0.886블록, 두께 약 0.197블록으로 한 블록 안에 들어갑니다. 설치판, 사진의 주변 물건과 벽 뒤쪽 배선은 제품 모델에 포함하지 않습니다.

## 연결과 동·호수

- 제품 ID: `qwertys_homenet:ip_203ap`.
- STAR 방식입니다. 기존 아날로그 경비실(`guard_console`)에 STAR 링크 도구로 연결할 수 있습니다. 도구로 IP-203AP를 선택한 뒤 웅크리고 아날로그 경비실을 클릭합니다.
- STAR 경비실 인터페이스를 사용하는 경비실기와도 호환됩니다. BUS 방식인 AM-10KP·KAM-305에는 연결하지 않습니다.
- 동·호수는 KVM-906과 같은 현장 설정 방식입니다. 제품 조작 화면의 동·호수 입력란에서 등록하고 저장합니다. 경비실 연결 후에도 설정한 번호를 유지합니다.
- 로고는 기존 제품 디자인/로고 도구로 기본·숨김·문구·리소스팩 이미지 중에서 설정합니다. 설정한 로고와 동·호수는 저장 및 제품 회수 시 유지됩니다.

## 현재 구현된 기본 조작

수화기를 클릭하거나 H를 눌러 들고 내려놓습니다. 들어온 호출은 수화기를 들어 응답하며, 내려놓으면 통화를 종료합니다. 수화기를 든 상태에서 경비 버튼(G)으로 연결된 STAR 경비실을 호출합니다. 현관 버튼(F)은 수화기를 든 상태에서 들어온 현관 호출에 응답합니다. 제품 그림의 현관·경비 버튼을 직접 클릭해도 같은 조작을 합니다.

상세 사용설명서는 추후 제공 예정입니다. 현재 조작은 모드의 기본 통화 기능입니다. 실제 제품의 호출음, 통화 전환 절차, 버튼 조합, 시간 제한과 추가 기능은 설명서를 받은 뒤 확정합니다. 수화기를 들기만 해도 자동으로 경비실에 발신하는 동작은 추가하지 않았습니다.

사진 합성, 이미지 생성 도구와 확인용 스크린샷을 사용하지 않았습니다. 게임에 필요한 모델·텍스처 리소스와 조작 화면만 제작했습니다.
