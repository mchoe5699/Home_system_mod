# QWERTY's HomeNet — Forge 1.20.1

KOCOM 수화기형 비디오폰과 일반 월패드·인터폰·현관 기기·홈 제어 기기를 제공하는 모드입니다. JDK 17, Forge 47.3.0, Gradle 8.8을 사용합니다.

```bash
./gradlew build
./gradlew runClient
```

결과물: `build/libs/qwertys_homenet-1.0.0.jar`

## 비디오폰

KVM-906 / KVM-904 / KVM-930 / KVM-960 / KVM-933을 제공합니다. 제품을 **형제모델 변경 아이템**으로 우클릭하면 목록이 열립니다. 휠로 스크롤한 뒤 원하는 모델을 클릭합니다. 모델별 버튼·화면 옆 표시기·커버 디자인·경비실 호환 규격이 함께 변경됩니다. 로고·본체 색상·직접 기기 링크·문 링크는 유지됩니다.

- 906: 현관·경비. 기기에서 세대번호 설정. 전용 아날로그 교환대에 직접 연결한 뒤 경비실 통화를 사용합니다.
- 904: 현관·문열림. 경비실 기능과 교환대 연결 없음.
- 930: 비상·외출·현관·경비실. 4선 공통, AM-10KP 전용. 동·호수는 교환대에서 설정.
- 960: 현관·경비실. 4선 공통, AM-10KP 및 호환 코콤 교환대. 동·호수는 교환대에서 설정.
- 933: 외출·현관/LP·경비실·문열림, 비상/전원 겸용 표시등 버튼. 8선 공통, KAM-305 및 호환 교환대. 동·호수는 교환대에서 설정.

KVM-906은 이전 0.6블록 버전의 2/3 크기(가로·세로 0.4블록)이며 원래 외형 비율을 유지합니다. 930·933은 자료의 큰 본체 비율을 반영해 약 0.491블록 크기입니다. 외부 전선·수화기 코드는 모델링하지 않습니다.

**KHN-893N 전용 제품, ASTRO KLP-70D, ASTRO KGP-70K, 화이트/실버 도어카메라는 제거했습니다.** 월패드는 특정 기종이 아닌 일반 월패드로 제공됩니다. 삭제된 제품이 배치된 기존 월드에서는 해당 블록/아이템이 사라질 수 있습니다. 기존 현관 기기의 세대번호 연결은 새 직접 링크로 다시 지정해야 합니다.

## 연결 도구

- **홈 링커**: 내부 월패드·비디오폰·인터폰 선택 → 현관 도어카메라·도어폰 선택. 선택한 내부 기기 자체에 연결하며 세대번호·동호수와 무관합니다. 같은 기기 쌍을 다시 선택하면 해제됩니다. 현관 기기당 최대 32개 수신기, 연결 범위 64블록입니다.
- **도어 링커**: 내부 월패드·비디오폰·인터폰 선택 → 문 선택. 내부 기기 릴레이에 문을 연결합니다. 같은 문을 다시 선택하면 해제됩니다. 일반 문·다락문·울타리 문 및 열림 속성이 있는 다른 모드 문을 지원합니다. 최대 16개, 범위 32블록. 릴레이는 3초 후 닫힙니다.
- **아날로그 경비실 교환대 연결 도구**: 내부 기기를 여러 개 선택 → 호환 교환대 선택. 한 번에 최대 128개. 모든 선택 기기를 먼저 검사해 호환되지 않거나 로드되지 않은 대상이 있으면 전체 연결을 적용하지 않습니다. 기기를 재선택하면 선택 해제, 웅크리고 허공 클릭은 전체 선택 초기화, 웅크리고 기기 클릭은 그 기기의 교환대 연결 해제입니다.
- **형제모델 변경 아이템**: 비디오폰 우클릭 → 스크롤 목록 → 모델 클릭. 통화 중에는 변경하지 않습니다. 지정 모델의 버튼 기능은 디자인 설정이나 임의 클라이언트 설정 패킷으로 변경할 수 없습니다.
- **KVM 디자인 편집 도구**: 로고(기본/없음/글자/커스텀 PNG), 본체·커버 색상 편집. 906·904·960은 커버 무늬도 바꿀 수 있습니다. 930·933은 작동 상태 표시기를 유지합니다.

일반 월패드의 제어 블록·스마트 조명 연결은 기존 홈 링커 방식대로 사용할 수 있습니다. 일반 비디오폰·인터폰도 직접 현관 기기 링크와 내부 문 릴레이를 지원합니다.

## 아날로그 교환대 구현 범위

사용자 요청대로 전용 교환대, AM-10KP, KAM-305 및 새 로비폰 본체는 **아직 추가하지 않았습니다**. 현재 배포본은 선택 도구·호환 검사·직접 연결 저장·경비실 통화/비상/외출 신호 인터페이스를 준비합니다. 실제 교환대 통화·동호수 배정·경비실 비상 전달·공동현관 연결을 사용하려면 호환 본체를 후속 제작해야 합니다. 교환대가 없는 상태에서 930·933의 비상 키는 자체 경보와 표시기를 작동시키고 연결 대기 안내를 표시하며, 다시 누르면 자체 경보를 해제합니다.

교환대 개발 시 `analog/AnalogSwitchboard.java`와 `AnalogBus`를 구현합니다. 공통 방식은 연결된 교환대만 `assignUnitFromSwitchboard`로 동호수를 배정할 수 있습니다. 8선 로비폰은 `AnalogLobbyEndpoint`를 구현하고 같은 교환대에 연결된 933에 호출합니다. 테스트용 가상 교환대·로비폰은 `src/test`에만 있으며 배포 JAR에는 포함하지 않습니다.

자세한 로고 리소스팩·사용법은 [KVM 사용 안내](docs/KVM-906.md)를 참고하세요.

## 검증

```bash
./gradlew -I tools/kvm_checks.gradle kvmChecks
./gradlew -I tools/kvm_gametest.gradle runGameTestServer
python3 tools/check_kvm_assets.py
```

설정·호환성 검사, 실제 Forge 월드에서 직접 링크·문 릴레이·모델 변경 및 파손/설치 시 NBT 유지·비상/외출 신호·교환대별 호환 제한·8선 로비 인터페이스를 검증합니다. 게임 테스트는 `run/gametest`의 별도 월드에서 실행됩니다.
