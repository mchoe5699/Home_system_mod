## 삼성 휴대장치 재제작 · SHT-102C `*` 문열림 수정

[교체용 qwertys_homenet.jar](qwertys_homenet.jar) · [SHT-102C](docs/SHT-102C.md) · [공통 휴대장치](docs/SHT-102C-휴대장치.md)

SHT-102C에는 별도 문열림 버튼이 없습니다. `현관`은 영상 확인용이며, 현관·공동현관과 통화 중 `*`으로 문을 엽니다. BUS 공동현관 착신에는 수화기를 들어 응답한 후 `*`을 누릅니다. 공통 휴대장치도 SHT-101C/SHT-102C에 연결해 통화한 뒤 `*`으로 열 수 있습니다.

## 연결 도구

- **홈 링커**: 내부 월패드·비디오폰·인터폰 선택 → 현관 도어카메라·도어폰 선택. 선택한 내부 기기 자체에 연결하며 세대번호·동호수와 무관합니다. 같은 기기 쌍을 다시 선택하면 해제됩니다. 현관 기기당 최대 32개 수신기, 연결 범위 64블록입니다.
- **도어 링커**: 내부 월패드·비디오폰·인터폰 선택 → 문 선택. 내부 기기 릴레이에 문을 연결합니다. 같은 문을 다시 선택하면 해제됩니다. 일반 문·다락문·울타리 문 및 열림 속성이 있는 다른 모드 문을 지원합니다. 최대 16개, 범위 32블록. 릴레이는 3초 후 닫힙니다.
- **경비실기 링크** (`analog_linker`, 기존 아이템 ID 유지): 서서 비디오폰·내부 기기를 클릭하면 선택하고 같은 기기를 다시 클릭하면 선택을 해제합니다. 기기 수 제한 없이 선택 후 **웅크리고 경비실기를 클릭**하면 일괄 연결합니다. 웅크린 상태에서는 경비실기만 선택 가능하며, 내부 기기나 허공 클릭은 선택 목록·기존 링크에 영향을 주지 않습니다. 서서 경비실기를 클릭하면 연결하지 않습니다. 모든 기기를 먼저 검사하며 STAR/BUS·제조사 호환성이나 로딩 상태가 맞지 않으면 전체 연결을 적용하지 않고 선택을 유지합니다. 성공하면 선택 목록을 비웁니다.
- **형제모델 변경 아이템**: 비디오폰 우클릭 → 스크롤 목록 → 모델 클릭. 통화 중에는 변경하지 않습니다. 지정 모델의 버튼 기능은 디자인 설정이나 임의 클라이언트 설정 패킷으로 변경할 수 없습니다.
- **KVM 디자인 편집 도구**: 로고(기본/없음/글자/커스텀 PNG), 본체·커버 색상 편집. 906·904·960은 커버 무늬도 바꿀 수 있습니다. 930·933은 작동 상태 표시기를 유지합니다.

홈 링커는 세대 내부 기기와 도어카메라·도어폰 연결 전용입니다. 경비실·제어 블록·조명·초인종·문은 홈 링커의 연결 대상이 아닙니다. 일반 비디오폰·인터폰도 직접 현관 기기 링크와 내부 문 릴레이를 지원합니다.

## STAR / BUS 경비실 시스템

AM-10KP 코콤 BUS 디지털 경비실기를 제공합니다. 930·960·933·940R3과 경비실 링크 아이템으로 연결할 수 있습니다. KAM-305 디지털 경비실기도 제공합니다. STAR 경비실기와 새 로비폰 본체는 아직 추가하지 않았습니다. [AM-10KP 사용법](docs/AM-10KP.md)과 [KAM-305 사용법·각도 조절·사진](docs/KAM-305.md)을 참고하세요.

모든 제품은 경비실 시스템을 **STAR(아날로그)** 또는 **BUS(디지털)**로 명시합니다. STAR 기기는 제조사와 무관하게 STAR 경비실기와 연결합니다. BUS 기기는 같은 제조사의 BUS 경비실기에만 연결합니다. STAR와 BUS 간 연결은 차단하며 경비 기능이 없는 904는 어느 경비실기에도 연결하지 않습니다. 906은 KOCOM STAR, 930·933·960은 KOCOM BUS입니다. 4선/8선은 외형·배선 정보로 유지하며 경비실 호환성을 판정하지 않습니다.

경비실기 개발 시 `guard/GuardExchange.java`를 구현하고 `guardSystem()`과 `manufacturer()`를 명시합니다. 제조사는 표시 이름이나 로고가 아닌 안정된 식별자(예: `KOCOM`)로 검사합니다. BUS 제조사 미지정 시 연결하지 않습니다. 기존 `analog/AnalogSwitchboard` 이름은 이 공통 인터페이스를 상속하는 호환용 이름으로 유지됩니다. 공통 방식은 연결된 경비실기만 `assignUnitFromSwitchboard`로 동호수를 배정할 수 있습니다. 8선 로비폰은 `AnalogLobbyEndpoint`를 구현하고 같은 경비실기에 연결된 933에 호출합니다. 테스트용 가상 경비실기·로비폰은 `src/test`에만 있으며 배포 JAR에는 포함하지 않습니다.

자세한 로고 리소스팩·사용법은 [KVM 사용 안내](docs/KVM-906.md)를 참고하세요.

```bash

./gradlew -I tools/kvm_gametest.gradle runGameTestServer
python3 tools/check_kvm_assets.py
```

설정·호환성 검사, 실제 Forge 월드에서 직접 링크·문 릴레이·모델 변경 및 파손/설치 시 NBT 유지·비상/외출 신호·경비실기별 호환 제한·8선 로비 인터페이스를 검증합니다. 게임 테스트는 `run/gametest`의 별도 월드에서 실행됩니다.

문열림은 모델과 실제 호출 기기에 따라 제한합니다. **906·930·960은 문열림 기능이 없습니다. 904는 직접 연결한 도어카메라 호출에 응답해 통화 중일 때만, 933은 호환 로비폰 호출에 응답해 통화 중일 때만** 문을 엽니다. 933의 도어카메라 통화와 모든 모델의 대기·호출 대기·경비실 통화에서는 문열림이 차단됩니다. 도어 링커로 내부 기기 → 문을 연결한 뒤 조건에 맞는 통화 중에 물리 문열림 버튼이나 화면의 연결된 문 열기 버튼을 누르면 약 3초간 열립니다. 전원이 켜져 있어야 합니다. 철문·나무문은 위칸을 연결해도 두 칸 모두 개폐합니다.

경비실에서만 동·호수를 설정할 수 있는 제품(930·933·960)은 연결 시 사용 중인 번호 및 예약된 번호와 겹치지 않는 무작위 동·호수를 배정합니다. 번호 예약은 월드에 저장해 재시작·재연결 후에도 유지하며, 같은 기기는 기존 배정 번호를 사용합니다. 내부에서 번호를 설정할 수 있는 제품(906 등)의 번호는 링크해도 유지됩니다.

후속 경비실기 구현은 `GuardExchange.onLinked(receiver, localUnit)`에 전달된 초기 번호를 경비실기의 세대 목록에 저장해야 합니다. 번호는 경비실 전용 제품이면 자동 배정된 값, 내부 설정 제품이면 현재 값입니다. 실제 경비실에서 번호를 바꿀 때는 연결된 기기의 `assignUnitFromSwitchboard`를 사용합니다.

KVM-906·904·930·933·960은 모두 가로·세로 0.45블록, 두께 약 0.099블록으로 같은 외곽 크기를 사용합니다. 경비실기 명칭은 아날로그 STAR·디지털 BUS 모두 **경비실기**로 표시하며, 아날로그 경비실기를 교환대라고도 부릅니다.

## KVM-940 / KVM-940R3 국선

실제 외부 전화망에 접속하지 않는 **게임 내 국선 시뮬레이션**입니다. 두 모델 모두 별도의 국선 번호를 등록하고 같은 차원의 로드된 940 계열 기기 번호로 통화합니다. 국선 번호는 동·호수와 별개이며 중복 등록할 수 없습니다. 디자인 설정의 본체 탭에서 전자식/기계식 다이얼 모드를 선택할 수 있고, 버튼 탭에서 벨 음량·밝기·명암을 조절합니다. 수화기를 들고 12키 다이얼을 누르면 발신합니다. 마지막 숫자 입력 후 약 1초에 발신하거나 `#`/발신 버튼으로 즉시 발신합니다. 입력 중 `*`는 마지막 숫자를 지웁니다. 연결 중 숫자 키는 게임 내 전화 키패드음을 내고 추가 발신하지 않습니다. 현관·경비와 구분된 국선 착신음/국선 램프를 사용합니다.

국선 착신 시 수화기를 들면 응답합니다. 현관/경비 통화 중에는 **후크 / 국선 전환**으로 국선에 응답하고, 현관/경비 버튼으로 해당 통화에 돌아갑니다. 현관·경비·국선의 동시 호출을 받으며 통화 전환 시 기존 통화를 보류합니다. 수화기를 놓으면 보류 중인 통화도 모두 종료됩니다. 통화와 보류 상태는 월드 재시작 후 재개하지 않으며 국선 번호만 저장됩니다. 국선 호출 대기는 약 30초, 국선 연속 통화는 약 3분으로 제한합니다. 현관 CRT는 약 3분 뒤 꺼지며 버튼으로 다시 켤 수 있습니다.

940R3에는 비상 버튼과 비상 기능이 없습니다. 외출 기능은 조작 화면에서 사용하며, 동·호수는 연결된 경비실기에서 등록합니다. 940·940R3의 CRT 옆 버튼은 사진처럼 어두운 사각 버튼과 현관·전화·열쇠 아이콘으로 구성했습니다.

### 외관 및 통화 수정

KVM 본체 기본색을 흰색으로 변경하고 커버 이음새 및 940/940R3의 버튼·다이얼을 수정했습니다. 경비실과 통화할 때 경비실 통화 중으로 표시합니다. AM-10KP는 단일 패널, 곡선 수화기와 12° 조작면을 적용했으며 부재/동 버튼으로 동 번호를 입력합니다. 교환 중 3자 대화 후 경비실이 수화기를 내려놓으면 두 세대가 직접 통화합니다. KAM-305는 8° 본체 조작면과 화면 수납 홈을 적용했습니다. 화면 0°는 수납 상태이며 초기 관리자 메뉴는 비밀번호 없이 진입합니다.

### KAM-305 설명서 조작 화면

KAM-305의 설정은 제품 LCD와 실제 숫자·방향·확인 버튼으로 조작합니다. 외부 설정 패널을 제거하고 설명서의 대기 로고, 6행 메뉴, 주소 변경, 호출, 기록, 부재, 장치기 조회 및 초기화 화면을 적용했습니다. 확인을 약 0.7초 누르면 수화기를 놓은 상태에서도 발신합니다. 상세 조작은 [KAM-305](docs/KAM-305.md)를 참고하세요.

## 제품 로고

**제품 디자인/로고 도구**로 현재 수신기와 현관 호출기의 로고를 변경할 수 있습니다. KVM은 도구를 든 채 웅크리고 클릭하면 공통 로고 편집기가 열립니다. 기본 로고·숨김·문구·리소스팩 이미지 방식을 지원하며 저장과 제품 회수 시 유지됩니다. 제조사 호환성은 그대로 적용됩니다.

## IP-203AP STAR 인터폰

첨부된 IP-203AP 사진 기준으로 본체·수화기·현관/경비 버튼 두 개를 제작했습니다. 코일선과 전선은 제외했습니다. 전체 세로 길이는 0.45블록, 가로는 0.198블록이며 본체 가로·세로 비율은 마지막 사진 기준 약 0.44입니다. 수화기는 본체 외곽 안에 들어가고 아이템과 조작 화면에도 같은 윤곽을 적용합니다. STAR 아날로그 경비실과 연결하고 동·호수는 KVM-906처럼 제품에서 설정합니다. 첨부 설명서에 맞춰 수화기를 들면 경비실 자동 호출, 현관 딩동·경비실 멜로디, 경비실 통화 중 현관 호출 대기와 현관/경비 버튼 전환을 적용했습니다. [현재 조작과 연결 방법](docs/ip203ap-operation.md)을 참고하세요.

## IP-203APB BUS 인터폰

IP-203AP와 같은 0.45블록 본체·수화기를 사용하며 첨부 사진의 비상·현관·경비 버튼과 표시등을 추가했습니다. BUS 디지털 경비실기 AM-10KP·KAM-305와 연결합니다. 동·호수 등록은 KVM-933처럼 경비실에서 수행하며 비상 통보, 현관·경비 동시 누름에 의한 부재 표시, 두 회선 전환을 지원합니다. AP와 APB 모두 기기/설정 패널로 구성한 조작 화면을 사용하며 앞쪽은 흰색, 뒤판은 회색입니다. [APB 조작 방법](docs/ip203apb-operation.md)을 참고하세요.

## KIP-234R2 BUS 인터폰

IP-203APB와 같은 0.45블록 외형에 사진 기준 열쇠·경비·현관 버튼부를 적용했습니다. 수화기 들기 후 경비 버튼으로 호출하며 로비·경비·현관 회선을 선택합니다. 열쇠는 같은 경비실에 연결된 로비폰과 통화 중일 때 해당 로비 문만 엽니다. 0.5초 동시 누름에 의한 부재 설정, 부재 로비 호출의 경비실 우회, 30초 호출·3분 통화 제한, 3단 음량을 지원합니다. 번호 등록은 KVM-933처럼 경비실에서 수행합니다. [KIP 조작 방법](docs/kip234r2-operation.md)을 참고하세요.

## IP-200PC · IP-200PCHB · DP-202H와 초인종

APB와 같은 0.45블록 본체의 형제 모델을 추가했습니다. PC는 버튼 없는 STAR 경비 전용, PCHB는 비상 버튼 하나의 BUS 경비 전용 모델이며 수화기를 들면 경비실을 바로 호출합니다. PC·PCHB는 도어폰·도어카메라 연결을 거부하고 새 호출 전용 초인종으로 딩동만 받을 수 있습니다. 초인종에는 음성 회선이 없습니다. DP는 경비실 연결 없이 열쇠 버튼으로 수화기가 놓인 상태에서도 연결된 문을 엽니다. [모델별 조작과 연결 방법](docs/compact-interphones-operation.md)을 참고하세요.

## 인터폰 형제모델 변경과 흰색 외장

IP-203AP·IP-203APB·KIP-234R2·IP-200PC·IP-200PCHB·DP-202H는 기존 형제모델 변경 아이템으로 서로 전환합니다. 앞쪽 플라스틱은 게임 조명으로 회색이 되지 않는 흰색 재질을 적용했습니다. 도어폰은 영상 없이 호출·통화를 제공하며 호출 전용 초인종과 구분됩니다. [변경 방법과 연결 유지 규칙](docs/ip-interphone-family.md)을 참고하세요.

동·호수 공통 범위는 각각 **1~9999**, 경비실기 링크·AM-10KP·KAM-305의 연결 세대수는 상한 없이 처리합니다. [공통 세대번호 안내](docs/household-addresses.md). 도어폰은 우클릭으로 호출·채팅 화면을 열며 영상 없이 양방향 메시지 통화가 가능합니다.

최근 검증: Forge 서버 GameTest 60개 통과. 실제 클라이언트에서 형제모델 6종의 화면·조작 및 도어폰 채팅 입력→서버 메시지 전달 확인.

## KLP-203RF BUS 로비폰

KOCOM KLP-203RF를 추가했습니다. 첫 사진의 외곽 비율과 렌즈/IR 창·4자리 붉은 세그먼트·금속 14버튼·엇갈린 스피커 슬롯·곡면 CARD 리더를 복원했습니다. 세대/경비실 호출, 응답 후 영상·메시지 통화, 수신기 문열림, 세대 및 로비 출입 비밀번호, RF 카드, KAM-305 로비 관리 연동을 제공합니다.

관리자 진입은 세대호출(C)+경비실(G) 동시 3초 → 초기 `9999#`입니다. 직접 입력하는 동·라인, 경비번호, 호출 호수 뒤 두 자리 범위(예: `03~10`), 관리 비밀번호 설정을 제공합니다. 경비번호가 실제 경비실기와 일치해야 동작합니다. [설치·조작 안내](docs/KLP-203RF.md).

## 현대 HMC-7000 경비실기

흰색 본체와 수화기, 경보 아이콘, 원형 숫자키, 20개 기능키, 2줄 LCD를 갖춘 현대 HMC-7000을 추가했습니다. 가장 긴 변 0.8블록의 세로형 제품이며 화면은 KAM-305처럼 Ctrl＋/－로 0~65도 조절합니다. 로고 편집과 블록 경계를 넘는 이동을 지원합니다. 현대 BUS와 같은 단지 안에서 세대·로비폰·관리실 통화, 보류·세대 간 교환, 경보 시험·기록, 시계·모닝콜을 제공합니다. [조작 방법 및 첨부 PDF의 누락 페이지와 게임 표현 차이](docs/HMC-7000.md).

HMC-7000 경보 버튼 줄: 버튼 아래 중복 글씨를 제거하고 버튼 면에만 글자를 유지했습니다. 공통 흰색 테두리, 화재·가스·방범의 좁은 밝은색 버튼과 넓은 빨간 비상 버튼, 분할선·입체 음영을 보정했습니다.

HMC-7000의 숫자키·기능키 배열, 간격, 위치와 버튼 음영을 보정하고 조작 화면에 로고 변경 버튼을 추가했습니다. 단지 대시보드는 같은 단지의 맞닿은 내부 경계만 지우고 외곽선을 유지하며, 떨어진 구획은 각각 외곽선을 유지합니다. 같은 단지의 지도 색상도 통일했습니다.

## 현대 HA-4100H

사진 기반 흰색 외형과 최장변 0.5블록(가로 0.5 × 세로 0.392)을 유지하고 첨부 설명서의 동작을 구현했습니다. 현대 HMC-7000 BUS·경비실 전용 동호 등록·로고 편집, 전화·보류·재다이얼·번호 기억, 관리실·로비폰·도어폰 통화, 흑백 영상·명암·밝기, 경보 시험·실경보·자동 통보를 제공합니다. [조작 순서와 게임 표현의 차이](docs/HA-4100H.md). 홈 링커로 HA-4100H를 선택한 뒤 도어카메라를 클릭해 연결합니다. HMC-7000은 전용 경비실 링크 도구로 연결합니다. 두 기기는 같은 단지에 있어야 하며, 연결 거부 시 이유를 표시합니다.

HA-4100H·HMC-7000 통화 화면은 대화 내역과 Enter 전송을 지원합니다. HA 기능 버튼은 버튼 면 전체가 점등하며, 경비실 발신 상태와 연결음을 표시합니다. 이동한 기기의 조작·채팅 수신 거리도 실제 위치를 기준으로 계산합니다.

1.0.1: HA-4100H 상단에서 서버 기능 버전·전원·경비실·현관 연결 상태를 확인합니다. T 또는 Enter로 메시지 입력란을 선택하고 Enter로 전송합니다. 별도 수화기 버튼도 제공합니다. 멀티플레이에서는 서버와 클라이언트 모두 1.0.8로 교체해야 합니다(기능이 다른 구버전과의 접속 방지). 실제 클라이언트 조작 검사는 `tools/ha_client_checks.gradle`을 사용합니다.

1.0.3: HA-4100H는 대기 상태에서 관리실/현관 버튼을 누른 뒤 수화기를 들어 HMC-7000으로 발신합니다. 버튼은 수화기를 자동으로 들지 않습니다. 공통 경비실 호출 명령도 같은 두 단계 순서를 지원합니다.

1.0.4: HA-4100H 수화기의 표준 클릭 범위를 넓히고 왼쪽·오른쪽 클릭을 지원합니다. 들기·놓기 명령을 분리하고 중복 들기에 의한 호출 취소를 방지합니다. 관리실 선택 후 수화기를 드는 두 단계 조작은 동일합니다.

1.0.5: 경비실→세대 통화 종료 후 남던 수화기 상태를 정리하여 세대→경비실 재발신과 호출 벨·응답을 복구합니다. 상대방이 종료하는 두 경우를 각각 재현한 회귀 검사와 실제 클라이언트의 통화 후 역방향 호출 검사를 추가했습니다.

1.0.6: 관리실 선택을 별도로 저장하고 수화기 들기 명령에서 발신을 처리합니다. 보류된 전화보다 명시적으로 선택한 경비실 발신을 우선하며, HMC-7000의 수신 회선 생성 확인 후 호출 중 상태를 표시합니다. 수신 거절 시 전원·세대 등록·회선 상태를 안내합니다. 경비실 선행 호출 없이 최초 세대 발신과 양방향 메시지를 검사합니다.

1.0.7: HA-4100H와 HMC-7000 간 일반 세대 호출의 발신·수신·응답·메시지 처리를 재구성했습니다. HMC가 수신 회선을 예약한 뒤 HA가 같은 상대에 대한 발신 상태로 전환하고, 실패하면 예약을 즉시 해제합니다. 반대 방향도 HMC가 회선을 예약한 뒤 HA를 울리며, 응답은 해당 회선과 상대를 검증합니다. 양방향 메시지는 연결된 HMC 회선으로 전달합니다. 수화기 클릭은 클라이언트 화면 상태에서 들기/놓기를 추측하지 않고 서버에 조작을 보내 서버 상태로 처리합니다. 관리실 버튼만으로 자동 발신하지 않습니다. 보류·전환·로비·경비실 상호 호출의 기존 전송 규칙과 단지 제한은 유지합니다.

1.0.8: [코콤 복구 기준과 전용 호출 경로](docs/kocom-isolation.md). HMC 생성 직전 코콤 핵심 클래스 25개의 동일성을 확인하고, 코콤 조작 경로와 현대 BUS 상속 기반을 분리했습니다. 배포 JAR 호출 인터페이스 정합성 검사도 추가했습니다.
