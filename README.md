# KOCOM KVM-906

사진과 KVM-906 사용 설명서를 참고한 Forge 1.20.1용 벽걸이 비디오폰입니다. 220×220×48.5mm 외형을 블록 1m 기준으로 모델링했습니다. 곡면은 작은 모델 요소로 근사하며, 외부 전선과 수화기 코드는 표시하지 않습니다. 기본 구성은 설명서의 **전원 램프 + 현관 버튼 + 경비 버튼**입니다. 사진에 보이는 문열림형 구성을 흉내 내거나 다른 버튼 배치를 만들려면 사용자 편집 구성을 사용하세요. 확인되지 않은 실제 형제모델 이름은 추가하지 않았습니다.

## 아이템과 사용

크리에이티브 **홈네트워크** 탭 또는 다음 명령으로 가져옵니다.

```mcfunction
/give @s qwertys_homenet:kvm_906
/give @s qwertys_homenet:kvm_designer
/give @s qwertys_homenet:kvm_model_tool
```

- **KVM-906**: 벽에 설치한 뒤 우클릭하면 실제 제품 배치의 조작 화면이 열립니다. 세대 번호를 설정하고, 기존 홈 링커로 해당 세대의 현관 카메라를 지정합니다. 동일 단지 안에서 연결됩니다.
- **수화기**를 누르면 들기/내려놓기. 현관 호출 중 들면 응답하고, 다시 놓으면 통화를 끝냅니다. 통화 메시지는 기존 모드의 채팅 통화 방식입니다. 실제 마이크 음성 전송은 제공하지 않습니다.
- **현관** 버튼은 연결된 현관 카메라를 흑백으로 보여주거나 끕니다. 화면은 클라이언트에 로드된 현관 주변의 블록·엔티티를 저해상도 광선 샘플링으로 보여주므로, 원래 게임 화면의 텍스처/스킨을 그대로 촬영하는 영상은 아닙니다. 현관 청크가 클라이언트에 로드되지 않으면 신호 없음으로 표시됩니다.
- 호출을 받지 않으면 약 30초 후 꺼집니다. 통화 중 화면은 3분 후 꺼지지만 통화는 수화기를 놓을 때까지 유지됩니다. 현관 버튼으로 다시 화면을 켤 수 있습니다.
- 하단 **음량·밝기·명암** 조절부를 누르거나 옆 조작 패널의 +/-를 사용합니다. 음량은 호출음에, 밝기/명암은 현관 미리보기에 적용됩니다.
- **경비** 버튼은 아날로그 교환대 제작 대기 안내만 표시합니다. 기존 디지털 경비실기·다른 세대·공동현관기의 디지털 호출에는 연결하지 않습니다. 새 아날로그 교환대 기능은 후속 요청까지 보류했습니다.
- 기본 KVM-906에는 문열림 키가 없습니다. 사용자 편집 구성에서 문열림 키를 배정하면 수화기를 들고 현관 통화 중일 때 기존 도어 링커의 문을 열 수 있습니다.
- **KVM 디자인 편집 도구**로 제품을 우클릭하면 로고/무늬·외관·버튼 편집 화면을 엽니다. 조작 화면의 디자인 설정 버튼으로도 접근할 수 있습니다.
- **KVM 모델 구성 변경 도구**로 제품을 우클릭하면 기본 KVM-906 ↔ 사용자 편집 구성을 전환합니다. 사용자 구성은 버튼 1~3개, 오른쪽 세로/하단 가로 배치, 현관/문열림/경비 대기/미사용 기능을 편집할 수 있습니다. 실제 형제모델 추가는 후속 요청을 기다립니다. 전환 시 버튼 배치는 해당 구성의 기본값으로 돌아가지만 로고·무늬·색상·세대 연결은 유지됩니다.

로고는 기본 KOCOM / 없음 / 글자 / 커스텀 PNG 중 선택합니다. 커버 무늬는 분홍·초록 사선 / 집·해·물결 / 민무늬 / 커스텀 PNG 중 선택합니다. 본체와 커버 색상은 6자리 HEX로 지정합니다(예: `F2EDDC`, `202C3E`). 각 입력 옆 **저장**을 눌러 서버에 적용하세요. 외관과 버튼 설정, 세대 번호, 전원 상태는 월드 저장 및 정상 파손·재설치 후에도 보존됩니다. 진행 중 통화는 재설치/재로딩 후 재개되지 않습니다.

## 커스텀 디자인 PNG

일반 Minecraft 리소스팩의 PNG를 사용합니다. 웹 주소나 로컬 절대 경로를 입력하지 않습니다. 예를 들어 다음 구조의 팩을 적용합니다.

```text
pack.mcmeta
assets/my_pack/textures/kvm/logo.png
assets/my_pack/textures/kvm/cover.png
```

```json
{"pack":{"pack_format":15,"description":"Custom KVM designs"}}
```

편집 화면에서 로고 유형과 커버 무늬를 각각 **커스텀**으로 바꾸고, PNG 경로를 입력·저장합니다.

```text
my_pack:textures/kvm/logo.png
my_pack:textures/kvm/cover.png
```

로고에는 투명 배경을, 커버 무늬에는 대략 38:66 비율의 투명 PNG를 권장합니다. 각자 제공한 PNG를 쓰므로 임의 디자인으로 바꿀 수 있습니다. 경로가 존재하지 않으면 기본 커스텀 예제로 대체합니다. 로고 경로/커버 경로는 각각 최대 64자입니다. 다른 플레이어도 같은 리소스팩을 적용해야 동일 디자인이 표시됩니다.

## 제작법

- 비디오폰: `철·유리판·철 / 석영·레드스톤·석영 / 철·철·철`
- 디자인 도구: 종이 + 파란색 염료 + 철 조각(순서 무관)
- 모델 구성 도구: 철괴 + 레드스톤 + 석영(순서 무관)

## 개발 검증

JDK 17과 저장소의 Gradle 8.8을 사용합니다.

```bash
./gradlew build
./gradlew -I tools/kvm_checks.gradle kvmChecks
./gradlew -I tools/kvm_gametest.gradle runGameTestServer
python3 tools/check_kvm_assets.py
```

`kvmChecks`는 설정의 유효성·저장 왕복·기본 모델의 버튼 잠금·커스텀 경로 제한을 검사합니다. GameTest 2개는 실제 Forge 월드에서 파손/설치 시 NBT 보존과 현관 통화/CRT 타임아웃/경비실 격리를 검사합니다. `src/test`의 검사 코드는 배포 JAR에 포함되지 않습니다. 게임 테스트용 임시 설정은 전용 `run/gametest` 디렉터리를 사용하며 클라이언트 사운드/언어 에셋을 요구하지 않습니다.

에셋을 다시 만들 때는 Pillow를 준비한 뒤 `PYTHONDONTWRITEBYTECODE=1 python3 tools/gen_kvm906.py`를 실행합니다. 이 생성기는 KVM 전용 에셋만 만듭니다. 다른 기기의 에셋 생성기를 실행할 필요가 없으며 별도 LCD 글꼴도 필요하지 않습니다.
