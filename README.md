### 연동 규칙

- 호출하면 **같은 단지 안의 같은 세대 번호 수신기가 모두** 울리고, 먼저 응답한 기기와 통화합니다.
- 어떤 수신기에서든 **문열림**을 누르면, 호출한 기기(로비폰/도어카메라/도어폰)에 **도어 링커로 연동된 문**이 문열림 시간 동안 열렸다가 닫힙니다. 호출기 자체도 같은 시간 레드스톤 신호를 냅니다.
- 같은 세대에 월패드·비디오폰·인터폰을 여러 대 두려면 모두 같은 세대 번호를 설정하세요(각 기기 설정 탭).
- **경비실기 → 세대**: 경비실기 화면에서 세대 번호를 입력하고 `세대 호출` → 그 세대의 월패드·비디오폰·인터폰이 모두 울립니다.
- **관할 경비실 번호**: 월패드 설정 > 관리자모드에서만 `관할 경비실 번호`(예: `50`)를 저장하면 `경비` 버튼·경비실 호출이 **50번 경비실을 먼저** 부릅니다. 50번이 없거나 통화 중이면 같은 단지의 다른 경비실로 갑니다. 통화 > 경비실/관리실의 `경비실` 버튼을 누르면 바로 호출됩니다. 경비실기 세대 번호(경비 주소)의 숫자로 찾습니다.
- **세대 → 경비실**: 월패드(통화 > 경비실/관리실, 또는 본체 `경비` 버튼)·비디오폰·인터폰의 `경비실 호출` → 같은 단지의 모든 경비실기가 울립니다. 세대 번호에 `관리`가 들어간 경비실기(예: `관리실`)는 `관리실` 호출로 따로 부를 수 있습니다.
- **세대 ↔ 세대**: 월패드 통화 > 세대통화(동/호 입력), 비디오폰·인터폰은 세대 번호 입력 후 `세대 호출`.
- 수신기끼리의 통화에는 문열림이 없고, 3분이 지나면 자동으로 끊깁니다.

### 도어 링커

1. 로비폰 / 도어카메라 / 도어폰을 우클릭해서 선택 (연동된 문 위치에 초록 입자 표시)
2. 문을 우클릭 → 연동, 다시 우클릭 → 해제. **열림 상태가 있는 블록이면 모두** 됩니다(나무·철 문, 다른 모드의 문, 다락문, 울타리 문). 링커로 누를 때는 문이 열리지 않습니다.
3. 웅크리고 기기 우클릭 → 그 기기의 문 연동 모두 해제 / 웅크리고 허공 우클릭 → 선택 초기화
4. 한 기기당 문 16개, 32블록 이내

※ MTR 스크린도어·승강장 안전문은 MTR 열차 운행에 맞춰 MTR이 직접 여닫기 때문에 연동되지 않습니다.

### 홈네트워크 대시보드

MTR 대시보드처럼 지도를 띄워 단지를 만듭니다.

- `단지 추가` → 지도에서 드래그해서 구역 그리기 → 이름·색상 → `저장`
- 지도 드래그로 이동, 휠로 확대/축소. 목록에서 단지 이름을 누르면 그 위치로, `✎` 수정(이름·색상·구역 다시 그리기), `✕` 삭제

- **같은 단지 안의 기기끼리만 연동**됩니다. 어느 단지에도 속하지 않은 기기는 "단지 없음"끼리 연동됩니다. 단지가 겹치면 더 작은 단지에 속합니다.

1. **월패드 설치 → 설정 > 관리자모드(월패드 비밀번호, 기본 `9999`)에서 세대 번호 입력** (비디오폰·인터폰·경비실기는 설정 탭) (예: `101-1203`). `101-1203`, `101동 1203호`, `1011203`은 같은 번호로 취급됩니다.
2. **홈 링커로 월패드 우클릭**(선택) → **제어 블록 / 스마트 조명 우클릭**하면 연결. 한 번 더 누르면 해제. (최대 32개, 64블록 이내)
3. 제어 블록을 **맨손 우클릭**하면 이름과 종류(조명·콘센트·난방·환기·가스밸브·도어락·전동커튼·기타)를 정할 수 있습니다. 종류는 월패드에 "켜짐/꺼짐" 또는 "열림/닫힘"으로 표시되고, **일괄소등**은 '조명' 종류만 끕니다.
4. **로비폰**: 공동현관에 인터폰을 달고, 옆에 철문(또는 피스톤 문)을 붙여 둡니다. 방문자가 키패드로 세대 번호를 누르고 **호출**.
5. **세대현관 도어폰**: 홈 링커로 월패드 선택 후 인터폰을 우클릭하면 그 세대 전용 도어폰이 됩니다. 버튼 한 번으로 호출.
6. 월패드가 **딩동** 울리면 (30초) 화면에서 **응답 / 문열기 / 거절**.
   - 응답하면 서로 **메시지**를 주고받을 수 있습니다 (양쪽 근처 8블록 플레이어 채팅에도 표시).
   - **문열기**를 누르면 인터폰이 3초간 레드스톤 신호를 내서 옆의 문이 열립니다.
   - 받지 못한 호출은 **부재중 호출**에 기록됩니다.

## 월패드 (KHN-893N)

설명서의 화면 구성을 그대로 따릅니다. 화면을 직접 눌러서 조작하고, 숫자는 키보드로도 입력됩니다.

- **메인 화면**: 날씨(바이옴 기온·비/눈)·요일·시각, 달력(오늘은 빨간 글씨), 상태표시(네트워크 / 재실·외출 / 공지사항 / 엘리베이터), 아이콘 `방범 · 제어 · 통화 · 조회 · 설정 · 에너지`
- **서브 화면**: 왼쪽 위 홈, 오른쪽 위 도움말, 왼쪽 메뉴, 탭
- **본체 버튼** (오른쪽): `비상`(경비실에 비상 전송·경보음) `외출`(외출 모드, LED) `경비`(경비실 호출/응답) `통화`(응답·끊기, 대기 중이면 현관 모니터링) `문열림`(통화 중 문 열기)
- **방범**: 방범1·방범2 설정, 가스 상태, 경보복귀·경보정지, 경보 시험
- **제어**: 가스밸브(닫기만 가능) · 조명(이름의 마지막 단어 앞부분이 방 이름 – `거실 1`, `거실 2` → 거실) · 난방(현재/설정 온도, 외출) · 환기(약/중/강) · 에어컨 · 기타. 제어 블록 종류로 탭이 정해집니다.
- **통화**: 우리집현관(호출 응답·문열기·영상저장) · 세대통화(동/호 키패드, 음성/영상통화, 끊기) · 경비실/관리실 · 일반전화(국선 없음). 통화 중에는 화면 아래 칸에서 메시지를 주고받습니다.
- **조회**: 공지사항 · 방문자확인(공동현관/현관 호출 때 자동 저장, 최대 64개, 삭제는 3초 안에 확인) · 보수신청 · 주민투표 · 관리비(에너지 사용량으로 계산) · E/V 호출 · CCTV · 무인택배 · 음성메모 · 주차조회
- **에너지**: 실시간사용량(전기·수도·가스·온수·난방) · 평균사용량(목표값 설정, 초과 시 팝업) · 원격검침(전전달/지난달/이번달, 게임 30일 = 1달)
- **설정**: 소리(알림·통화음·호출음·시스템음) · 비밀번호(기본 `9999`, 분실 시 `15770051`. 여기서 정한 4자리가 로비폰 세대 비밀번호) · SMS·MMS / ARS(외출 설정 시에만) · 터치보정 · **관리자모드**(월패드 비밀번호와 같음, **세대 번호·관할 경비실 등록**)

## 경비실기 (KOCOM ASTRO KGP-70K)

설명서 화면 구성(메인 / 방범 / 통화 / 조회 / 설정)을 따르고, 본체 앞면 키를 직접 눌러 씁니다.

- **본체 각도**: 맨손으로 경비실기를 바라보고 `Ctrl` + `+` / `-` → 1도씩 (0~60°, 기본 22°). 받침 다리가 본체를 따라 늘어나고 줄어듭니다.
- **경비실 비밀번호로 공동현관 출입**: 경비실기 설정 > 비밀번호(처음 `9999`로 들어가 4자리 지정)는 로비폰의 공통 비밀번호 입력에서 쓸 수 있습니다. 단, 로비폰 관리자 설정의 **경비 번호가 그 경비실기 번호와 같을 때만** 열립니다 (20번 경비실 비밀번호 → 경비 번호 20인 로비폰만). 로비폰 설정의 `경비 출입 비밀번호`는 그 값을 보여주기만 하고(읽기 전용), 변경은 경비실기에서만 합니다.
- **경비 주소**: 설정 > 관리자모드(`56266`)에서 00~99 (99 = 통합관리실, 월패드의 `관리실` 호출 대상)
- **송수화기**: 울릴 때 누르면 받기, 통화 중 누르면 끊기. 통화 중에는 블록에서도 수화기가 들려 있습니다.
- **세대 / 경비 / 로비 키** → 번호 입력 → **조그 가운데(확인)**. 세대는 `동 + 확인 + 호 + 확인`. `*` = 입력 취소. 조그를 돌리면(마우스 휠) 목록 페이지 이동
- **경비실끼리 통화**: 경비 키 → 경비 번호 → 확인
- **공동현관 호출**: 로비 키 → 공동현관 번호(로비폰의 로비 번호: 동 또는 라인) → 확인 → 로비폰과 바로 통화, `문열림`으로 공동현관 문 열기
- **문열림 키**: 공동현관과 통화 중이면 그 문, 아니면 3초간 레드스톤 신호(DC 접점)
- **부재 설정**: 조회 > 부재설정 (또는 `부재` 버튼) → 넘길 경비 번호 → `부재등록`. 부재 중 걸려온 호출은 그 경비실로 넘어가고, 번호를 비우면 부재중 기록만 남습니다. **우회등록**은 통화 중일 때 넘길 경비실.
- **방범**: 세대 비상 → 방범알림(비상 깜빡임)·방범목록(최대 100). `경보정지` 또는 `비상|전원` 버튼으로 확인
- **유인택배**: 동/호 입력 → `택배등록` → 그 세대 월패드에 "택배가 도착했습니다" + 조회 > 무인택배 목록
- **통화 목록**: 받은(↙)·건(↗)·부재(✕)·넘긴(→) 호출이 탭마다 기록됩니다.

## 공동현관 로비폰

실제 공동현관기(248×279×50.2mm) 비율로 **세로 2/3칸 × 두께 0.1칸** 크기, 블록 면 가운데에 붙습니다. 블록을 우클릭하면 기기 화면이 열리고, LCD 키패드·오른쪽 터치키(보안·호출·경비·취소)·카드 인식부를 마우스로 누릅니다(키보드 숫자키도 됨). 블록 정면에도 시계·입력 번호·호출 상태·문열림 아이콘이 표시됩니다.

- **세대 호출**: 세대 번호 → `호출` (로비번호의 동이 앞에 붙음. 주차관제로비=1이면 동 → `동` → 호 → `호출`)
- **경비 호출**: `경비` (경비번호 월패드, 비우면 세대 번호가 `경비실`인 월패드)
- **세대 비밀번호**: 세대 번호 → `비밀번호 입력` → 4자리 → `확인` (월패드 설정 탭에서 지정)
- **공동 비밀번호**: 대기화면 `공동비밀번호 입력` → 4자리 → `확인`
- 비밀번호가 틀리면 **비밀번호 입력 화면이 다시** 뜨고, 3회 틀리면 경비실 자동 호출
- 문이 열리면 **네트워크 아이콘 옆에 문열림 아이콘**이 문열림 시간 동안 표시되고 같은 시간 레드스톤 신호
- `보안`: 키패드 임의 배열 / 대기화면 `취소`: 숫자 크기(작은→보통→큰, 항상 버튼 안) / `도움말`
- 근접센서: 플레이어가 다가오면 화면이 켜짐 (근접센서 데이타 40 ≈ 2칸)

### 출입 카드

`출입 카드`(종이 2 + 철 조각 + 레드스톤)를 들고 로비폰을 우클릭하면 카드를 댄 것으로 인식합니다. 카드마다 고유 번호가 있습니다.

- 세대 카드 → 문열림 / 마스터 카드 → RF 카드 메뉴 바로 진입 / 등록용 카드 → 세대 카드 등록 화면
- 화면이 열려 있을 때는 카드를 손에 들고 **카드 인식부(CARD)** 를 눌러도 됩니다.

### 관리자 모드

대기화면에서 **`호출` 다음 `경비`** → 관리자 비밀번호(초기값 **`0000`**).

- `1`~`7` 항목, `←` `→` 페이지(6페이지), `0` RF 카드 설정, `9` 근접센서 설정, `취소` 나가기
- 편집 중 `호출` = 지우기, `경비` = 저장. 로비번호는 숫자 → 하단 `동` / 숫자 → 하단 `라인`
- **RF 카드 설정**: 1 마스터 카드 등록, 2 RF 등록용 카드 등록 (카드 접촉 → `0`), 3 세대용 RF 카드 등록 및 삭제
  (1 세대 카드 등록: 동 → `*`, 호 → `#`, 카드 접촉 / 2 카드 삭제: 카드 접촉 / 3 세대 카드 삭제: 동·호 입력 후 `#` 한 번 더 / 4 카드 전체 삭제: `0`)
- `호출`·`경비`를 누르면 상위 메뉴로

동작하는 설정: 로비번호, 경비번호, 시스템 비밀번호, 주차관제로비, 경비 문열림 비밀번호, 공동 비밀번호(+사용여부), 근접센서, 키 LED, LCD 백라이트, 숫자 음, 문열림 시간, 멜로디·키톤 볼륨. 네트워크·DSP 항목은 실제 기기처럼 값만 표시됩니다.

### 글꼴

LCD 글꼴(`assets/qwertys_homenet/font/lcd.ttf`)은 사용자가 제공한 파일이며 라이선스상 재배포가 금지되어 있어 **저장소에는 올리지 않습니다**. 빌드한 jar에만 넣어서 개인적으로 사용하세요. 직접 빌드할 때는 같은 경로에 글꼴 파일을 넣으면 됩니다. 텍스처는 `python3 tools/gen_lobby_phone.py`로 다시 만들 수 있습니다(글꼴 필요).

## 구조

```
src/main/java/com/qwerty/homenet/
├─ HomeNet.java                  메인 클래스
├─ registry/                     블록·아이템·블록엔티티·크리에이티브 탭 등록
├─ block/                        월패드, 인터폰, 제어 블록, 스마트 조명, 기기 종류
├─ blockentity/                  각 블록의 상태와 통화 로직
├─ intercom/                     통화 상태, 인터폰 상태, 메시지, 부재중 기록
├─ data/UnitRegistry.java        세대 번호 → 월패드 위치 (월드 저장 데이터)
├─ item/HomeLinkerItem.java      홈 링커
├─ network/                      패킷 (서버↔클라이언트)
└─ client/                       월패드 / 인터폰 / 기기 설정 화면
```

화면은 텍스처 없이 코드로 그립니다 (`client/HomeNetScreen.java`의 색상 상수로 테마 변경 가능).
벨소리는 바닐라 소리 블록 차임을 높낮이 두 번 울려 "딩-동"을 냅니다.
